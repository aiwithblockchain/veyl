用对话操作 VPN

不需要看懂协议，也不需要点一长串设置。对着输入框说「连到日本」， Veyl 会挑节点、生成配置、启动内核，然后把出口 IP 告诉你。

下载

它解决什么

对话即操作

连接、换节点、断开、看状态，都是说一句话。界面上一张工具卡，过程看得见。

用自己的 Key

AI 走你自己的 DeepSeek API Key，存在系统钥匙串里。我们不转发、不代理你的调用。

不中转流量

客户端直连节点，我们不经过你的数据。平台只负责给你一份可用节点清单。

内核是官方的

客户端下载 sing-box 官方发行版并校验哈希，不修改源码。版本由应用管理。

你需要知道的

  • 需要自己准备一个 DeepSeek API Key。没有 Key 也能用，只是要手动选节点。
  • P1 只设置系统代理，不接管全局流量。不走系统代理的程序不受影响。
  • P1 只支持有公网 IP 的节点。家庭宽带节点要等后续版本。
  • 客户端完全开源。内核是 GPL-3.0 的 sing-box，以其原始形式分发。

从源码构建

git clone --recurse-submodules https://github.com/aiwithblockchain/veyl.git
cd veyl
npm install
npm run app:dev

需要 Rust 1.77+、Node 18+。构建与打包见 docs/build-and-release.md。

# Veyl 界面规范

Veyl 是一个**常驻菜单栏的桌面网络工具**，界面主体是**对话**。
它不是仪表盘，不是控制台页面，也不是营销页。

先读同目录 `../product-designer/SKILL.md`（信息架构与 UI 基础）与 `../frontend-design/SKILL.md`（设计方法）。
与本文件冲突时，**本文件的硬规则优先**。

---

## 1. 架构：对标 Claude Code 桌面版

```
┌───────────────┬──────────────────────────────────────┬──────────────┐
│  侧栏 240     │  顶栏：标题 ······ 状态 · 面板开关      │  右栏 320    │
│               ├──────────────────────────────────────┤  默认隐藏     │
│  Veyl         │                                      │              │
│               │        对话消息流                     │  连接状态     │
│  总览          │     （列宽 ≤ 720，居中）              │  线路图       │
│  ─────        │                                      │  主按钮       │
│  会话 1        │                                      │  节点         │
│  会话 2        │                                      │  数据         │
│               ├──────────────────────────────────────┤  详情 ⌄       │
│  设置          │        输入框                        │              │
└───────────────┴──────────────────────────────────────┴──────────────┘
```

### 1.1 中间永远是对话

**没有「控制台页面」这个东西。** 空对话时显示的是**对话的空态**，不是一张仪表盘：一句话说明 + 一个主按钮 + 最多 3 条建议问题，垂直居中，列宽不比消息流宽。

任何形态下中间区域都必须能直接输入、直接发消息。不允许出现「先选一个功能再对话」的中间层。

### 1.2 右栏默认隐藏

- 右栏承载连接状态、线路图、主按钮、节点切换、连接数据与详情。
- **启动时不出现在屏幕上。** 由顶栏的状态控件打开，关闭状态存 `localStorage["veyl.ui.panelOpen"]`，默认 `false`。
- 宽屏（≥1100px）停靠：对话列宽随之收窄，但消息列仍居中、不超过 720。
- 窄屏（<1100px）浮层：覆盖在对话上，右侧滑出，点击遮罩或 Esc 关闭。

理由：对话才是产品主体。连接状态是次要信息，常驻一个 320px 的栏会让 90% 的操作时间都在看一个不用看的区域。

### 1.3 侧栏是会话导航

只放：品牌 / 新建对话 / 会话列表（可折叠）/ 设置。
不放「总览」这类功能入口、不放连接状态、不放开发者徽标。中间区域本身就是对话，不需要一个「回到总览」的入口。

## 2. 三条不变量

### 2.1 同一屏幕只有一个主按钮

主按钮 = 视觉权重最高的实心按钮。

| 主区显示 | 主按钮在哪里 |
|---|---|
| 空对话 | 对话区中央 |
| 有对话 | 右栏（打开右栏时）；右栏关闭时顶栏只给一个描边的「连接/断开」小按钮 |
| 首次引导 | 引导页 |

截图眯眼看，只有一个实心色块。

### 2.2 每个事实只有一个住处

| 事实 | 唯一住处 |
|---|---|
| 连接状态 | 顶栏状态控件（始终可见）+ 右栏状态头（打开时） |
| 出口 IP、直连 IP、时长、延迟 | **右栏** |
| 节点名 | **右栏** |
| 端口、系统代理、连接数、PID、版本、哈希 | **右栏的「详情」折叠区** |
| 默认配置版本 | 设置页「网络」分区 |
| 错误摘要 | 右栏状态头一行；完整信息进详情 |

### 2.3 引导只对没学会的用户出现

`hasEverConnected` 为真后，不再出现建议问题、提示条、空态说明。
高级配置只能从设置页进入，不主动出现。

## 3. 视觉

**一句话：浅色、克制、信息密度低、边界靠留白不靠线框。**

默认浅色，跟随系统 `prefers-color-scheme` 切换深色。两套都必须是完整可用的。

### 3.1 颜色 token

```
浅色（默认）
--bg           页面底色        #FAFAF9
--bg-panel     侧栏 / 右栏      #F5F5F3
--bg-card      卡片 / 输入框     #FFFFFF
--bg-hover     悬停            #EDEDEA
--line         分隔线          rgba(0,0,0,.07)
--line-strong  边框            rgba(0,0,0,.14)

--ink          主文字          #1B1B1A
--ink-2        次要文字        #5C5C58
--ink-3        弱化 / 标签      #8B8B85

--accent       强调（链接、选中） #2C6BE0
--ok           已连接          #1C8A57
--warn         异常            #A96A00
--err          失败            #BE3A2E

深色（prefers-color-scheme: dark）按同样角色反相，不要单独发明色相
--bg #16181B / --bg-panel #1C1F23 / --bg-card #22262B
--ink #E9E9E7 / --ink-2 #A5A5A0 / --ink-3 #77776F
```

**用色规则**
- 主按钮用 `--ink` 实心 + `--bg` 文字（浅色下是深色按钮，深色下是浅色按钮）。**不用彩色实心按钮。**
- `--ok/--warn/--err` 只用于状态点、状态文字、描边，**不做按钮填充**。
- 危险操作一律 `.btn--danger-ghost`（描边 + 危险色文字），包括二次确认里的最终按钮。重量靠二次确认给。
- 一屏出现的彩色不超过 2 种。

### 3.2 字体

离线硬约束：**不加载外部字体、不用 CDN**。

- 正文与标题：系统 sans（`-apple-system` / `PingFang SC` / `Segoe UI`）。
- **数字与标识符用 mono**（端口、IP、PID、版本、耗时、哈希），套 `.num`，`font-variant-numeric: tabular-nums`。

字号阶梯（只有这 6 档）：
```
22px/600  页面与引导主标题
17px/600  区块标题
15px/500  卡片标题、按钮
14px/400  正文、消息
13px/400  次要说明
11px/500  小标签（--ink-3，中文不加 letter-spacing）
```
标题行高 1.35，正文 1.65。

### 3.3 间距与圆角

4px 网格：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
页面左右边距 24–32；区块间距 24；卡片内边距 16。
圆角两档：`--r-sm: 8px`（按钮、输入、行）、`--r-lg: 12px`（卡片、浮层）。
**不用大圆角胶囊化的按钮**，那是营销页的做法。

### 3.4 签名元素：线路图

只在右栏状态卡里出现一条水平线，从「本机」到「出口」，编码真实连接状态：

- 未连接：中断，`--ink-3`，中间 6px 缺口
- 连接中：从左往右生长，`--accent`
- 已连接：连续，`--ok`，极慢的流动虚线
- 失败：缺口处一个 2px 断点标记，`--err`

右栏关闭时它不出现。这是全产品唯一的装饰性元素，其余一律不加动效。

### 3.5 动效

只有三类：状态过渡 120ms、线路流动 3s 循环、浮层 160ms（透明度 + 4px 位移）。
`prefers-reduced-motion: reduce` 全关。

## 4. 四个场景

### 4.1 首次安装（无 Key、无配置）

全屏引导，两步：

| 步骤 | 内容 | 主按钮 | 次按钮 |
|---|---|---|---|
| 1 | 一句话说明 + 「先连上，再聊」 | 连接测试节点 | 导入我的配置文件 / 跳过 |
| 2 | 配置 AI（可选）：DeepSeek Key | 保存并验证 | 稍后再说 |

连接优先于 AI。平台链接 `https://platform.deepseek.com/` 用一行文字链接，不做大按钮。

### 4.2 有 Key、无会话（空对话）

中间区域的空态，垂直居中，宽度不超过 720：

```
        先连上，再聊。

        [   连接到测试节点   ]

        或者问我：
        · 为什么我打不开某个网站？
        · 检查我的网络配置
```

建议问题只在 `!hasEverConnected` 时出现。

### 4.3 对话中

消息流居中，列宽 ≤720。输入框贴底，宽度与消息列一致。
对话区**不出现任何连接控件**——连接在顶栏状态控件和右栏里。

### 4.4 熟练用户

不显示任何引导、建议问题、空态营销文案。
空对话只剩一行 `问点什么，或者让我诊断网络` 加输入框。

## 5. 高级配置的 AI 解释

每个高级项旁一个统一的文字链接 `问 AI`。点击以固定前缀开一条会话：

```
我在 Veyl 的高级设置里调整「{项名}」。当前值是 {值}。
请用三句话说明：这项设置实际改变了什么、什么时候该改、改错会有什么后果。
不要给通用教程，只说这个设置本身。
```

覆盖：代理模式、本地端口、默认配置源、API 类型与 Base URL、模型选择。
这是唯一的高级解释入口，不另做帮助文档页。

---

## 6. 文案

- 中文。按钮用动词短语 2–6 字；说明用完整句子。
- 按钮说的词，结果消息用同一个词（「连接」→「已连接」）。
- 不用「请」堆客套，不用感叹号。
- 错误三段式：**发生了什么 → 为什么 → 现在做什么**。
- 空态写用户能做的动作，不写「暂无数据」。
- `TUN` / `mixed` / `selector` 这类术语出现时必须带中文解释，或只放在「详情」里。

---

## 7. 实现约束

- 样式集中在 `src/styles/app.css`，按区块注释分组。不引入 CSS-in-JS 或 UI 框架。
- 状态文案与状态色映射集中在 `src/ui/status.ts`，不在组件里重复 switch。
- 删组件同时删它的 CSS 段。
- **离线优先**：不加任何外部字体、图片、CDN。深色主题只用 `prefers-color-scheme`，不做手动切换开关（本期）。

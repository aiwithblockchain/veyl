和租一个共享节点，不一样

服务器

每一台都归你，不与人共享

共享节点把同一个 IP 分给很多人。Veyl 给你开的是独立的服务器，节点只在你自己的账号里，不和别人共用。不限设备数，也不限制同时登录。

AI

助手看得到连接，不只是陪你聊天

它读得到节点、延迟和当前配置。你说「换到日本」，它就去挑节点、改配置、重连。用的是你自己的 DeepSeek Key，存在系统钥匙串里；我们不转发、不代存你的调用。

试用

先连 7 天，再决定要不要买

装好就能加入 2 个免费节点，每台设备 7 天，从第一次连接开始计时。到期后节点自动从池里移除，不需要先付款。

它做三件事

01

连接和切换

一个按钮启动。控制台上是连接时长、流量、延迟和出口 IP。默认智能模式，国内站点直连，其余走节点；要全部流量都走节点，切到全局。

Proxy 模式 · Tun 模式
02

自建服务器

在应用里选地区、选配置，下单后几分钟自动装好，节点直接进池可用。不用了随时销毁，按天计费，服务器装好才开始算。

512 MB · 1 GB · 2 GB
03

手机导出

把自己付费的节点导出成一份导入码，手机上的第三方客户端扫码就能用。

设置 › 账户 · 在手机上使用

手机上也能用

Veyl 不提供手机客户端。桌面端导出导入码，手机上的第三方客户端扫码就能用。

导入

  1. 01
    在桌面端导出

    设置 › 账户 →「在手机上使用」，找到你在用的客户端。

  2. 02
    扫码装客户端

    弹层里先扫安装码，把客户端装到手机上。

  3. 03
    扫码导入

    再用导入码扫一次，配置就进手机了。

只导出你自己创建的付费节点，免费试用节点不包含。导入码可以随时重新生成，旧码立即失效。

开始之前：
准备一个 DeepSeek API Key

AI 助手用你自己的 DeepSeek Key。没有 Key 也能用，只是节点要自己选。

  1. 01 注册

    打开 platform.deepseek.com，注册账号。

  2. 02 充值

    在账户里充值，保证余额够用。

  3. 03 创建 API Key

    创建一个 Key。它只显示一次，丢了只能重新创建。

  4. 04 粘贴到 Veyl

    首次启动时，或 设置 →「AI」，把 Key 粘进去。

Key 只保存在本机的系统钥匙串里，我们不转发、不代存你的调用。AI 费用按 DeepSeek 官方用量计算。

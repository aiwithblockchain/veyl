Not the same as renting a shared node

Server

Every server is yours, not shared

A shared node hands the same IP to many people. Veyl creates a dedicated server for you; its node lives only in your account and is shared with no one. No device limit and no limit on concurrent logins.

AI

The assistant can see your connection, not just chat

It reads your nodes, latency, and current configuration. Say “switch to Japan” and it picks a node, edits the config, and reconnects. It runs on your own DeepSeek key, kept in the system keychain; we do not relay or store your calls.

Trial

Connect for 7 days before you decide

Once installed you can join 2 free nodes, 7 days per device, counted from your first connection. When the trial ends the nodes drop out of the pool automatically, and no payment is required first.

It does three things

01

Connect and switch

One button to start. The console shows connection time, traffic, latency, and exit IP. Smart mode is the default: sites in China go direct, everything else through your node. Switch to global to send all traffic through it.

Proxy mode · Tun mode
02

Your own server

Pick a region and a size in the app. A few minutes after you order, the server is provisioned and its node joins your pool, ready to use. Destroy it whenever you want; billing is by the day and starts only once it is running.

512 MB · 1 GB · 2 GB
03

Export to phone

Export a node you paid for as an import code. Scan it with a third-party client on your phone and it is ready to use.

Settings › Account · Use on phone

Import

  1. 01
    Export on the desktop

    Settings › Account → “Use on phone”, then pick the client you use.

  2. 02
    Scan to install the client

    In the dialog, scan the install code first to put the client on your phone.

  3. 03
    Scan to import

    Scan once more with the import code and the configuration lands on your phone.

Only nodes you created and paid for are exported; free trial nodes are excluded.

Billed by the day

Servers are billed by the day, with no monthly or yearly plans. The first day is charged only once the server is running; destroy it and nothing more is billed.

Before you start:
have a DeepSeek API key ready

The AI assistant runs on your own DeepSeek key. You can use Veyl without one; you just pick nodes yourself.

  1. 01 Sign up

    Open platform.deepseek.com and create an account.

  2. 02 Add credit

    Top up your account so it has enough balance.

  3. 03 Create an API key

    Create a key. It is shown only once; if you lose it, create a new one.

  4. 04 Paste it into Veyl

    On first launch, or under Settings → “AI”, paste the key.

The key is stored only in your machine's system keychain; we do not relay or store your calls. AI usage is billed by DeepSeek at its official rates.

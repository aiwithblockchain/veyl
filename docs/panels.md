# 控制面板 = 一套配置方案

> 日期：2026-11-03
> 一句话：**一个控制面板就是一套完整的网络配置。切换面板就是切换配置和模式。**

---

## 1. 一套面板包含什么

| 项 | 例子 |
|---|---|
| 连接方式 | 接管全部流量（TUN）/ 只给代理地址（proxy） |
| 分流策略 | 本地直连 / 全部走 VPN / 指定服务走 VPN |
| 节点 | 用哪个服务器 |
| DNS | 本地与境外各用哪几个候选 |
| 代理参数 | 端口（proxy 模式） |
| 内网排除 | 额外要绕开的网段（TUN 模式） |

这些是一整套，**不拆开单独切换**。用户不需要理解「为什么我换了模式，分流也跟着变了」——因为在他脑子里这就是同一件事：换了一套方案。

---

## 2. 什么时候新建一套

| 触发 | 举例 |
|---|---|
| **改连接方式** | 从「只给代理地址」升级成「接管全部流量」——这是最典型的一次，必须新建，不能就地改 |
| 换场景 | 公司一套、家里一套、出差一套 |
| 换用途 | 一套「日常」，一套「只给某个软件用」 |

**改连接方式必须新建而不是就地修改**：`proxy` 和 `TUN` 是两种完全不同的网络接管方式，就地改会让「我刚才明明配好了」变成「它自己变了」。新建一套、起个名，用户知道自己做了什么。

其它改动（换节点、加一条分流规则）**就地改当前面板**，不新建——否则面板会爆炸。

---

## 3. 名字

**用户起名，我们给建议名。**

新建时弹一个输入框，预填一个能用的建议：

```
新建一套配置

名字  [ 公司 · 接管全部        ]

这套会接管全部流量。以后可以在顶部随时切回来。

[ 创建 ]   [ 取消 ]
```

建议名的构成：`场景或时间 · 关键特征`。比如「家里 · 本机代理」「出差 · 指定服务」。

用户不改也能直接用。**不允许重名**——重名会让下拉列表里两个一模一样，等于没名字。

---

## 4. 位置：中间区域顶部

```
┌──────────────────────────────────────────────┐
│  家里 · 本机代理 ▾              ● 已连接      │
├──────────────────────────────────────────────┤
│                                              │
│              中间区域的内容                    │
│                                              │
└──────────────────────────────────────────────┘
```

点开是一个下拉列表：

```
✓ 家里 · 本机代理        本机代理 · 已连接
  公司 · 接管全部        接管全部
  出差 · 指定服务        接管全部
  ─────────────────────
  ＋ 新建一套
```

每项显示「名字 + 模式」，因为用户可能记不住自己给哪套配了什么。

**左栏不放面板列表。** 左栏留给别的内容，面板切换就在它上面一行。

---

## 5. 切换的代价

切换面板 = 换配置 = 必须重启运行时。这意味着：

| 情况 | 行为 |
|---|---|
| 当前未连接 | 直接切，无感 |
| 当前已连接 | **先提示会断开一次**，确认后切换并自动重连 |
| 当前有未保存的对话改动 | 先问是否保存 |

不静默切换——用户点一下名字，网络断了两秒，如果不说清，他会以为是故障。

---

## 6. 存储

| 内容 | 存哪 | 为什么 |
|---|---|---|
| 面板的索引（id、名字、模式、创建时间、最后使用时间、是否当前激活） | SQLite | 要排序、要查重名、要记住上次用的哪套 |
| 面板的完整配置 | SQLite（同一行或关联表） | 要能整体读写、整体校验 |
| 节点密码 | `secrets.enc`，配置里只留引用 | 明文密码永不落盘 |
| **预置资源**（提示词、默认配置模板、规则集） | **文件**，随包预置 | 见 `docs/upgrade.md`：它们是产品资产，跟 APP 版本走，不进数据库 |

---

## 7. 与「千人千面」的关系

面板定的是**配置**，不是**界面长相**。同一套配置下，中间区域显示哪些块仍然由 AI 编排。

但两者有关系：**换了面板，AI 应该重新编排一次中间区域**——因为连接方式和分流都变了，原来那块「本机代理地址」的卡在新面板里没有意义。

切换面板之后，AI 收到一条系统消息说明换了什么，然后决定中间区域显示什么。不需要再问用户一遍。

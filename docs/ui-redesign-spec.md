# 界面重构方案 v2（架构纠正）

> 日期：2026-11-03
> 替代 v1。v1 把「控制台」做成了一个独立页面，并把右栏做成常驻第三列、整体用深色——三点都错了。
> 规范来源：`.claude/skills/veyl-ui/SKILL.md`（硬规则）
> 方法来源：`.claude/skills/product-designer/SKILL.md`、`.claude/skills/design-system-lead/SKILL.md`、`.claude/skills/frontend-design/SKILL.md`

---

## 0. v1 错在哪

| # | v1 的做法 | 正确做法 |
|---|---|---|
| 1 | 中间主区默认是「控制台」页面，`view` 初值 `"overview"` | **中间永远是对话**。空对话显示的是对话空态，不是另一个页面 |
| 2 | 右栏作为常驻第三列，`panelPreferred` 默认 `true` | **右栏默认隐藏**，由顶栏状态控件打开，`panelOpen` 默认 `false` |
| 3 | 深色（`--bg: #0B0C0E`），「深色仪器面板」 | **浅色为默认**，跟随 `prefers-color-scheme` 切深色 |

架构基准：Claude Code 桌面版——左侧会话导航，中间对话，右侧信息面板按需出现。

## 2. 组件改造

### 2.1 `src/App.tsx`

- **删除 `"overview" | "chat"` 这个视图概念**。`view` 状态整个移除，渲染只由「有没有当前会话」决定。
- 无当前会话 → 渲染 `EmptyChat`；有会话 → 渲染 `ChatView`。
- `panelPreferred` 初值改为 `false`（`localStorage` 有值时以存储为准）。
- 侧栏不再有「总览」入口，对应 `onSelectOverview` 一并删除。
- 窄屏断点从 1240 改为 **1100**；窄屏时右栏渲染为浮层（复用 `useFocusTrap`，Esc 关）。

### 2.2 `src/components/EmptyChat.tsx`（新建，替代 `ConsoleView.tsx`）

`ConsoleView` 删除。空对话是**对话的空态**，不是页面：

```
        （垂直居中，宽度 ≤ 720）

        先连上，再聊。                 ← 22px，随连接状态变化
        用官方提供的节点，点一下就能用。   ← 13px --ink-2

        [   连接到测试节点   ]          ← 唯一实心按钮

        或者问我：                     ← 仅 !hasEverConnected 时
        · 为什么我打不开某个网站？
        · 检查我的网络配置
```

- 已连接时的标题改为 `已就绪，聊点什么`，主按钮改为描边的「断开」或不显示主按钮。
- 建议问题点击 = 用该文案开新会话并发送（沿用 `onSend`）。
- 输入框始终存在，与消息流同一个 `Composer`。
- 不显示默认配置版本、不显示诊断入口——都移到设置页与右栏。

### 2.3 `src/components/Sidebar.tsx`

- 删除「总览」行。
- 顺序：品牌 → `新建对话` → 会话分组 → 设置。
- 底部不再有任何徽标。

### 2.4 `src/components/StatusPanel.tsx`

结构不变（6 块），但要适配浅色与新布局：
- 状态头副文案在未连接时不显示「系统代理未接管」这类技术话术，改为一句人话。
- 窄屏浮层模式下加 `compact`，宽度 100%、右侧滑入。
- 顶栏状态控件与它共用 `src/ui/status.ts` 的同一个状态机。

### 2.5 `src/styles/app.css`

- 用 `.claude/skills/veyl-ui` §3.1 的**浅色 token 替换**现有一套，并新增 `@media (prefers-color-scheme: dark)` 覆盖块。两套都要能看。
- 圆角从 14 降到 12，按钮不用胶囊。
- 删除 `console__*`、`diagnosis__*`、`app--status-collapsed`、`overview` 相关样式。
- 新增 `empty-chat*`、`topbar__status`、`panel-overlay` 区块。
- 保留 `msg__*`、`tool-card*`、`thinking-block*`、`composer*`、`markdown*`、`modal*`、`sheet*`，只替换其中的颜色/间距为 token。

### 2.6 顶栏

```
┌──────────────────────────────────────────────┐
│ 会话标题                    ● 已连接 · 东京 01  ⧉ │
└──────────────────────────────────────────────┘
```

- 左：当前会话标题（无会话时显示 `Veyl`）。
- 右：状态控件（点 + 句子，点击打开右栏），后面一个面板开关按钮。
- 状态控件是**唯一常驻的连接入口**；连接/断开的主按钮仍在右栏。

## 3. 不改的部分

- `src-tauri/`、`src/agent/`、`src/state/`、`package.json`：一行不动。
- `ChatView` / `MessageItem` / `Markdown` / `ToolCallCard` / `ThinkingBlock` / `Composer` 的**逻辑**不改，只接受样式变化。
- `Settings.tsx` 的四分区结构保留，只换主题与间距。
- `Onboarding.tsx` 两步结构保留。

## 4. 验收

| # | 场景 | 通过条件 |
|---|---|---|
| U1 | 启动 | 直接看到对话区（空态），不是另一个页面；**右栏不在屏幕上** |
| U2 | 整体观感 | 浅色、白底、密度低；没有大面积深色块 |
| U3 | 主按钮 | 空对话时只有一个实心按钮 |
| U4 | 打开右栏 | 点顶栏状态控件出现；关闭后刷新页面仍保持关闭 |
| U5 | 有对话时 | 中间是消息流，没有任何连接控件；连接操作只在右栏 |
| U6 | 窄窗口 | <1100px 时右栏变浮层，Esc 可关 |
| U7 | 深色系统 | 系统切深色后界面跟随，不出现白底黑字错配 |
| U8 | 侧栏 | 没有「总览」，只有新建对话、会话列表、设置 |
| U9 | 数据唯一 | 出口 IP 只在右栏出现一次；连接成功后入口在顶栏一眼可见 |
| U10 | 离线 | 断网启动不白屏、不请求外部字体/图片 |

# Veyl 业务流程（本阶段定稿）

> 日期：2026-11-03
> 定位：界面与业务流程的最终形态。底层能力未就绪的部分一律按「已具备」设计。
> 依据：`docs/user-segments.md`

---

## 0. 核心原则：智能优先

**先让产品获得智能 → 智能去获取节点 → 建立网络连接。**

连接不是用户手动点出来的结果，是 AI 完成之后的产物。
这推翻了早期「先连上，再聊」的设定。

对应地，产品的主入口是「配置 AI」，不是「点连接」。

---

## 1. 首次启动：一屏，三个入口

```
                    Veyl

        配置 AI 后，我来帮你连上网络。

        ┌──────────────────────────────────┐
        │  DeepSeek API Key                │
        │  sk-________________________     │
        └──────────────────────────────────┘
              [ 保存并验证 ]

        还没有 Key？去 platform.deepseek.com

        ────────────────────────────────────

        [ 使用 Google 登录 ]

              我懂网络，不用 AI
```

| # | 入口 | 面向谁 | 进去之后 |
|---|---|---|---|
| 1 | 配置 AI API（默认展开） | 大多数用户 | AI 主动获取节点并建立连接 |
| 2 | 使用 Google 登录 | 有 Veyl 账号的用户 | 同上；账号体系后续接邮箱注册与付费 |
| 3 | **我懂网络，不用 AI** | 三级、四级用户 | 直接进主界面，用右侧面板手动操作网络 |

- 三个入口在**同一屏**，不分成多步向导。
- 第 1 项是视觉重点；第 2 是次按钮；第 3 也是按钮，但用最轻的样式（描边 / 文字按钮），位置在最下面。
- 三个入口通往同一个主界面，**不改变布局**——因为右侧面板本来就能直接操作网络。

### 1.1 第三个入口的文案

用 **「我懂网络，不用 AI」**。

理由：它是一句自我识别，不是一句功能描述。用户读到就知道这是给自己的。不用「跳过」「高级模式」「开发者」这类词——「跳过」显得产品在挽留，「高级模式」让人怀疑自己不够格。

备选（若嫌上面太口语）：`不需要 AI，我自己管网络`。

---

## 2. 配置 AI 之后

保存并验证成功后，**不进入空聊天页**，而是直接进入对话，AI 已经拿到智能、主动办第一件事：

```
AI：我已经连上测试节点了，出口在东京。
    现在打开浏览器试试，应该能访问 ChatGPT 了。

    [ 换个节点 ]  [ 检查网络 ]
```

- 连接状态同时在顶栏与右侧面板可见。
- 用户不需要理解「连接」这个动作发生了什么，只需要知道结果。
- 连接失败时，AI 给的是「发生什么 / 为什么 / 现在做什么」三段式，不是错误码。

---

## 3. 选择「我懂网络，不用 AI」之后

直接进入主界面，**没有任何引导**：

- 中间是对话区，但 AI 不可用，输入框禁用并显示一行说明。
- 右侧面板可用：连接、断开、换节点、代理地址、端口、诊断、恢复网络，全部可用。
- 首次进入时右栏**自动展开**（这批用户的下一步动作就在右栏），之后按用户上次的选择保持。

这一条保证了「不影响布局」：三个入口进来看到的都是同一个界面，差别只在右栏是否默认展开、以及对话是否可用。

---

## 4. 日常使用

**有 AI 的用户**：通过对话办事。右栏用于查看状态与做精确操作。

**无 AI 的用户**：通过右栏办事。对话区保持禁用但可见，随时可以在设置里补配 AI。

**连接入口位置**：
- 有会话时：右栏（打开状态）。
- 右栏关闭时：顶栏一个描边的连接/断开小按钮。
- 空对话且未连接：对话区中央的主按钮。

---

## 5. 四级用户：提供节点

入口在设置页 →「提供节点」，与首次启动无关。

流程：说明 → 选服务商 → 读懂页面并分步指导创建 → 校验配置 → 指导接收款 → 生成并指导发布。
能力边界见 `docs/user-segments.md` §4。

---

## 6. 与 Claude Code 桌面版的对应关系

| Claude Code | Veyl |
|---|---|
| 首次打开要求登录或填 API Key | 首次打开要求配 AI / Google 登录 / 明确选「不用 AI」 |
| 未登录不能使用 | 不配 AI 时对话不可用，但网络功能可用 |
| 登录后直接进入对话 | 配好后直接进入对话，AI 主动开始干活 |

差异点：Claude Code 没有「不用 AI」这条路，因为它本身就是 AI 工具。Veyl 是网络工具，所以必须留这条路——但它被放在最下面，不抢主路径。

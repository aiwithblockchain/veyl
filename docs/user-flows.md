# Veyl 业务流程（本阶段定稿）

> 日期：2026-11-03
> 定位：本文件是**界面与业务流程的最终形态**。底层能力未就绪的部分一律按「已具备」设计，后端补齐是后续工作。
> 依据：`docs/user-segments.md`

---

## 1. 一个决定：使用方式三选一

产品不让用户理解 proxy 与 TUN。用户只回答一个问题：**你要让什么能用？**

| 选项（界面原文） | 使用方式 | 底层 | 用户要做的配置 |
|---|---|---|---|
| 只让浏览器能上国外的网站 | `browser` | 系统代理 | 无 |
| 电脑上的软件也要能用 | `all_apps` | TUN | 无 |
| 我自己会配置代理 | `manual_proxy` | 系统代理 + 显示端口 | 自己在软件里填 |

- 在**首次启动第一屏**问一次，之后不再问。
- 设置页「使用方式」可改，改完立即生效（下次连接）。
- 一级、二级用户界面上**不出现** proxy / TUN / 端口 / 环境变量任何字样。
- 只有 `manual_proxy` 能看到代理地址与可复制的配置片段。

**「提供节点」不是第四种使用方式**，是叠加在正常使用之上的独立能力，入口在设置页，见 §5。

## 2. 首次启动流程

```
① 选择使用方式
   你主要拿 Veyl 做什么？
   ○ 只让浏览器能上国外的网站
   ○ 电脑上的软件也要能用（AI 客户端、会议、邮件、游戏）
   ○ 我自己会配置代理
   [继续]

② 建立第一次连接
   我们已经准备好一个测试节点，点一下就能用。
   [连接到测试节点]   [导入我的配置文件]   [稍后再说]

③ 配置 AI（可选）
   AI 用来解释连不上的原因、推荐节点。
   [ 粘贴 DeepSeek API Key ]  [保存并验证]  [稍后再说]
```

- 第 ② 步完成即进入主界面，**不强制**走完第 ③ 步。
- 第 ③ 步可跳过，跳过后主界面保留一条可关闭的提示。
- 全程不显示完整 Key，不写日志。

## 3. 日常使用流程（一级 / 二级）

```
打开 Veyl
  ↓
顶栏显示当前状态  →  点「连接」
  ↓
已连接，顶栏显示 出口地区 · 出口 IP
  ↓
用户去用浏览器 / 客户端软件，不需要做任何配置
```

- 一级与二级的**操作完全一致**，差别只在底层模式，用户不可见。
- 连接失败时：顶栏变红，右栏给出**一句人话 + 一个下一步动作**，不出现错误码。
- 关闭窗口 = 后台运行；托盘图标常驻。

---

## 4. 日常使用流程（三级）

与一级/二级相同，多出三处：

1. 右栏「详情」里显示**代理地址**（`127.0.0.1:<port>`）与「复制配置片段」。
2. 诊断里多一项「命令行工具是否走代理」——这是系统代理模式的固有边界，需明确说明不是故障。
3. 设置页可一键切到「所有软件都走代理」（TUN），用于 Claude Code 这类按 IP 封锁、需要全流量出口的场景。

---

## 5. 四级用户：提供节点

入口：设置页 →「提供节点」。**不是**首启流程的一部分，不影响主流程。

```
① 说明
   把节点提供给别人用，可以按使用量获得收益。
   需要你自己准备服务器、自己负责合规与可用性。
   [我了解，继续]

② 选服务商
   Veyl 推荐在哪里买服务器，并说明不同价位的差别。
   [去选购]        ← 打开外部网站

③ 创建节点
   Veyl 读懂当前网页，逐步告诉用户：
   - 这一步在选什么、哪些选项有影响
   - 关键字段该填什么、填错了会怎样
   每一步完成后用户回到 Veyl 点「下一步」。

④ 校验与接入
   把生成的配置填回 Veyl，Veyl 校验能连通后才允许继续。

⑤ 获得收益
   指导用户接上收款方式，讲清收益来源与风险。
   Veyl 不代持私钥、不代签合约。

⑥ 发布
   生成可发布的节点信息，指导用户完成发布。
```

**能力边界**：Veyl 只做引导、解释与校验；不代注册、不代付款、不代持私钥、不代签合约、不承诺收益、不做流程外的任意网页抓取。详见 `docs/user-segments.md` §4。

---

## 6. 使用方式的判断与切换

- 首次由用户自选，**不靠推断**。用户自述比任何行为推断都准，而且这是唯一能在首屏就问清楚的机会。
- 用户在某个软件上连不上时，AI 诊断的结论里包含一条建议：**「换一种使用方式」**，一键切换。
- 设置页始终可改。

---

## 7. 三种使用方式的状态文案

同一件事，三种用户看到的措辞不同：

| 场景 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 已连接 | 已连接 · 东京 | 已连接 · 东京 | 已连接 · 东京 |
| 右栏副文案 | 出口 203.0.113.7 | 出口 203.0.113.7 · 所有软件已接管 | 出口 203.0.113.7 · 代理 127.0.0.1:50046 |
| 连接失败 | 连不上，可能是节点的问题 | 同上 | 同上 + 可选的技术细节 |

---

## 8. 本阶段不做

- 自动推断用户层级。
- TUN 与系统代理的手动切换（三级用户在设置里选「使用方式」即可，不单独给一个「TUN 开关」）。
- 四级用户的实现细节（等产品负责人给方案）。

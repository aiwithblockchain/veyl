# 简化新建配置：界面版式规范

> 把 `docs/design/simplified-config-create.md`（下称「源文档」）的文字方案落成可直接照着写的版式。
> **适用范围**：本文描述的是**无 AI 兜底**的手动两问表单（含审视页与供应商广场）。AI 就绪时点「新建配置」直接进对话，
> 不打开这个弹窗；AI 路径的提问卡片见源文档 §11.2。
> 产品语义以源文档为准；本文只补视觉与布局，不新增字段、不改契约。
> 两份文档已于 2026-11-12 对齐（PM 裁决）：节点来源卡叫 `其它节点`、页面叫「供应商广场」；
> 审视页五行全部只读（含地区只读展示，没有控件）；名称自动生成、审视页只读（建立后可在左栏双击改名）；主按钮未连接 `创建并连接`、已连接 `创建配置`。
> 改任何一处结论都要同步另一处，避免两处各说一套。
> 不改代码。依据优先级：`veyl-ui` 硬规则 > `ui-ux-pro-max` > 一般审美。

## 0. 共用规则

| 项 | 规格 |
|---|---|
| 弹窗宽度 | 桌面 `min(480px, calc(100vw - 48px))`；窄屏（<640）`calc(100vw - 32px)` |
| 内容内边距 | 桌面 24；窄屏（<640）20 |
| 字号 | 只用 20 / 17 / 15 / 14 / 13 / 12 / 11（`veyl-ui` §3.2），不新增 16 / 18 / 10 |
| 间距 | 只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40（4px 网格） |
| 颜色 | 只用现有 token；本轮不引入色相。选中靠描边 + 勾选点，不做彩色填充 |
| 图标 | 不新造图标集：返回用文字 `←`，单选点用 CSS 圆点，加载复用现有转圈 |
| 主按钮 | 每一步只有一个是实心的；其余是 ghost / 文字链接（`veyl-ui` §2.1） |

**两问的排法结论：两张卡上下堆叠，桌面与窄屏都如此，不做并排。**

理由：弹窗内容宽 432（桌面）时，并排每张卡只剩约 178px；13px 中文一行约 13 个字，每条解释会折成 5–6 行，两张卡高度还会不齐——比较反而更难。上下堆叠一行约 30 个字，每条解释 2 行读完，命中区也更容易做到 ≥64px。

### 1.3 卡片解剖

| 部位 | 规格 |
|---|---|
| 卡片 | 整张可点；`padding: 16px`；`min-height: 88px`；圆角 `--r-sm`；`1px` 描边 |
| 单选点 | 16×16 圆；未选 `1px --hair-strong` 空心；选中 `1px --ink` 外环 + 6×6 `--ink` 实心点 |
| 标题 | 15 / 1.35 / 500，`--ink`，与单选点同一行，间距 10 |
| 定位句 | 13 / 1.55 / 400，`--ink-2`，标题下 6 |
| 补充说明 | 13 / 1.55 / 400，`--ink-3`，与定位句之间不额外留空 |
| 卡间距 | 8 |
| 组间距 | 24（不画分割线） |

**状态**

| 状态 | 描边 | 背景 | 单选点 |
|---|---|---|---|
| 未选 | `1px --hair-strong` | 透明 | 空心 `--hair-strong` |
| hover | `1px --ink-3` | `--paper` | 同上 |
| 选中 | `1px --ink` | 透明 | 实心 `--ink` |
| 键盘焦点 | 追加 `0 0 0 3px var(--accent-soft)` 外环 | 不变 | 不变 |

### 1.4 文案（逐字）

| 卡 | 标题 | 定位句 | 场景解释 |
|---|---|---|---|
| 1 | `TUN 模式（接管全部流量）` | `整台电脑都走 VPN。` | `浏览器、聊天、游戏、命令行都走 VPN，不用逐个软件设置。`<br>`第一次连接时，系统会请求一次授权。` |
| 2 | `Proxy 模式（只给代理地址）` | `只让部分软件走 VPN。` | `只让能填代理地址的软件走 VPN，其它软件保持原样。`<br>`需要在那个软件里填一次本机代理地址。` |

- 括号里的中文是标题的一部分，不是副标题；`veyl-ui` §6 的禁词例外只覆盖这两行标题（源文档 §5.3）。
- 两个词在正文、按钮、状态里仍不得出现。

### 1.5 键盘

- Tab 进入本组，焦点落在当前选中卡；`↑ / ↓` 在两张卡之间切换并即时选中；`Enter / Space` 选中。
- 整组用 `role="radiogroup"` + `aria-labelledby`，每张卡是一个原生 radio（视觉隐藏）；`aria-checked` 跟随。
- 焦点环必须在卡外圈完整可见，不被滚动容器裁掉（`ui-ux-pro-max` · Focus States · High）。

## 3. 审视页

### 3.1 行序与文案

```
看一眼，没问题就创建。

名称        配置 1
接管方式    TUN 模式（接管全部流量）
            浏览器、聊天、游戏都走 VPN。
节点来源    Veyl 免费节点
流量范围    智能模式
            国内网站直连，其它走 VPN。
            保存后可以在控制台随时切换。
地区        中国大陆

                              取消   [ 创建并连接 ]
```

| # | 标签 | 值（15 / `--ink`） | 第二行（13 / `--ink-2`） |
|---|---|---|---|
| 1 | `名称` | `配置 N`（自动取名，只读） | — |
| 2 | `接管方式` | `TUN 模式（接管全部流量）` / `Proxy 模式（只给代理地址）` | TUN：`浏览器、聊天、游戏都走 VPN。`<br>Proxy：`只让填了代理地址的软件走 VPN。` |
| 3 | `节点来源` | `Veyl 免费节点` / `其它节点` | 免费：—；供应商（接入后）：`已选 N 个节点` |
| 4 | `流量范围` | `智能模式` / `全局模式` | `国内网站直连，其它走 VPN。` / `所有流量走 VPN。`<br>末尾固定一句：`保存后可以在控制台随时切换。` |
| 5 | `地区` | `中国大陆` / `日本` / `未知` | — |

- 地区**只展示**，没有选择器、没有「对 / 不对」按钮（源文档 §7、§9）。
- 地区未知时，第 4 行改为：`没识别出你在哪个地区，所以按全局模式创建；之后可以在控制台切换。`（不再重复第 5 行的「未知」）。
- `流量范围` 是只读事实，不是第三个问题；不给开关。
- 名称只读（源文档 §7）：自动生成 `配置 N`，没有输入框、不可聚焦；**建立后可在左栏双击名称就地改名**（源文档 §10.1、`configs-and-nav.md` §2.2）。

### 3.2 版式

- 顶部一行 `← 返回`（13 / `--ink-3`，按钮，不是链接下划线）；右侧两个进度点，第二个实心。
- 行用两列网格：标签列 72px，值列自适应；行距 16；不画分隔线。
- 第二行说明与值左对齐（值列内），不复用标签列。
- 底部操作区：`取消` ghost 32px 在左，主按钮 44px 在右，间距 8。

### 3.3 主按钮与失败

| 场景 | 文案 | 行为 |
|---|---|---|
| 未连接 / 没有当前配置 | `创建并连接` | 创建成功后自动启动连接 |
| 当前已连接 | `创建配置` | 只创建，不切连接；提示「已创建，从左侧切换」（源文档 §7） |
| 保存中 | `正在创建…`（禁用，宽度不跳） | 不接受二次点击 |
| 保存失败 | 按钮恢复；错误条在操作区上方 12px | 错误留在页内，不弹 toast、不清空已选内容 |

已连接时按钮必须改文案：按钮承诺什么就做什么，不能写着「连接」却不切。

## 4. 常驻开关：流量范围

### 4.1 位置

在控制台 hero 内、连接状态下方，与「启动 / 断开 / 重新连接」同一个视觉块。**不新起一块，不进 AI 编排区。**

```
已连接  12:41:07                    [ 断开 VPN ]   ← 第 1 行：状态 + 主按钮
流量范围  [ 智能模式 | 全局模式 ]                    ← 第 2 行：开关（上距 16）
国内网站直连，其它走 VPN。                          ← 第 3 行：说明（上距 6）
```

### 4.2 尺寸与层级

| 元素 | 规格 |
|---|---|
| 行间距 | 第 1 行 → 第 2 行 16；第 2 行 → 第 3 行 6 |
| 标签 `流量范围` | 12 / 1.4 / 400，`--ink-3`，与开关间距 12，垂直居中 |
| 开关 | 高 32；两段各 `min-width: 72px`；总宽约 152；段间 6 |
| 段文字 | 13 / 500；未选 `--ink-2`；选中 `--ink` |
| 段样式 | 每段 `1px --hair-strong` 描边、`--r-sm`；选中段 `1px --accent` + `--accent-soft` 底（复用现有分段控件，不新造） |
| 说明行 | 12 / 1.45 / 400，`--ink-3`，最大宽度 46ch |
| 主按钮 | 44 高、实心 `--ink`；**开关不用实心、不用主按钮色** |

层级：主按钮是唯一的实心块；开关是 32px 描边控件；说明是 12px 弱文字。开关不得与按钮并排，避免出现第二个「按钮区」。

### 4.3 三种状态

| 状态 | 控件 | 说明行 |
|---|---|---|
| 未连接 | 可点；显示该配置的 `routing_mode` | 按 §8.3 文案，末尾追加 `连接后生效。` |
| 已连接 | 可点；热切，不断开、不确认 | 按 §8.3 文案，不加后缀 |
| 切换中（正在连接 / 正在断开） | 两段都禁用：`opacity: .55`、`cursor: default`、`aria-disabled="true"` | **不换文案**：状态词已经在说「正在连接 / 正在断开」，同一事实不在第二处重复 |

### 4.4 说明行文案（源文档 §8.3，逐字）

| `routing_mode` / 地区 | 开关 | 说明 |
|---|---|---|
| `direct` 且地区 = `cn` | `[智能模式] 全局模式` | `国内网站直连，其它走 VPN。` |
| `direct` 且其它已知地区 | `[智能模式] 全局模式` | `本国网站直连，其它走 VPN。` |
| `direct` 且地区未知 | 智能模式选中 | `没识别出你在哪个地区，现在所有网站都会走 VPN。` |
| `proxy_all` | `智能模式 [全局模式]` | `所有流量走 VPN。` |

- 只有两档；不出现「指定服务」。
- 未连接时读数行的「范围」一行删除，同一个事实只住在开关里。
- 地区未知的提示用 `--ink-2` 正文，不用红色——它是需要解释的降级，不是故障。

## 6. 失败态：免费节点拉取失败

### 6.1 位置

在第 2 问内部、「Veyl 免费节点」卡正下方 8px，随卡同宽。**不是 toast、不是弹窗、不是页面级横幅。**

```
┌ ● Veyl 免费节点 … ┐
└───────────────────┘
┌──────────────────────────────────────────────┐  ← 8px
│ 没能取到免费节点。                            │  ← 13/500 --err-text
│ 可能没联网，或免费节点服务暂时不可用。          │  ← 13 --ink-2
│ 点「重试」；还是不行，就改选「其它节点」。      │  ← 13 --ink-2
│ [ 重试 ]                                      │  ← 10px，ghost 32
└──────────────────────────────────────────────┘
```

### 6.2 样式

- 容器：`padding: 12px 14px`；左侧 `2px --err` 竖线；底 `--danger-soft`；圆角 `--r-sm`；宽度同卡。
- 第一行 `--err-text`，后两行 `--ink-2`；行距 1.55。
- 文案三段式：发生了什么 → 可能原因 → 现在做什么（`veyl-ui` §6）。
- 失败块 `role="alert"`，出现时读屏播报一次（`ui-ux-pro-max` · Error Messages）。
- 重试按钮 ghost 32px，左对齐，上距 10；不新造图标。

### 6.3 状态

| 状态 | 块内 | 重试按钮 | 「下一步」 |
|---|---|---|---|
| `failed` | 三段式文案 | 可用 | 禁用 |
| `loading` | `正在获取免费节点…` + 14px 转圈；块 `aria-busy="true"` | 变 `正在获取…` 并禁用 | 禁用，文案变 `正在获取…` |
| `ready` | 块消失 | — | 可用 |

- 不自动重试、不自动跳转、不静默创建空配置（源文档 §6.2）。
- 失败块只在「Veyl 免费节点」被选中时显示；改选「其它节点」后隐藏，状态保留，切回来还在。
- 失败时弹窗仍可取消、仍可改选另一张卡。

## 7. 桌面与窄屏差异

| 项 | 桌面（≥640） | 窄屏（<640） |
|---|---|---|
| 弹窗 | 480 居中，`max-height: 86vh`，内容滚动 | 视口 − 32，居中；同样滚动 |
| 内边距 | 24 | 20 |
| 两问排法 | 上下堆叠 | 上下堆叠（唯一排法） |

## 8. 无障碍与交互

- 两问各是一个 `radiogroup`；整卡可点，命中区 ≥64；Tab 进组、方向键切换、焦点环完整可见。
- 选中状态同时由描边、勾选点与 `aria-checked` 表达，不只靠颜色。
- 开关用两个 `<button aria-pressed>`，组标签 `流量范围`（`ui-ux-pro-max` · Compact Control Semantics · Critical）。
- 禁用控件：`disabled` + `aria-disabled`，`opacity: .55`/`.38`，光标不是手型。
- 审视页是只读事实列表，用 `<dl>`；主按钮可 Tab 到，焦点可见。
- 加载用 `role="status" aria-busy="true"`，布局不因转圈跳动（`ui-ux-pro-max` · Loading Indicators）。
- 所有解释常驻，不用 tooltip、不折叠。

## 10. 依据

- **`veyl-ui`**：§2.1 一屏一个主按钮；§2.2 每个事实一个住处（流量范围只住 hero 开关、地区只读）；§3.1 状态色只用于点/文字/描边、选中不靠彩色填充；§3.2 字号阶梯；§3.3 4px 网格与圆角；§3.4 签名元素（开关不抢计时器/状态词）；§6 错误三段式与禁词例外（仅两问标题）。
- **`docs/design/simplified-config-create.md`**：§5 两问与会话解释；§6 节点来源与失败路径；§6.3 供应商广场边界；§7 审视页只读事实与保存结果；§8 开关位置、状态与文案；§10 默认值。
- **`ui-ux-pro-max`**（本次检索）：
  - *Focus States / Keyboard Navigation*（High）：模态内每个可操作控件都要有可见焦点，Tab 顺序与视觉一致。
  - *Compact Control Semantics*（Critical）：紧凑控件用原生 button + `aria-pressed`，不用可点 div。
  - *Color Only*（High）：选中不能只靠颜色，需同时有勾选点与 `aria-checked`。
  - *Error Messages*（High）：错误用 `role="alert"` 播报，不只做视觉提示。
  - *Error Recovery*（Medium）：错误必须带下一步（重试 / 改选），不只报错。
  - *Disabled States*（Medium）：禁用要降透明度并改光标，不能与可点态同形。
  - *Loading Indicators*（High）：等待有稳定反馈与 `aria-busy`，避免布局跳动。

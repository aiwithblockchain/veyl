# AI 中转：已否决（2026-11-16）

> **决定**：M1 **不做 AI 中转**，只做「用户自带 Key」（走现有 `llm_provider_*`）。
> **原因**：自建中转要维护 token 计量、账本扣费、每日限额、售价表、上游价格巡检、汇率换算与告警一整套；维护成本远大于收益。目标用户基本已有自己的 AI 账号，直接填 Key 即可。
> **现状**：从未进入实现——控制面没有中转路由，Host 没有 `ai_relay_status` / `ai_usage_summary`，契约里也没有 `veyl-relay` 内置 provider。AI 对话只依赖用户自己的 provider 配置。
> **完整设计**（含火山方舟调研、价格接口、DDL、Host 改动清单、验证清单）见 git 历史中本文件的旧版本。

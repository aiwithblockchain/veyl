# 中英双语回归手册（i18n 批次 5）

> 对应 `docs/design/i18n.md` §5 的 8 条验收，加上本批新增的错误码、状态行、工具卡与缺失 key 回退。
> 构建与真机由用户执行；本手册只列走查步骤与判据，不替代自动化测试。
> 结果记在最后一节的表里：每条填「中 / 英 / 通过与否 / 备注」。

## 0. 准备

- 构建并启动：`bash scripts/dev/tun-dev.sh`（签名后装到 `/Applications`，不要在仓库里裸跑 `tauri dev`）。
- 两个语言各准备一遍：设置 › 高级 › 语言（第一行）切到「English」/「中文」，**不重启**观察切换，再重启观察持久化。
- 需要能创建一套配置、连一次 Proxy 或 Tun、新开一个 AI 会话；测试账号与节点由执行者准备。
- 观察日志：开发构建下看终端与 `~/Library/Application Support/…/logs/`；`i18n missing key=… lang=…` 只会出现在开发构建的控制台。

## 1. 语言切换与持久化（§5-1、§5-7）

| # | 步骤 | 中文界面 | 英文界面 |
|---|---|---|---|
| 1.1 | 设置 › 高级 › 语言（第一行）选「English」 | — | 整棵界面立即变英文，**不需要重启** |
| 1.2 | 不重启，逐页浏览：引导页、控制台、配置列表、节点组、我的服务器、设置、右栏 AI | — | 无中文残留（专有名词 Veyl / DeepSeek / sing-box / Proxy / Tun 允许） |
| 1.3 | 退出并重启 | 仍是中文 | 仍是 English |
| 1.4 | 选「跟随系统」，把系统语言改成英文，重启 | 界面变英文 | — |
| 1.5 | 选「跟随系统」，系统语言改成中文，重启 | — | 界面变中文 |

## 2. 首启与系统语言（§5-7）

| # | 步骤 | 判据 |
|---|---|---|
| 2.1 | 新装（或清掉应用数据）后首次启动，系统语言为中文 | 默认「跟随系统」，界面中文 |
| 2.2 | 同上，系统语言为英文 | 界面英文 |
| 2.3 | 同上，系统语言为日文等非 zh/en | 界面用 **English**（不是中文） |

## 3. AI 会话语言（§5-2、§5-3）

| # | 步骤 | 判据 |
|---|---|---|
| 3.1 | 英文界面新开一个会话，问「我现在是什么配置？」 | 回复英文；思考过程英文；状态行英文；工具卡英文 |
| 3.2 | 同会话让它解释一个设置 | 解释英文；按钮字串「Explain what this setting means」能被 AI 识别 |
| 3.3 | 中文界面新开会话重复 3.1 / 3.2 | 全部中文；按钮「解释这个设置的含义」能被识别 |

## 3A. 老会话语言不变（§5-8，单独一节）

| # | 步骤 | 判据 |
|---|---|---|
| 3A.1 | 中文下开一个会话聊两句 → 切到 English → 回到**旧会话**继续问 | 旧会话的回复、状态行、工具卡仍是中文；系统提示词不换 |
| 3A.2 | 同一时刻**新开**一个会话 | 新会话是英文 |
| 3A.3 | 英文下同理反向（旧会话英文、新会话中文） | 对称成立 |
| 3A.4 | 重启应用后再打开旧会话 | 语言跟随该会话创建时的语言，不跟随当前设置 |

## 4. 切换不影响业务状态（§5-4）

切语言前后分别记录并比对：

- [ ] 登录状态与账户菜单一致，不需要重新登录
- [ ] 正在进行的连接不断开，接管方式（Proxy / Tun）不变
- [ ] 已创建的服务器列表与详情一致
- [ ] 节点池、当前节点、延迟数值一致
- [ ] 正在进行的 AI 请求不中断（语言切换不打断流式输出）

## 5. 无中英混杂（§5-5）

两个语言下逐块检查，任何一块出现另一种语言即记缺陷（专有名词除外）：

- [ ] 引导页三入口（AI Key / Google 登录 / 不用 AI）
- [ ] 控制台主按钮、状态条、连接/断开、失败提示
- [ ] 配置列表与配置详情（含接管方式、分流、节点）
- [ ] 节点组列表与详情（含测速三态、添加节点、导入）
- [ ] 我的服务器列表/详情/向导/充值/登录
- [ ] 设置各页（通用、连接、账户、高级、折叠区）
- [ ] 账户菜单与退出确认
- [ ] 全部确认卡（退出、删除、切换接管方式、断线切换、装包授权、危险操作）
- [ ] 右栏 AI：会话标题、空态、输入框、停止、错误条
- [ ] 工具卡（完成 / 失败 / 事实 / 动作按钮）
- [ ] 运行时失败与后台组件提示
- [ ] 问题报告入口与动作按钮

## 6. 缺失 key 回退（§5-6）

- [ ] 开发构建下走一遍主流程，控制台搜 `i18n missing key`：应为 0 条。
- [ ] 临时验证（只在本地临时构建里做，**不要提交**）：删掉一条正在用的 key，确认英文界面回退到中文原句且布局不裂，日志出现 `i18n missing key=… lang=…`；验证后立刻恢复。（中文缺 key 时实现返回空串，正常由结构测试拦截，不作为走查项。）
- [ ] 回退后不出现 `undefined`、`[object Object]`、或整块消失。

## 7. 错误码文案（Q4，本批新增）

每个场景分别在两种语言下触发，判据：**界面只出现对应语言的句子，不出现后端中文、`message` 原文、错误码**（技术详情折叠区里的 `errorCode` 允许）。按四组走，每组做完勾一次。

### 7.1 设置与 AI

| 场景 | 触发方式 | 中文应显示（语义） | 英文应显示（语义） |
|---|---|---|---|
| AI Key 无效 | 设置 › AI 填错 DeepSeek Key | 密钥无效，检查后重试 | key invalid |
| AI 未配置 | 点连接页「问 AI」或建机向导「让 AI 帮我选」（未配置时右栏没有输入框） | 全局告警 +「去配置」，跳到设置 › AI | global warning + configure, opens Settings › AI |
| 模型名/地址不合法 | 设置 › AI 留空或填错 | 对应字段的参数提示 | field-specific copy |
| 请求繁忙 | 上一条未回完再发 | 等这条回完再发 | wait for the current reply |
| 令牌超限 | 触发一次超预算请求 | 带金额与上限 | with cost and limit |
| 钥匙串失败 | 模拟本地密钥存储失败（如只读目录） | 本地密钥存储操作没成功 | key store operation failed |

### 7.2 登录与账号

| 场景 | 触发方式 | 中文应显示（语义） | 英文应显示（语义） |
|---|---|---|---|
| 验证码错误 | 登录填错验证码 | 带剩余次数 | with attempts left |
| 验证码过期 | 等验证码过期再提交 | 过期，重新获取 | expired, request again |
| 发送过于频繁 | 连续点发送验证码 | 带冷却秒数 | with cooldown seconds |
| 设备被撤销 / 账号停用 | 用被撤销设备登录 | 明确的账号状态句 | account-state copy |
| 未登录 | 未登录打开我的服务器 | 先登录 | sign in first |

### 7.3 建机与服务器

| 场景 | 触发方式 | 中文应显示（语义） | 英文应显示（语义） |
|---|---|---|---|
| 余额不足 | 余额不足时下单 | 带所需金额与最少天数 | required amount and min days |
| 该地区无此档位 | 选一个不可用组合 | 换个地区或档位 | pick another |
| 服务器已不存在 | 两台设备同时操作同一台 | 已不存在，刷新列表 | gone, refresh |
| 建机失败 | 故意让安装失败 | 阶段相关的失败句 | stage-specific copy |
| 服务器忙碌 | 建机中重复操作 | 稍后再试 | try again shortly |
| 服务器同步进行中 | 同步中再点同步 | 正在同步 | sync in progress |

### 7.4 配置与节点同步

| 场景 | 触发方式 | 中文应显示（语义） | 英文应显示（语义） |
|---|---|---|---|
| 订阅地址非 https | 导入节点填 http 地址 | 订阅地址必须是 https | must use https |
| 订阅拉取失败 | 断网导入 URL | 没拉到订阅内容 | couldn't fetch |
| 导入内容无节点 | 粘贴一段普通文本 | 内容里没有可用的节点 | no usable nodes |
| 配置名重复 | 新建两个同名配置 | 名字重复了 | name taken |
| 节点不在这套配置 | 对已删除节点操作 | 节点不在这套配置里 | not in this config |
| 节点凭据过期 | 节点同步后凭据失效 | 重新同步后再试 | sync again and retry |
| 同步失败 | 单台凭据拉取失败 | 该台失败、其余不受影响 | one failed, others continue |
| 全部流量未授权 | 未允许后台助手就点 Tun 连接 | 允许后台助手后再连 | allow the helper |
| 开发版接管受限 | 开发构建点 Tun 接管 | 用 `bash scripts/dev/tun-dev.sh` 启动 | same with the command |
| 后台组件忙 | 连续快速连接/切换 | 后台组件正在忙，稍后再试 | busy, try again |
| 网络/超时 | 断网点连接 | 网络或超时提示，不是空白 | network/timeout copy |

验收点：
- [ ] 四组都走完，中英文语义一致，不出现两套说法
- [ ] 英文界面无 CJK 字符（技术详情里的代码除外）
- [ ] 失败时不会出现空错误条（B1 已修 chat 的空白问题）
- [ ] 同步失败时其余服务器照常显示，不整块清空

## 8. AI 状态行与工具卡（B1/B2 新增）

| # | 场景 | 判据 |
|---|---|---|
| 8.1 | 发一条需要思考的消息 | 状态行「正在思考 / Thinking」 |
| 8.2 | 流式回复中 | 「正在回复 / Replying」 |
| 8.3 | 模型调用工具时 | 「正在处理… / Working…」；**不出现工具名**（如 RuntimeStatus） |
| 8.4 | 上游重试 | 「上游临时波动，N 秒后重试（1/3）…」英文对应；数字正确；**不出现上游英文诊断串** |
| 8.5 | 回复过长被截断 | 「回复达到长度上限，已截断 / cut off」 |
| 8.6 | 上下文压缩 | 出现「上下文已压缩」通知，不是后端原句 |
| 8.7 | 工具成功 | 卡片显示该工具的完成句（来自前端表），不显示后端 `display.text` |
| 8.8 | 工具失败 | 显示失败句与技术 `errorCode`，正文不出现后端中文 |
| 8.9 | 会改设置的工具（连接/修复/升级/删除配置） | `changed` 三态文案正确，且**不出现「网络」二字** |
| 8.10 | 旧事件回放（缺 `text_key`） | 按 `phase` 兜底，不空白 |

## 9. 运行时失败（既有映射）

- [ ] 故意让后台组件启动失败：界面显示按 `RUNTIME_*` 查表的中/英文案
- [ ] 不渲染 `last_error.message`（排障文本只进日志）
- [ ] 失败后重试按钮文案与状态一致

## 10. 已知缺口（本手册不判失败）

- 问题报告产出的文件名与标题仍是中文（报告内容随会话语言）。
- 连接页探测 tooltip 仍读 `probe.error.message`；后端清空后可能显示空 title。
- `runtime_status` / `chat_history` 仍返回字符串错误，界面走 `errorText` 兜底。
- `app_language_*` / `server_sync_interval_*` 的 `INTERNAL` 无 `details.reason`，走调用点兜底。

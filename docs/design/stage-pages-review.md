# 页面评审：已连接舞台与新建节点（2026-11-17）

> 依据截图 17–20（已连接 · 新建节点，右栏展开 / 收起各一组），对照 `veyl-ui`、`ui-ux-pro-max` §5 Layout / §9 Navigation、`ai-first-product.md` §主界面 / §新建节点、`my-servers.md` §7.2。
> 只出清单，不改代码。测速入口正在实现（卡片副行右端文字链接），不计入缺失。
> 结论分三类：**必须改**（P1）、**建议改**（P2）、**不改**（附理由）。

---

## 0. 先纠正一个前提

截图 18 / 20 的「新建节点」**不是 client 舞台**，而是 `MyServersPage` 在没有选中服务器时渲染的向导（`MyServersPage.tsx:98`）。所以它带着「我的服务器」左栏、导航高亮「我的服务器」、**没有 `返回`**（这个分支没传 `onBack`；`MyServerWizard.tsx:431` 只有传了才渲染）。

client 舞台里还有一份同样的向导（`App.tsx:2144`），那份**有 `返回`**、没有左栏。同一个页面因此有两套外壳——这是下面几项的共同根因。

---

## 1. 必须改（P1）

### 1.1 创建流程只留一个宿主：client 舞台

| 项 | 现状 | 改为 |
|---|---|---|
| 宿主 | servers destination 的向导（带服务器左栏、无返回）+ client 舞台的向导（无左栏、有返回） | **只保留 client 舞台这一份** |
| 「我的服务器」左栏 `＋` | 进入 servers 向导 | 切到 client 舞台并打开新建节点；`返回` 回到进入前的 servers 列表（记 origin） |
| servers destination | 删除无返回的向导分支 | 永远只显示服务器列表 / 详情 |

理由：

1. 无节点用户的下一步是「建一台」，此时左栏写着「我的服务器 0 · 登录后查看你的服务器」，与主区的「新建节点」不是同一个语境；一屏两个任务。
2. 这个分支没有 `返回`，用户只能点导航离开，等于把「取消创建」藏起来。
3. 两个入口两套外壳，同一个页面要维护两份间距与返回规则。

**若实现成本过高，退而求其次**（同批必须做）：保留 servers 宿主，但
- `MyServersPage` 给向导传 `onBack` → 回服务器列表；`Esc` 同效；
- 左栏副标题改 `我的服务器`（见 2.1）；
- 左栏空态在未登录时仍只写 `登录后查看你的服务器`，已登录零台写 `还没有服务器`。

### 1.2 创建按钮的重量

- 现状：`.btn` 基类 **32 高**（`app.css:1049`），`创建` 是这一页唯一主按钮，却比连接舞台的 48 矮一截，也比 `veyl-ui` 的 44 标准小。
- 改为：**高 44、最小宽 96、内边距 0 20、15/500**；与连接舞台的主按钮同一重量。
- 底栏改为 **sticky**：`position: sticky; bottom: 0; background: var(--canvas); padding: 12px 0 16px; border-top: 1px solid var(--hair)`。现在底栏随内容滚走（截图 18 里完全看不到 `创建`），用户在选完地区/规格后必须再滚到底才能提交。

### 1.3 价格只留一处

- 现状：档位卡 `每天 $0.30 · 每月 1000 GB 流量`；底栏 `每天 $0.30 · 约 $9/月`。同一个每日价出现两次。
- 改为：**卡片保留每日价**（它是三档之间唯一的对比轴）；**底栏去掉每日价，写成 `标准 · 约 $9/月`**（档位名 + 月估算）。下面的扣费说明不变：`从余额扣一天；之后每天续扣，余额不足会提示充值。`
- 结果：`每天 $0.30` 只在卡片出现；底栏只出现一个新数字（月估算），不是重复。

### 1.4 流量文案不折行

- 现状：`每天 $0.30 · 每月 500 GB 流量` 在 176–200px 的卡片里折成两行，第二行只剩一个「量」。
- 改为：档位卡副行拆成两段、各自不折行：
  - 第一行 `每天 $0.30`（15/`--ink`，价格）；
  - 第二行 `每月 500 GB`（12/`--ink-3`，去掉「流量」两字）。
  - `.wizard-plan` 用 `display:grid; grid-template-rows: auto auto auto 1fr auto`，三张卡等高；副行 `white-space: nowrap`。
- 不缩短成 `$0.30/天`：中文界面里 `每天 $0.30` 更好读，且与底栏的 `约 $9/月` 成对。

### 1.5 助手收起 tab 的命中区

- 现状：只有 36×36 的图标是按钮（`AssistantTab.tsx:17-36`），竖排「助手」在按钮**外面**（`AssistantTab.tsx:38`），点文字没反应；36 也低于 44。
- 改为：**整个 56px 宽的 tab 就是一个按钮**（图标 + 竖排文字同属一个 `<button>`），命中区 56×约 88；去掉图标外面那圈 36×36 描边方块（现在看起来像有两个控件）。
- 图标 18 / `--ink-2`，文字 11 / `--ink-3`（对比度约 5:1，合格）；未读点 6px `--focus` 绝对定位在图标右上，**已有**，保留。
- `aria-label` 用 `展开助手` / `展开助手，有新消息`；`focus-visible` 用 `--focus` 描边。

### 1.6 预制问题不要越界到新建节点

- 现状：截图 18 / 20 的右栏在建机页仍显示那五条连接类问题（`连上了，但网页打不开`…），与当前任务无关。
- 改为：五条只在 `screen === "client"`（无节点时 `no_nodes`）出现；`new_node`、`servers`、`settings`、`trial_expired` 不显示。建机页若要有引导，用与建机相关的 2–3 条（另议），不与这套混用。
- 这条要同步改 `docs/design/assistant-empty-state.md` 的展示条件（本轮只记录，不改那份文档）。

## 2. 建议改（P2）

### 2.1 服务器左栏的品牌副标题

- 现状：`Veyl` + `网络控制台`（`MyServersRail.tsx` 的 `rail__brand`）。`网络控制台` 是 client 的副标题，放在「我的服务器」下名不副实。
- 改为：只留 `Veyl`；或副标题为 `我的服务器`。推荐只留 `Veyl`——下面一行已经有 `我的服务器 0`，副标题是重复。

### 2.2 新建节点舞台的版心

- 现状：在 1200+ 窗口里内容铺满约 1000px，三张档位卡横跨整屏；连接舞台是 400 居中。两个舞台的阅读宽度差 2.5 倍。
- 改为：给向导列 `max-width: 640px; margin: 0 auto`；三张卡在 640 内各约 200，配合 1.4 的两行副行正好。连接舞台保持 400。

### 2.3 系统行

- 现状：`系统 / Ubuntu 24.04 LTS`，值 14 / `--ink`，与其他事实行同权，看起来像一个可选项。
- **保留**：`my-servers.md` §7.2 已明确这是一行只读事实、不可选（安装脚本只支持这一个系统）。
- 改为：值 13 / `--ink-2`，不加 hover、不加 chevron、不做按钮；与 `服务器类型` 的 12px 标签形成「标签小、值中」的层级，不与底部价格抢。

### 2.4 已连接舞台的摘要行

- 现状：`已加入 2 个免费节点，最快 238ms` 与选中行的 `238 毫秒` 是同一个事实；`报告问题` 直接贴在同一句末尾，没有分隔（截图里像句子的一部分）。
- 改为：`报告问题` 前加 12px 间距或一个 `·`；摘要字号从 13 降到 12，作为收尾回执而不是读数。
- **不改内容**：`最快 Xms` 暂留——T2 验收断言了这句原文；测速入口落地后按 `connection-stage-probe.md` §5 去掉数字，届时再看是否整行收起。

### 2.5 右栏空态五条的可点感

- 现状：五条是 13 / `--ink-2` 的纯文字，44 高，hover 只变深，静止时与正文无法区分。
- 改为：hover / focus 时加下划线（其余不变）；不加底色、不加图标，保持空态的安静。

## 3. 不改（附理由）

| 项 | 结论 |
|---|---|
| 系统行是否可点 | **不可点**。`my-servers.md` §7.2：安装脚本只支持 Ubuntu 24.04，不给装不上的选项；`docs/requirements.md` 也只承诺 22.04/24.04 镜像。只做展示。 |
| 区域 chip 32 高、6px 圆角 | 保留。这是桌面表单的紧凑控件，不是主操作；`veyl-ui` 的 44 只约束主按钮与主要命中区，加高会把地区分组拉得很长。 |
| 已连接时「断开」保持实心黑块 | 本轮不改。产品与原型（`free-nodes-ready.html`）都这么定；若以后要改，应与「连接」同批改，不单独动。 |
| 摘要整句删除 | 不改。T2 断言 `已加入 2 个免费节点，最快 XXms`；测速落地后只去掉数字，不整句删。 |
| 未读点 | 已有（`AssistantTab.tsx:37`），不需要新增；只按 1.5 改成 tab 内的绝对定位。 |
| 舞台垂直居中、状态带 20 间距 | 不改。当前节奏与 `free-nodes-ready.html` 一致（44 带 + 20 卡距 + 12 按钮距 + 12 说明距）。 |

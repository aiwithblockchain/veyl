## 0. 一句话

左下角账号图标不再弹浮层：未登录去登录，已登录直接进 `设置 › 账户`；账户页去掉「在其它设备上使用」，新增「退出登录」和「近 30 天账单」，账单用弹层展示。

## 1. 现状

- 点击 activity bar 底部的头像 → 弹出小浮层：邮箱、余额、充值、退出登录。
- `设置 › 账户`：邮箱、余额（刷新 / 充值）、「在其它设备上使用 → 查看」。
- 结果：退出登录有两个入口，余额在两处重复，头像浮层和设置页各说一半。

## 2. 目标

### 2.1 左下角账号图标

| 状态 | 点击行为 |
|---|---|
| 未登录 | 打开现有登录流程 |
| 已登录 | 打开 `设置 › 账户` |

- **不再有头像浮层**，对应组件与只服务于它的文案一起删除。
- 未登录时的图标不加角标、不加红点。

### 2.2 设置 › 账户（从上到下）

1. 邮箱
2. 余额 + `刷新` + `充值`（维持现状）
3. **近 30 天账单**（新增，次按钮，打开弹层）
4. **退出登录**（新增，`danger-ghost`，放最底部）

删除：「在其它设备上使用 → 查看」整行。

> 不丢功能：左栏「我的服务器」在**已登录且至少一台节点就绪**时，会在「新建节点」下方出现同一个入口（`MyServersRail.tsx`）。设置里这一行是重复的，删掉即可。

### 2.3 近 30 天账单（弹层）

**为什么用弹层**：设置右栏是「一条条设置」的列表，塞 30 行报表会把设置页变成数据页；弹层可以独立控制宽度、滚动和关闭方式，也不影响设置页的布局。

- 形式：居中弹层，宽约 560，最大高度约视口 70%，内部滚动；表头固定。
- 每行：日期、机器费、流量超支、当日合计；最近一天在最上。
- 底部：30 天合计。
- 不出现：DO 成本、单价、周期说明、机器规格。
- 状态：加载中（占位行）、空（「最近 30 天没有消费」）、失败（发生了什么 → 为什么 → 重试）。
- 关闭：右上 `×` 与 `Esc`；关闭后焦点回到触发按钮。

---

## 3. 数据口径

- 数据来自钱包流水（`wallet_ledger`）与各机器的流量超支扣费，**按天归集**；30 天会横跨两个计费周期，不能只读当前周期。
- 机器费 = 当日各机器的按天扣费之和；流量超支 = 当日扣的超支合计；合计 = 两者相加。
- 单位：金额与余额一致（美元，两位小数）；流量列用 GB。
- 日界：默认按**本地日期**归集（用户看的是自己的日子），弹层脚注注明「按本地时间统计；计费周期按 UTC 月」。若产品要求与周期严格同源，改成 UTC——见 §5。

## 4. 与其它界面的关系

- 头像浮层删除后，`充值` 仍在账户页；未登录用户点头像进登录。
- 退出登录只保留设置页一个入口，失败文案沿用现有 `account.logoutFailed`。
- 手机端导出的入口问题见 §5，未定之前**不要先删那一行**。

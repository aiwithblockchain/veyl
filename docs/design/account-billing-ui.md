# 账户入口与近 30 天账单（界面重构需求）

> 日期：2026-11-26
> 状态：**已实现（2026-11-26 重做）**。**视觉以 `prototype/account-surface-v2.html` 为准**——下文凡是与其冲突的版式描述都已过时，以原型为准。数据口径（类别映射、`totals`、时间窗、保留期）仍然有效。
> 关联：`traffic-billing.md` §8.1（账单数据来源）、`servers-list-detail.md`（事实区版式）

> **2026-11-26 重做要点（覆盖下文旧描述）**
> - **层级**：余额 34px/600 mono 是唯一焦点，其余全部后退；全页只有两条 hair。详见 `veyl-ui` §3.2 的显示级字号。
> - **顺序**：邮箱 → 余额（+ 充值按钮）→ 本月流量 → 近 30 天账单（折叠）→ footer（邮箱与退出登录同一行）。旧文写的「邮箱第一行、余额 20 mono」已作废。
> - **充值**：默认折叠，点按钮用 `grid-template-rows: 0fr→1fr` 160ms 展开；档位是 3 列方块（`$6 $10 $25 $50 $100 其他`），不再是「5 档常驻 + 自定义输入框」。
> - **付款后就地等（2026-11-26 改）**：打开收银台后账户弹层**不关**，档位整块换成等待态（标题 + 金额 + 说明 + 「重新打开收付款页 / 改金额」）；余额一变大就换成「● 已到账 $X · 余额 $Y」，不自动收起；收起再展开回到选择态。展开充值后「收起」降为描边，实心按钮让位给自定义金额提交。
> - **账单**：折叠时**不显示任何数字、也不发请求**，点「明细」才加载并展开；表格三列（类别 / 日期 / 金额），机器名挂在类别下。
> - **「每天约 $X · N 台服务器」**：这是账号级汇总，不是「约可运行 N 天」那种除法预测（后者已被撤掉），口径见 `login-and-payment.md`。

## 0. 一句话

左下角账号图标不再弹浮层：未登录去登录，已登录直接打开**账户弹层**（不再是设置的一段）；账户弹层去掉「在其它设备上使用」，含「退出登录」和「近 30 天账单」，充值与账单都就地铺在这一层。

## 2. 目标

### 2.1 左下角账号图标

| 状态 | 点击行为 |
|---|---|
| 未登录 | 打开现有登录流程 |
| 已登录 | 打开账户弹层 |

- **不再有头像浮层**，对应组件与只服务于它的文案一起删除。
- 未登录时的图标不加角标、不加红点。

### 2.2 账户弹层（从上到下）

账户独立成一层弹层（宽约 720，`max-height: min(86vh, 780px)`）；header 与 footer 固定，只有中间的 body 滚动（单层单滚动）。设置弹层只剩 AI / 连接 / 高级，不再有「账户」段。

1. 余额（**34px/600 mono，显示级**）+ 右上「充值」按钮（**默认折叠，点击展开档位**）
2. **本月流量**：`本月流量额度 Y GiB · 已用 X GiB` + 6px 通栏进度条 + `明天再涨 X GiB`；接近 80% 时琥珀
3. **近 30 天账单**：默认折叠，**折叠时不显示数字也不请求**，点「明细」才加载并展开
4. footer：左 `邮箱 · 复制`，右「退出登录」文字按钮

旧版的「邮箱第一行 / 余额 20 mono / 充值常驻 5 档」已作废，见顶部重做要点。

删除：「在其它设备上使用 → 查看」整行。

> 不丢功能：左栏「我的服务器」在**已登录且至少一台节点就绪**时，会在「新建节点」下方出现同一个入口（`MyServersRail.tsx`）。这一行是重复的，账户里不再保留。

### 2.3 近 30 天账单（账户弹层内就地）

**为什么就地**：账户弹层已经是 720 宽的独立一层，账单直接铺在充值块下面即可；再叠一个弹层会变成两层窗口，用户从付款页回来时不知道该先关哪层。

- 位置：充值块下方，默认折叠成一行摘要；展开后表格直接铺在正文里，**只有账户 body 一个滚动容器**，表头 sticky（不透明背景），不再有表体自己的限高滚动或横向滚动。
- 折叠行内容：**只有 `近 30 天账单` + `明细` + 箭头**，**不给任何数字、也不发请求**（整行是 `<button aria-expanded>`）。展开后才加载并显示 `充值 $120.00 · 扣费 $2.94`。2026-11-26 改：折叠时既不请求也不显示合计，打开账户弹层因此只有一个请求。
- 状态：读取中只给一行「读取中…」（`role=status`，不可展开）；失败给一行短错误 + 独立的 `重试` 按钮（不能嵌在切换按钮里）；空数据只写摘要 +「最近 30 天没有消费」，不给箭头、不是按钮。
- 行数分批：初始 40 行，底部「显示更多」每次 +100；点击后焦点落到新出现的第一行。接口 `truncated` 时底部保留「只显示最近 1000 笔」。
- 顶部一行汇总：`充值 $120.00 · 扣费 $2.94`（示例数字自洽：期初 $1.00 + 充值 $120.00 − 扣费 $2.94 = $118.06）。
- 每行三列：**类别（充值 / 机器费 / 流量超支 / 退款 / 其他）、日期、金额**；**机器名挂在类别下方当第二行小字**（2026-11-26 改：四列时充值行的机器格全空、右侧一大片白，看起来像渲染坏了）；按时间倒序，最近的在最上。
- 「其他」是兜底：映射不到上面四类的流水（人工调账、活动赠额）落在这里，只显示类别，**不丢行**。
- 机器费、流量超支、退款这三类，行内补一句机器标识（截断名 + 机型 / 地区）；同一天多台机器各占一行。
- 底部不再放「30 天合计」——摘要已经给了充值 / 扣费两个合计。
- 不出现：DO 成本、单价、周期说明。**「近 30 天」是滚动窗口，不是计费周期**（计费周期是 UTC 自然月），这里不写周期，免得用户把两者当成一回事。
- 不再单独弹层：`Esc` 与遮罩只关账户弹层本身。

## 3. 数据口径

- 数据只来自钱包流水 `wallet_ledger`，**不做按天归集**：一行就是一笔流水。
- 类别映射（`ref_type`）：`stripe_payment` / `dodo_payment` → 充值；**`order` 与 `server_day` 都 → 机器费**（`order` 是第 0 天的扣费，漏了它每台机器的第一天就不显示）；`server_traffic` → 流量超支；`server_refund` → 退款。查询显式排除 `ref_type = 'snapshot'`。
- 机器标识按 `ref_type` 分派：`server_day` / `server_traffic` / `server_refund` 从 `ref_id` 前缀取 server id；`order` 走 `orders.id → servers.order_id`。解析不出来就只显示类别，**不丢行**。
- 金额符号统一 **`$`**；日期取 `created_at`，本地日由客户端按 `Intl` 换算（D1 没有 `AT TIME ZONE`）。
- 机器名 join `servers`（已销毁的机器行在账单窗口内仍存在，能显示名字）；金额两位小数，与余额一致。
- 账本明细保留 ≥31 天（`traffic-billing.md` §7.4 已把裁剪边界夹到 `now − 31 天`），所以 30 天窗口永远完整；但仍要显式排除 `snapshot`——它的时间戳正好落在窗口边界上。

## 6. 验收

1. 未登录点左下角头像 → 登录流程；已登录 → 直接打开账户弹层。
2. 界面上不再出现头像浮层。
3. 账户弹层顺序为：余额（+ 充值按钮）→ 本月流量 → 近 30 天账单（默认折叠）→ footer 里的邮箱与退出登录；余额 34px 为全页唯一焦点，全页两条 hair。

5. 退出登录只此一处，成功后界面回到未登录状态。

# 任务：账户独立成一个界面（充值就地、账单就地、不再叠弹层）

> 日期：2026-11-26
> 状态：**已实现（2026-11-26）**，后经同日晚一轮版式重做（余额 34px 唯一焦点、充值默认折叠、账单懒加载）。视觉基准是 `prototype/account-surface-v2.html`，本文保留为实现前定的目标与边界。
> 上游：`account-billing-ui.md`（账单形态与口径）、`traffic-billing.md` §8.1（接口）、`.claude/skills/veyl-ui`（界面规范）

---

## 0. 一句话

把「账户」从设置弹层里的一个段落拿出来，做成独立的一个界面：余额、充值、账单、退出登录都在这一屏；充值和账单**不再各自叠一层弹窗**。

---

## 1. 为什么

现在点左下角头像 → 设置弹层（640）→ 账户段 → 再点「充值」或「查看账单」→ **第二个弹层叠在上面**。三个具体问题：

| 问题 | 现象 |
|---|---|
| 层级越叠越深 | 设置是一层、充值/账单是第二层。用户在付款页回来时，桌面中央堆着两层窗，先关哪个都不直观。 |
| 付款后窗还在，而且点不动 | `MyServerTopUp.tsx:98-105`：拿到 `checkout_url` 后 `setWaiting(true)`，金额格与自定义提交被 `disabled`（`:203`、`:228`、`:240`），只留一个「刷新」。用户困惑「我是不是点错了」。 |
| 空间不够 | 账单表被压在 560 宽里，机器标识只能折到第二行，每行都变成两行高；720 宽可以一行放完类别 / 机器 / 日期 / 金额。 |

---

## 2. 现状（代码事实）

| 事实 | 位置 |

| 充值成功后打开外部浏览器，弹层保留并置灰金额格 | `src/components/MyServerTopUp.tsx:96-105`、`:203/:228/:240` |
| 账单弹层是设置弹层的兄弟节点，`modal-backdrop--nested` | `src/components/BillingLedgerDialog.tsx`、`Settings.tsx:3209` 附近 |

**结论**：入口其实不深（头像一下就到了），深的是**结构**——账户是"设置的一个段落"，所以它的子动作只能往上叠。

---

## 3. 目标

### 3.1 结构：账户成为一个独立弹层，不是第四个 destination

- activity bar **仍然只有三个 destination**（客户端 / 节点组 / 我的服务器）。左下角头像改成打开「账户」弹层，不再是 `openSettings("account")`。
- 设置弹层只剩 **AI / 连接 / 高级** 三段；账户段整个移出。
- 账户弹层宽约 **720**，`max-height: min(86vh, 780px)`，**单层、单滚动**，内部不再有任何子弹层。

理由（写给实现者，避免改方向）：账户没有列表可放进左栏，做成 destination 会得到一个空左栏，且账户是低频短任务，不值得常驻第四个图标。

### 3.2 账户弹层的内容（从上到下，一屏）

```
邮箱        buyer@example.com                        复制
余额        $46.80                                    刷新
充值        [$6] [$10] [$25] [$50] [$100]
            [自定义 ______]  [充值]
最近 30 天  充值 $120.00 · 扣费 $2.94                    明细 ▸
退出登录                                              （footer 固定，danger-ghost）
```

- header 与 footer 固定，只有中间的 body 滚动；退出登录不随正文滚走。
- 账单默认折叠：点「明细」展开四列表格，展开后仍只有 body 一个滚动容器，表头 sticky；行数初始 40，「显示更多」每次 +100。

- 未登录：只显示登录入口，不显示余额/充值/账单/退出登录（与现在 `blockedIdentity` 的口径一致）。
- 身份异常（`identityProblem`）：沿用现在的提示与「重新验证 / 切换账号」动作。
- 账单为**空**时仍显示顶部汇总，表体给一句「最近 30 天没有消费」。
- 账单超过 1000 笔时底部一行「只显示最近 1000 笔」。

### 3.3 充值：就地展开，付款后**关掉面板**

- 金额格与自定义输入直接摊在账户弹层里，不再是第二个弹窗。
- **拿到 `checkout_url`、外部浏览器已打开后：立即关闭整个账户弹层**，并给一条 toast：
  `已在浏览器打开收付款页。付款完成后余额会自动更新。`
  - **不要**保留面板、**不要**把金额格置灰。用户回来看到的应该是干净的桌面，而不是一个点不动的窗。
  - 关闭后余额刷新：App 窗口重新获得焦点时刷新一次（`window` 的 `focus` 事件 + 现有 `refreshWallet({ force: true })`）；手动「刷新」作为兜底。
- 余额已经到账（接口直接返回余额，没有 `checkout_url`）时走原路径：留在面板里给 `topup.charged` 提示并刷新余额。
- 打开收银台失败（错误信封里带 `checkout_url`）时保持现状：面板不关，给错误 + 「在浏览器中打开」的兜底链接。
- 另外两个入口（建机向导余额不足、我的服务器页）改成打开**同一个账户弹层**并把滚动位置落到充值区；关闭后回到原页面。

### 3.4 设置

- 设置弹层删除账户段，删除相关状态（`billsOpen`、`billsTriggerRef`、`returnBillsFocusRef`、`trapPaused` 里的 `topupOpen` 依赖）。
- 设置里若仍有指向账户的入口（例如「去充值」），改成打开账户弹层。
- 设置宽度仍是 640，不改。

---

## 4. 必须遵守的交互规则

1. **任何时候屏幕上只有一层弹层**。不允许 `modal-backdrop--nested` 再出现在账户路径上。
2. **付款后关面板**，不是禁用控件。置灰但留着是这次要修的核心问题。
3. `Esc` 关闭账户弹层；关闭后焦点回到打开它的按钮（头像，或建机向导里的「去充值」）。
4. 焦点陷阱只挂一层：账户弹层打开时，设置/向导的陷阱暂停。
5. 金额符号与文案口径不变：`$`、两位小数、`+`/`−`（账单行）；账户内不出现「周期」字样（`traffic-billing.md` §8.1）。

## 6. 验收

1. 点左下角头像 → 直接出现账户弹层（不是设置弹层）；设置里已没有「账户」这一段。
2. 账户弹层里能看到邮箱、余额、充值金额格、最近 30 天账单、退出登录；**全屏只有一层弹层**。
3. 选 `$25` → 点充值 → 外部浏览器打开收银台 → **Veyl 的账户弹层立即关闭**，桌面无残留弹窗，出现 toast；回到 App 时余额自动刷新一次。
4. 同上，但在付款页直接关掉浏览器回来：余额不变，头像点开可以再充，没有卡住的灰按钮。
5. 打开收银台失败（模拟 `checkout_unavailable`）：面板不关，给错误原因与「在浏览器中打开」链接。
6. 建机向导里余额不足 → 点「去充值」→ 打开账户弹层并落在充值区；关掉后回到向导，选择不丢。
7. 账单：默认折叠成一行摘要（不带余额），点「明细」展开；合计只用接口 `totals`；展开后整屏仍只有一个滚动条；`Esc` 关闭后焦点回到头像。
8. 未登录、身份异常、账单为空、账单截断四种状态各自正确。
9. 中英文两种语言下，720 宽内四列（类别 / 机器 / 日期 / 金额）不折行、不横向滚动。

## 7. 非目标

- 不新增 activity bar 的第四个 destination。
- 不做设备管理、发票、支付方式管理。
- 不改控制面接口与 `commands.md` 契约（`GET /v1/billing/ledger`、`my_server_billing_ledger` 保持原样）。
- 不改 `MyServerTopUp` 的金额校验规则（$6–$300、整美元）。

---

## 8. 风险与取舍

- **`topupOpen` 语义变更**：现在它同时被建机向导、我的服务器页、设置三处使用。改成"打开账户弹层的充值区"后，这三处的返回路径要逐个验，尤其向导——关闭后必须回到向导且保留选择。
- **付款后自动刷新**要靠窗口获得焦点触发。若用户在浏览器里付款后不切回 App，余额不会自己变——这是可接受的，因为下次切回来就会刷。
- 移除 `.modal--bills` / 嵌套层后，`BillingLedgerDialog` 那份焦点与叠层逻辑（含 `useFocusTrap(…, false)`、`returnBillsFocusRef`）一并删掉，别再留两套。
- 文档要同步：`account-billing-ui.md` §2.2/§2.3 的"设置 › 账户"改成"账户弹层"；`.claude/skills/veyl-ui` §2.2 的"唯一住处"表把"余额/充值/账单"的住处改成账户弹层。

# Veyl 主界面重塑方案（第一步）

> 日期：2026-11-05
> 状态：待产品负责人确认；确认前不改 `src/`
> 原型：`docs/design/prototype/index.html`

---

## 0. 一句话方向

**把主界面做成一台安静的高精度仪表：时间、流量、延迟是唯一读数，其余全部是余白。**

“高端”不靠装饰、渐变、玻璃或大圆角，靠三件事：**尺度、对齐、克制**。大号等宽数字给出精密感；所有内容共用一条左轴给出秩序感；一屏只允许一个视觉重心。

---

## 1. 三个关键取舍

### 1.1 删掉最左的 56px activity bar，改成三栏

现在的最左列只有一个图标，却占掉 56px 和一整条视觉边界。它的职能（“我在看哪个列表”）已经由左栏标题说清楚。

- **取舍**：三栏 = 配置栏 280 / 控制台弹性 / 助手 420。
- **代价**：失去未来放第二个导航图标的槽位。等真有第二个列表时，再以“左栏顶部标签”的形式加，而不是重新竖一条空列。

### 1.2 用大号计时器做视觉中心，而不是再画一条线路图

当前中间空、轴线断，是因为中间没有一个真正的“主对象”。我们把**已连接时长**放大到 64px 等宽数字，作为整个控制台的锚点；未连接时主对象换成 44px 的状态词。它同时解决三件事：

- 中间有了内容，不必靠堆卡片填满；
- 数字天然精密，符合“把全部流量交出去”的工具气质；
- 与原来的线路图相比，它携带的是用户真正会看的信息，不是装饰。

线路图不再出现。出口 IP、流量、延迟作为仪表读数排在计时器下方，各有唯一住处。

### 1.3 主按钮墨黑，但“已连接”时降为描边

闲置时，主按钮是唯一的实心墨块：“启动 VPN”。已连接时，状态本身已经是用户想要的结果，再把“断开”做成全屏最重的实心块，会让界面一直在催促用户破坏当前状态。

- **取舍**：实心权重只给“启动 / 重连”；“断开”降为 1px 描边 + 墨色文字，仍是该区域唯一的按钮。
- **不变量**：主界面任何时刻只有一个主操作，位置不变、文案随状态变。

## 2. 信息归属表（硬要求）

同一事实全屏只出现一次。下表是实现的唯一口径。

| 事实 | 唯一住处 | 旧界面里的重复 | 处理 |
|---|---|---|---|
| 连接状态（未连接 / 连接中 / 已连接 / 失败 / 不稳定） | 控制台 hero 的 H1（状态词；已连接时是「状态词 + 计时器」） | 顶部状态胶囊、底部节点卡“未连接”、旧 hero 的「连接状态 · X」小行 | 全部删掉；LED 只作装饰 |
| 已连接时长 | hero 大号计时器 | 顶部摘要 | 合并进 hero |
| 流量（总量 + 上下行） | hero 读数行「流量」 | 顶部摘要、底部节点卡「已用流量」 | 只留 hero |
| 延迟 | hero 读数行「延迟」 | 顶部摘要、底部节点卡「延迟」 | 只留 hero |
| 出口 IP | hero 读数行「出口」（可复制） | 顶部出口胶囊 | 只留 hero |
| 最近 60 秒速率 | 读数行下方的速率条 | 无 | 新增；与「流量总量」是两件事 |
| 当前节点名 | 底部节点卡标题 | 底部节点卡 + 旧中间提示 | 只留节点卡 |
| 服务器地址 / 端口 / 加密方式 | 底部节点卡的一行等宽事实 | 旧底部「技术详情」 | 收进节点卡，不再另开 |
| 配置列表 / 当前配置 | 左栏 | 左栏 + 中间 | 只留左栏 |
| 新建配置入口 | 左栏标题行右侧的 `+` | 左栏标题 `+`、左下「＋ 新建配置」 | 只留一个 |
| AI 对话 / 历史 | 右栏 | 右上角气泡按钮 | 面板常驻；关闭后是右边缘 tab |
| 失败原因 | 中间失败卡 | 无 | 新增唯一住处 |
| 失败后的三步自救 | 失败卡内的 01/02/03 | 无 | 新增；只指路，不放按钮 |
| 三级代理地址 | 中间代理卡 | 旧底部技术详情也有一份 | 只留中间卡 |
| 二级授权 | 系统弹窗 + 中间授权说明卡（仅首次） | 无 | 新增，授权后消失 |
| 启动 / 断开 / 重连 | hero 唯一主按钮 | 顶部 | 只留一处 |
| 换节点 / 检查连接 | 底部节点卡 | 旧底部 | 只留一处 |
| 设置 / 版本 / 日志 | 左栏底部「设置」；版本与日志在设置页 | 左栏 / 设置 | 不变 |
| AI 未读 | 助手标题右侧的点；面板收起时在边缘 tab 上 | 旧顶部气泡点 | 迁移 |

**AI 对话里不重复上述事实。** 助手可以问“需要我做什么”，但不再报一遍“已连接 / 28 毫秒 / 203.0.113.42”。

### 2.1 状态表达的唯一性（硬规则）

- **状态只由 H1 说一次。** 视觉上不再出现「连接状态 · 已连接」这类小行；读屏保留一个 `.sr-only` 的 `role="status" aria-live="polite"`，不占视觉空间。
- **一个状态只允许一句行动指引。** 未连接、连接中、已连接各一句；不再同时保留标题下的说明和事实区下的提示。
- **失败卡没有标题。** H1 说「连接失败」；H1 下的一行小字只负责区分「没连上 / 连接断了」，只此一处；卡片直接从原因开始，随后是三步自救。
- **无节点不重复。** H1 `未连接` + 一句原因「这套配置还没有节点。」；动作只在右侧助手，不在控制台再放一遍。

## 3. 设计 token

### 3.1 颜色

浅色为默认。深色本轮只留结构（变量同名反相），不交付完整深色。

| 角色 | 值 | 用途 |
|---|---|---|
| `--canvas` | `#EFEBE1` | 最外层底色、左栏 |
| `--paper` | `#FAF8F2` | 控制台纸面 |
| `--panel` | `#F6F2E9` | 助手栏 |
| `--card` | `#FFFFFF` | 节点卡、代理卡、失败卡 |
| `--ink` | `#171614` | 主文字、主按钮底 |
| `--ink-2` | `#5B5850` | 次要文字 |
| `--ink-3` | `#6E6A5F` | 标签、辅助说明（对纸面 ≥ 4.5:1） |
| `--hair` | `rgba(23,22,20,.10)` | 分隔线 |
| `--hair-strong` | `rgba(23,22,20,.18)` | 输入框、卡片描边 |
| `--cobalt` | `#1F46B8` | 选中、链接、焦点环 |
| `--cobalt-soft` | `rgba(31,70,184,.07)` | 选中底色 |
| `--green` | `#1B7A4E` | 已连接 |
| `--amber` | `#946200` | 降级 / 提醒 |
| `--red` | `#A8382D` | 失败 |

规则：

- 主按钮永远是 `--ink` 实心，不用彩色实心按钮。
- `--green / --amber / --red` 只出现在 LED、细左边线、状态词和少量图标上，不做大面积填充。
- 一屏最多两种彩色：已连接 = 绿 + 蓝（选中），降级 = 琥珀 + 蓝，失败 = 红 + 蓝。
- 不用渐变、玻璃、彩色阴影。

### 3.2 字体

离线硬约束：不加载外部字体、不引 CDN。

```css
--sans: -apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI",
        "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--mono: "SF Mono", ui-monospace, "Menlo", "Consolas", monospace;
```

| 用途 | 字号 / 行高 / 字重 | 字体 |
|---|---|---|
| 计时器 | 64 / 1.0 / 400，`-0.03em` | mono，tabular-nums |
| 状态词（未连接 / 连接失败） | 44 / 1.1 / 600，`-0.02em` | sans |
| 状态标签（已连接 / 不稳定） | 20 / 1.3 / 500 | sans |
| 区块标题（节点名） | 17 / 1.35 / 600 | sans |
| 卡片标题 | 20 / 1.3 / 600 | sans |
| 正文 / 读数 | 15 / 1.55 / 400 | sans |
| 读数数字 | 20 / 1.2 / 400 | mono，tabular-nums |
| 辅助 / 元信息 | 12 / 1.45 / 400 | sans |
| 标签（中文） | 11 / 1.3 / 500 | sans |
| 标签（英文） | 10.5 / 1.2 / 500，`+0.14em` | mono / sans |

标题行高 1.35，正文 1.65 的旧规则保留；新增的 64px 计时器与 44px 状态词是**显示级**，不进入正文阶梯。正文最小 12px。

### 3.3 间距

4px 网格：`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64`。

- 控制台左右内边距 40；上下 24–40。
- 左栏内边距 20。
- 助手里内边距 24。
- 区块之间 32–40；卡片内 20–24。
- 读数行上下 18。

### 3.4 圆角与阴影

| token | 值 | 用途 |
|---|---|---|
| `--r-xs` | 2px | LED、标签 |
| `--r-sm` | 6px | 按钮、输入框、配置行 |
| `--r-md` | 10px | 节点卡、代理卡、失败卡 |
| `--r-lg` | 14px | 浮层、弹窗 |

阴影只给两类东西：底部节点卡、浮层。

```css
--shadow-card: 0 1px 0 rgba(23,22,20,.03), 0 8px 24px rgba(23,22,20,.05);
--shadow-float: 0 18px 48px rgba(23,22,20,.14), 0 1px 2px rgba(23,22,20,.06);
```

### 3.5 层级

| 层 | 颜色 | 说明 |
|---|---|---|
| 桌面 | `--canvas` | 左栏与最外层 |
| 纸面 | `--paper` | 控制台 |
| 凹槽 | `--panel` | 助手栏，比纸面深半级 |
| 卡片 | `--card` | 白，1px `--hair-strong` 描边 |

层级靠明度与 1px 边，不靠投影。只有节点卡允许一层极浅阴影，让它“落在纸上”。

### 3.6 动效

- 状态切换：120ms opacity。
- 连接中：hero 下方一条 1px 不确定进度线，1.6s 循环；`prefers-reduced-motion` 下改为静态 30% 线。
- 浮层：160ms opacity + 4px 位移。
- 无其他动效；计时器每秒跳动是数据更新，不做动画。

## 4. 布局与响应式

### 4.1 三栏

```
┌──────────────┬──────────────────────────────┬──────────────────┐
│ 配置 280      │ 控制台                        │ 助手 420          │
│              │                              │                  │
│ Veyl         │ 状态 LED + 计时器       [断开] │ 助手   DeepSeek   │
│ 配置   3  +   │                              │ ───────────────  │
│ 家里          │ ───────────────────────────  │ 对话             │
│ 公司          │ 流量   1.24 GB               │                  │
│ 客户          │ 延迟   28 ms                 │                  │
│              │ 出口   203.0.113.42   复制    │                  │
│              │                              │                  │
│              │ 浏览器现在能用了。             │                  │
│              │                              │ ───────────────  │
│ 设置          │ ┌ 节点卡 ──────────────────┐  │ [ 问点什么…  ↑ ] │
│              │ └──────────────────────────┘  │                  │
└──────────────┴──────────────────────────────┴──────────────────┘
```

- 默认：`280px minmax(0,1fr) 420px`。
- 控制台内容列最大 760px，左对齐；右侧留白是构图的一部分，不塞东西。
- 左栏与助手栏都是 1px `--hair` 分隔，不用阴影。
- 窗口最小 960×640；低于 960 不做移动端适配，按桌面窗口处理。

### 4.2 断点

| 宽度 | 配置栏 | 助手 | 说明 |
|---|---|---|---|
| ≥ 1440 | 280 | 420 | 完整三栏 |
| 1200–1439 | 260 | 380 | 三栏，读数行仍完整 |
| 1024–1199 | 240 | 覆盖层 400 | 助手收起为右边缘 56px tab；点开为浮层，Esc 关闭 |
| < 1024 | 72 图标栏 + 抽屉 | 覆盖层 | 配置列表变成抽屉；不优先做，但结构允许 |

- 助手宽度不参与拖拽；配置栏本轮也不做拖拽。先把版式定下来，拖拽是下一步。
- 助手默认：**宽屏 ≥1200 打开**；窄屏收起为 tab。用户手动收起后记住选择（`localStorage: veyl.ui.panelOpen`）；首次启动强制打开。
- 助手收起后，右边缘留 56px tab：竖排“助手”+ 未读点；点击展开。

### 4.3 高度行为

- 控制台内部不整页滚动；只有助手对话和时间线各自滚动。
- 窗口高度不足 720 时，读数行压缩为 48px，节点卡保持完整。
- 底部节点卡紧贴控制台底部，距底 24px；它不随内容滚动。

## 5. 组件规格

### 5.1 主按钮

| 项 | 规格 |
|---|---|
| 高度 | 44px |
| 内边距 | 0 20px |
| 圆角 | 6px |
| 字体 | 15 / 500 |
| 默认 | `--ink` 底，`--paper` 字 |
| hover | `#000` 底 |
| active | 下沉 1px |
| focus | 2px `--cobalt` 外环，offset 2 |
| disabled | `--ink` 8% 底 + `--ink-3` 字（仍可读，不消失） |
| 已连接态 | 1px `--hair-strong` 描边 + `--ink` 字，透明底 |

文案：`启动 VPN` / `正在连接…`（禁用）/ `断开 VPN` / `重新连接`。全屏只此一个实心或描边主操作。

### 5.2 状态

- **H1 是唯一的视觉状态表达。**
- 未连接 / 连接中 / 失败：44px 状态词；未连接不放 LED，连接中蓝、失败红。
- 已连接 / 不稳定：H1 内是 20px 状态标签 + 64px 计时器；状态标签属于标题，不是独立的「小状态行」。
- LED：6×6px，圆角 2px；已连接绿、连接中蓝、降级琥珀、失败红。只作装饰，`aria-hidden`。
- 读屏状态：`.sr-only` 的 `role="status" aria-live="polite"`，视觉不占位。
- 不使用胶囊状态标签。

### 5.3 配置列表项

| 项 | 规格 |
|---|---|
| 高度 | 64px |
| 内边距 | 12px 12px 12px 14px |
| 圆角 | 6px |
| 默认 | 透明底 |
| hover | `rgba(255,255,255,.55)` |
| 选中 | `--card` 底 + 左侧 2px `--cobalt` 内线 + 名称 600 |
| 名称 | 15 / 500；选中 600 |
| 元信息 | 12 / `--ink-3`，如 `3 个节点 · 浏览器` |
| 连接标记 | **不显示**；“已连接”只属于 hero |

配置行只表达“我在用哪套配置”，不表达网络状态。

### 5.4 读数行

| 项 | 规格 |
|---|---|
| 行高 | 57px（上下 18px） |
| 栅格 | `92px 1fr auto` |
| 标签 | 12 / `--ink-3` |
| 主值 | 20 / mono / `--ink` / tabular-nums |
| 副值 | 12 / `--ink-3`，右对齐 |
| 行间 | 1px `--hair` |
| 出口行 | 副值是「复制」文字按钮，复制后 2 秒变「已复制」 |

**速率条（连接后）**

- 位置：读数行下方、节点卡上方，横跨内容列。
- 标签：左侧 `最近 60 秒`，右侧 `上行 1.2 MB/s · 下行 12.4 MB/s`（12px mono）。
- 图形：46px 高；一条 1px 状态色折线 + 7% 透明度面积；没有网格、没有刻度。
- 两端只写 `60 秒前` / `现在`（9.5px mono）。
- 降级时折线与面积改用 `--amber`；未连接/失败时不出现。
- 数据：前端按 `runtime-health-changed` 里的 `traffic.up_rate` / `down_rate` 追加样本（后端健康检查约 2 秒一次），保留最近 30 个点，约覆盖 60 秒。样本不足时左端留空；没有历史时画一条贴底基线，不伪造波形。
- 这一段是**前端内存里的环形缓冲，进程重启即丢**。不新增后端历史接口，也不改后端采样频率；实现的人不要以为要去动 Rust。
- 这是固定读数面的一部分，不属于 AI 编排区。

### 5.5 节点卡

| 项 | 规格 |
|---|---|
| 容器 | 白底、1px `--hair-strong`、10px 圆角、`--shadow-card` |
| 内边距 | 18px 20px |
| 标题行 | 左：11px 标签「当前节点」+ 17/600 节点名；右：操作 |
| 事实行 | 12px mono、`--ink-3`：`203.0.113.8 : 20343 · aes-256-gcm` |
| 操作 | 32px 高描边小按钮：`更换`；已连接时加 `检查` |
| 选中但未切换 | 出现 `用这个节点`，描边 + 蓝字；不与 hero 主按钮同级 |

节点卡是底部唯一的容器，解决“飘在白底上”的问题；它不再重复状态、流量、延迟。

### 5.6 中间区（那件事）

- 只有一句话时：15px / `--ink-2`，左侧 2px 状态色细线，`padding-left: 12px`，最大 52 个汉字宽。
- 三级代理卡：白底卡片，10px 圆角，24px 内边距；标题 20/600；地址 24px mono；右侧「复制」32px 描边按钮；下方 13px 说明。
- 失败卡：白底，左侧 2px `--red`，10px 圆角，24px 内边距；**没有标题**——H1 已经是「连接失败」。第一行直接是原因（15/500），随后用 `01/02/03` 三步写「现在做什么」：重新连接 → 换一个节点 → 让助手定位。三步都是文字，不放按钮。
- 降级卡：同样无标题；第一行是原因「最近的网络检查没有通过。」，下面是行动。
- 二级授权卡：同上，左侧 2px `--cobalt`。
- 所有卡都不含按钮（复制除外），下一步用文字指路，不复述顶部/底部已有的操作。

### 5.7 助手栏

| 项 | 规格 |
|---|---|
| 宽度 | 420（宽屏）/ 380 / 覆盖层 400 |
| 头部 | 64px：`助手` 15/600 + `DeepSeek` 11px 标签 + 右侧「新对话」「收起」两个 28px 图标按钮 |
| 对话 | 无气泡；每条消息上方 11px 署名（`Veyl` / `你`），正文 14.5 / 1.65；消息间 1px `--hair`；用户消息正文 `--ink`，助手 `--ink-2` |
| 选项 | 32px 高描边选项按钮，最多 3 个，纵向排列 |
| 输入 | 44px 白底、1px `--hair-strong`、6px 圆角；右侧 28px 发送按钮；占位 `问点什么，或让我改配置` |
| 底部提示 | 10.5px `--ink-3`：`⌘↵ 发送` |
| 收起态 | 右边缘 56px 竖排 tab：`助手` + 未读点 |

助手是产品的主功能，不是浮层工具。宽屏默认可见；窄屏才退成 tab。

## 6. 三个级别的界面差异

不显示“一级/二级/三级”这类标签，差异只体现在行为与中间区。

| | 一级（浏览器） | 二级（所有软件） | 三级（手动填代理） |
|---|---|---|---|
| 左栏元信息 | `浏览器` | `全部软件` | `本机代理` |
| 未连接中间区 | 一句话：点启动，浏览器就能用 | 一句话 + **首次授权说明卡**（系统弹窗前的解释） | **代理卡**：预计地址、协议、无复制 |
| 已连接中间区 | 一句话：浏览器现在能用了 | 一句话：所有软件现在都能用了 | **代理卡常驻**：实际地址、复制、HTTP/SOCKS5 |
| 失败卡 | 同一张 | 同一张 | 同一张 |
| hero 读数 | 时长 / 流量 / 延迟 / 出口 | 同左 | 同左 |
| 授权 | 无 | 首次连接时系统弹窗 | 仅当这套配置选了“全部软件接管” |
| AI 助手 | 可问浏览器问题 | 可问桌面软件问题 | 可问“地址填哪里” |

判定依据仍是配置的 `connect_mode` 与 `routing_mode`；界面不出现 `proxy`、`TUN`、`分流`、`规则集` 四个词。

## 8. 与现有规范的关系

本次允许推翻规范。明确改动的几条：

| 旧规范 | 新方案 | 为什么 |
|---|---|---|
| 四列（56 activity bar + 240 + 弹性 + 400） | 三列（280 + 弹性 + 420） | activity bar 只有一个图标，纯占位 |
| 右栏默认隐藏 | 宽屏默认打开，可收起并记忆 | 对话是产品差异点；隐藏它等于隐藏主功能 |
| 中间大部分时候为空 | 已连接时由计时器 + 读数行占据；未连接时由配置摘要占据 | 空白不是“安静”，没有主对象才是 |
| 主按钮永远实心 | 启动/重连实心，断开描边 | 已连接是用户想要的状态，不应持续催促破坏 |
| 六档字号 | 增加 64px 计时器与 44px 状态词两个显示级 | 仪表需要读数尺度；正文仍从 12px 起 |
| 圆角 8/12 | 2/6/10/14 | 更精确的层级；卡片与按钮不再同一圆角 |
| 线路图是签名元素 | 计时器是签名元素 | 线路图信息量低，且已被产品负责人否掉 |
| 暖石底 #FAFAF9 | 纸面 #FAF8F2 + 桌面 #EFEBE1 | 拉开左栏/纸面/卡片的层级，去掉“全屏一个白” |
| 强调色 #2A5FD0 | 钴蓝 #1F46B8 | 更沉、更像印刷油墨；只做选中与焦点 |

保留的硬规则：一个主按钮、每个事实一个住处、界面不出现 `proxy`/`TUN`/`分流`/`规则集`、离线系统字体、浅色默认、AI 不接管固定骨架。

**与 `ui-ux-pro-max` 的分歧**：它的 `--design-system` 返回的是深色 navy + Inter + “Trust & Authority” 营销站方向。深色与该技能自己要求的“浅色默认”冲突，Inter 需要联网加载，与离线约束冲突；“Trust & Authority” 的证书/案例/CTA 结构也不适用于常驻桌面工具。本方案只采用它命中的 Minimalism & Swiss Style 的网格、留白与克制，配色、字体和结构自行定义。

# 服务器详情页：三块分区与事实区排版

> 日期：2026-11-23
> 状态：**已定稿（2026-11-23）**。只出文档，不改代码。
> 范围：`MyServerDetail` 的中间详情页版式；状态文案沿用 `my-server-detail-states.md`，本轮不改。
> 依据：`veyl-ui` §3.3（4px 网格与间距档 4/8/12/16/24/32/48；边界靠留白不靠线框）/ §3.2（字号阶梯）/ §2.1（一屏一个主动作）；`ui-ux-pro-max` 命中 `Typography · Font Size Scale`（只用固定阶梯上的字号）与 `Accessibility · Text Reflow and Spacing`（内容驱动高度、不把文字裁进固定高度盒）；「分组 / 留白隔离」两条检索无数据库命中，按 `veyl-ui` §3.3 的留白规则处理。

---

## 1. 三块：状态 / 事实 / 危险操作

- **分界只用一种手法：48 间距。** 状态块与事实块之间 48，事实块与危险块之间 48；块内间距一律 ≤ 24。删掉现在 `.myservers__footer` 与 `.myservers__danger` 上的两条细线。
- 为什么不用另外三种：细线只能画一条边，用户现在的读感就是「一条线下面挂着一排东西」，线不产生分区；浅底会把页面变成卡片堆，状态块还会随状态换高度；分区标题（「状态」「服务器信息」）给一页已经在嫌乱的内容再加一层文字。48 是块内节奏 24 的两倍，只靠留白就分出三块，符合 `veyl-ui`「边界靠留白不靠线框」。

```
悉尼                                      ● 安装服务端 · 已等待 3 分 49 秒
                                          ← 24
[━━━━━━━━ ━━━━━━━━ ━━━━━━━━ ━━━━━━━━]   ← 四段进度
这一步已经 3 分钟，还在继续。
                                          ← 48
地区    悉尼              流量    每月 1000 GB 出站
                                          ← 48
[销毁]                                    ← 取消创建待排期，本轮用销毁
```

## 2. 事实区排版：两列键值网格

- 网格：容器 `container-type: inline-size`；内层 `grid-template-columns: repeat(2, minmax(0, 1fr))`，`@container (max-width: 479px)` 退回单列；列间距 48，行间距 12，最大宽 760（更宽时左对齐，不拉伸）。
- 每格：标签列固定 48、标签与值间距 12、值可换行；标签 12/`--ink-3`，值 14/`--ink`；最小行高 24，行高随内容增长（不裁剪，依据 `Text Reflow and Spacing`）。
- 5 个事实按行优先排：地区 \| IP，节点 \| 费用，流量。建机中只有 2 个事实时正好占满一行；停机中只有 1 个，单列显示。
- 这样多出来的横向空间被第二列吃掉，页面重心不再全压在左边；窄窗格（内容 < 480）退回单列，不硬塞两列。

```
地区    悉尼              IP      203.0.113.7  [复制]
节点    已就绪            费用     每天 $0.30
流量    每月 1000 GB 出站
```

## 3. 动态状态不进事实表

| 项 | 安装中 | 失败 | 就绪 / 已计费 |
|---|---|---|---|
| 节点 | 不显示——状态块已经在说正在装服务端 | 不显示 | 显示 `已就绪`，条件 `isServerNodeReady` |
| 费用 | 不显示——「开通后开始计费」是过程，不是属性 | 显示结论（已退回 / 未扣费） | 显示 `每天 $X`，条件 `billing_state !== "pending"` |
| 地区 / 流量 | 显示 | 地区显示，流量不显示 | 显示 |

- 规则一句话：**只有长期成立的事实进事实区；正在发生的过程留在状态块。** 不再出现 `节点 未就绪`、`费用 创建中，开通后开始计费` 这两句。
- 状态块与事实区的连接点是「就绪」这一下：节点入池、开始计费，同一次刷新里两行一起出现。

## 4. 四态差异（块顺序永远不变）

| 形态 | 状态块 | 事实区 | 危险块 |
|---|---|---|---|
| 安装中 | 状态行 + 四段进度 + 一步句 | 2 格（地区、流量） | `销毁`（danger ghost；取消创建待排期，本轮用销毁） |
| 已开通 | 状态行 + `用了 X` | 5 格（3 行） | 左 `销毁`；诊断可用时右侧 `智能诊断` |
| 失败 | 状态行 + 失败说明 | 2 格（地区、费用结论） | 左 `销毁`；右 `[AI 定位] [重新建一台]`；结算失败为 `[重新建一台] [去充值]`（去充值为主、最右，**不给 AI 定位**） |
| 停机 | 停机中：一行；墓碑：一句；欠费/停用：说明 | 停机中 1 格、墓碑 0 格、欠费 5 格 | `重试销毁` / `删除` / `[销毁][去充值]` |

- 危险块永远是页面最后一块、独占一行：**左 = 危险操作，右 = 动作组（次按钮挨主按钮左侧）**。它靠 48 间距与事实区分开，不再靠一条线；没有主按钮时右侧空着，销毁也不居中。

## 6. 验收点

1. **分区**：状态块 → 事实块 → 危险块均为 48 间距，块内 ≤ 24；footer 与 danger 的两条 hairline 已移除；三块顺序在四种形态下不变。
2. **事实网格**：内容 ≥ 480 两列、否则单列；标签列 48、标签与值 12、列间距 48、行间距 12、最小行高 24、最大宽 760；长值换行不被截断，IP 与复制按钮同格不换行。
3. **动静分离**：安装中不出现「节点」「费用」两行；节点只在就绪后、费用只在开始计费后（或失败结论）出现；两行在就绪那次刷新里同时出现。
4. **危险块**：永远最后、独占一行，左危险右动作组；销毁沿用 danger-ghost + 二次确认；无主按钮时销毁不居中。
5. **中英文**：Region / Traffic 在 48 宽标签列内不折行；窄窗格（内容 < 480）下事实退回单列，值不被裁。

# 退出确认弹窗：视觉规格

> 日期：2026-11-17
> 状态：设计定稿，待实现。只出规格与文案，不改代码。
> 流程不变：`后台运行`（默认、主）/ `退出`（次）；`Esc`、`×`、点遮罩都等于取消（回 `background`）。
> 现有实现：`src/components/QuitDialog.tsx`、`app.css:1354-1440`、`ai-first-product.md` §退出确认。

---

## 0. 触发条件

**`Cmd+Q` 与菜单「退出 Veyl」在任何时候都弹窗**，与是否已连接无关（2026-11-17 产品决定）。这是一个常驻菜单栏的应用：用户按快捷键或点菜单退出时，想表达的是「我要离开窗口」，而不是「我要关机」——这个选择不能因为此刻没连接就被吞掉。

| 入口 | 路由（`QuitRoute`） | 已连接 | 未连接 |
|---|---|---|---|
| `Cmd+Q` | `Menu` | 弹窗 | **弹窗** |
| 菜单「退出 Veyl」 | `Menu` | 弹窗 | **弹窗** |
| 托盘菜单 `退出` | `Tray` | **直接退出**（不弹） | **直接退出**（不弹） |
| 系统注销 / 关机 | `System` | **不弹，直接退出** | **不弹，直接退出** |

两条例外的理由（同一句话）：**用户已经用更明确的方式说了「退出」**。

- `Tray`：托盘 `退出` 是从菜单栏的小菜单里逐级点出来的，意图比 `Cmd+Q` 更明确，再弹一次就是二次确认套二次确认。
- `System`：系统注销 / 关机是系统在关我们，弹窗只会卡住用户关机（`ExitRequested` 的系统发起路径标为 `QuitRoute::System`，永不拦截）。此时网络本来就要断，没有「保持连接」这个选项。

未连接时弹窗的代价很低（`Esc` 一下的事），收益是：用户始终知道「窗口关了但我还在菜单栏」，以及「退出到底关不关进程」这两件事。

## 2. 标题与正文

已连接：

```
退出 Veyl？                                        ×
─────────────────────────────────────────────────
后台运行   保持连接
退出       断开连接并恢复网络设置
```

未连接：

```
退出 Veyl？                                        ×
─────────────────────────────────────────────────
后台运行   留在菜单栏
退出       关闭 Veyl
```

| 元素 | 规格 |
|---|---|
| 标题 | 17 / 1.35 / 600，`--ink`；`margin: 0` |
| 关闭 × | 32×32（图标 14），右上角，`--ink-3`；hover 底色 `--bg-hover`、变 `--ink`；`title="关闭"`；与标题基线视觉对齐，`margin: -4px -8px 0 0` |
| 正文 | 与标题间距 16；两行，行距 10；不画分隔线 |
| 行标签 | 13 / 1.5 / 600，`--ink`，固定列宽 72（`后台运行` / `退出` 对齐） |
| 行说明 | 13 / 1.5，`--ink-2`；左对齐接在标签后 12 |
| 颜色 | 正文只有 `--ink` / `--ink-2`，**不用绿/红**——这两句是后果，不是状态；全屏唯一的彩色是已连接时 `退出` 按钮的 `--red` |

**正文按连接状态取词**，其余部分（标题、布局、关闭方式、按钮顺序）两种状态完全一致。未连接时不能沿用「断开连接并恢复网络设置」：那一刻没有连接可断，也没有网络设置要恢复，照抄就是一句假话，比不写更糟。

**不用列表圆点、不用图标。** 理由：

- 两个后果必须和两个按钮一一对上；把按钮名做成行标签，读者不需要自己配对。
- 加图标就要新造「连接 / 断开」两个图形，而现有图标集里没有，新增一套线性图标与「不新造图标集」冲突；用状态色又会让「退出」看起来像错误状态。

## 3. 按钮

| 项 | 值 |
|---|---|
| 位置 | 正文下方 24，右对齐，并排 |
| 尺寸 | 高 40、最小宽 96、内边距 0 18、圆角 6、13 / 500 |
| 顺序 | 左 `退出`，右 `后台运行`（主按钮在最右，macOS 习惯） |
| 间距 | 8 |
| 主按钮 | `后台运行`：`--ink` 实心 + `--canvas` 字（沿用 `.btn--primary`），默认焦点 |
| 次按钮 | `退出`：**已连接**用 `.btn--danger-ghost`（描边 + `--red` 字），不是普通 ghost——“退出会断开连接”是负向且不可撤销到这次会话的动作，描边红字让代价可见，重量仍低于主按钮；**未连接**用普通描边（`.btn--ghost`）：关进程没有网络代价，红字会把一件小事说成危险 |
| 禁用 | 命令在途：两个按钮都 `disabled`，沿用各自禁用样式（主按钮变灰、次按钮 38%），光标默认；不加 spinner、不改按钮文字（避免布局跳动） |

- 按钮不撑满整行，不并排等宽到 420；两个 96–120 的小按钮足够，留白由右侧承担。
- 不把 `退出` 放在最左并拉开距离：那是详情页危险动作的规则；在确认弹窗里，两个选项属于同一个决定，应该相邻。

## 4. 关闭方式

| 方式 | 行为 | 视觉 |
|---|---|---|
| `×` | 取消 → 回 `background` | 右上角常驻，32×32 热区，hover 有底色 |
| `Esc` | 同上 | 不加文字提示（系统惯例，写出来反而吵） |
| 点遮罩 | 同上 | 遮罩无 hover 反馈；按下即关闭 |
| 命令在途 | 三者都失效 | `×` 变 38% 透明度，`Esc` / 遮罩不响应 |

- 三种关闭都**不是**「退出」，只是不打断用户；弹窗不额外说明这一点，因为「取消」本身就是默认。
- 弹窗不带「取消」按钮：`×` 与遮罩已经承担取消，再加一个按钮会让三个选项里有两个同义。

## 5. 可访问性

| 要求 | 实现 |
|---|---|
| 角色 | **`role="alertdialog"`**（不是 `dialog`）：这是一个需要用户立即回应的决定，screen reader 会先读标题与描述 |
| 模态 | `aria-modal="true"` |
| 标题 | `aria-labelledby="quit-dialog-title"`（现有） |
| 描述 | **`aria-describedby="quit-dialog-desc"`**，指向包含两行后果的容器（新增） |
| 初始焦点 | 主按钮 `后台运行`（现有 `primaryRef`）；不是 `×` |
| 焦点陷阱 | `useFocusTrap`（现有），Tab 只在两个按钮 + `×` 之间 |
| Esc | 关闭；`busy` 时不响应（现有） |
| 关闭后 | 焦点回到打开前的位置；没有则回到中间舞台的主按钮（由上层负责） |
| 状态 | `busy` 时 `aria-busy="true"`（现有） |
| 错误 | `role="alert"`，12 / `--err-text`，放在按钮上方 12（现有结构，字号从 13 调到 12 以让位给正文） |
| 对比度 | 标题 15:1、说明 7:1、危险描边文字 6.4:1，均 ≥4.5:1 |

## 6. 文案

保持「按钮名 + 结果」的句式（上一版把「会……」改成这个形式），并按连接状态取词：

| 位置 | 原文 | 改为 |
|---|---|---|
| 标题 | `退出 Veyl？` | 不变（两种状态都一样） |
| 已连接 · 第一行 | `后台运行会保持连接。` | `后台运行` + `保持连接` |
| 已连接 · 第二行 | `退出会断开连接并恢复网络设置。` | `退出` + `断开连接并恢复网络设置` |
| 未连接 · 第一行 | — | `后台运行` + `留在菜单栏` |
| 未连接 · 第二行 | — | `退出` + `关闭 Veyl` |

理由：

1. 原句是两段并列的叙述，读者要自己判断哪句对应哪个按钮；改成「按钮名 + 结果」后，一眼对上。
2. 去掉重复的「会」，两行等长，不会一长一短。
3. 不新增第三句（例如「关闭窗口不会退出」）：那会引出新的疑问，而 `×` 的默认语义已经足够。
4. 未连接时改词的理由只有一条：**只写正在发生的事**。「断开连接并恢复网络设置」在未连接时是假的；`留在菜单栏` / `关闭 Veyl` 才是这一刻两个按钮的真实差别——即「窗口没了，应用还在」与「应用也没了」。

## 7. 落地清单

- **触发**：只有 `QuitRoute::Menu`（Cmd+Q / 菜单「退出 Veyl」）打开弹窗，去掉「已连接才弹」的判断，任何连接状态都弹；`QuitRoute::System`（系统注销 / 关机）与 `QuitRoute::Tray`（托盘「退出」）保持直接退出。
- **浮层**：`quit-dialog`：`padding: 24px`；`box-shadow` 改为上面的双层值；`background: var(--card)`。
- `quit-backdrop`：`background: rgba(23,22,20,.22)`（深色 `.55`），不加 `backdrop-filter`。
- `quit-dialog__title`：不变（17/600）。
- `quit-dialog__body`：改为两行 label/value 的 `dl` 或 grid，行距 10；label 13/600 `--ink`，值 13 `--ink-2`；**文案按 `connected` 取两组常量**（§6），不要在 JSX 里拼字符串。
- `quit-dialog__actions`：`margin-top: 24px`；按钮加 `.quit-dialog__btn { height:40px; min-width:96px; padding:0 18px; }`；`退出` 按状态选 `.btn--danger-ghost`（已连接）/ `.btn--ghost`（未连接）。
- `role` 改 `alertdialog`，补 `aria-describedby`；关闭按钮 32×32。

# 连接页节点列表：按来源分三组

> 日期：2026-11-24
> 状态：**已实现**（2026-11-25）；同日改为「来源分段标签」，见 §6。
> 前置：等「节点添加」批次（`NodeImportDialog` 等）提交后再动 `ConnectionStage.tsx`，避免同文件两份实现冲突。已解除（33653a1）。
> 上游：`docs/design/node-import-ui.md` §7（两类节点的能力边界）。

---

## 0. 结论

连接页的节点列表从「免费节点 / 你的服务器」两组，改成三组，顺序为**付费在前、免费垫底**：

| 顺序 | 组标题 | 包含的 `source` | 用户能感知的特征 |
|---|---|---|---|
| 1 | 我的服务器 | `owned` | 付费、可智能分析 / 可更换连接密码 |
| 2 | 自定义节点 | `url` + `manual` | 凭据在自己或服务商手里，行内保留「自定义」小标，我们修不了 |
| 3 | 免费节点 | `seed` | 会过期，失效后自动从池里移除 |

组间沿用现有「免费节点」与「你的服务器」之间的分割线；组标题 12 / 500 / `--ink-3`，不加卡片、不加背景。

---

## 1. 为什么不是四组

曾考虑按 `owned` / `seed` / `url` / `manual` 拆四组。否掉的理由是：**`url` 与 `manual` 对用户没有任何行为差别**——都是用户自己的、都不归我们修、都要用户自己维护。拆开只多一个标题，不增加任何可操作信息。

真正能感知的差别只有三件事：能不能修（`owned` vs 其它）、要不要花钱（付费 vs 免费）、会不会过期（`seed` 会）。三组正好对应这三件事。

---

## 2. 为什么要调顺序

现在免费节点排在前面。免费节点是兜底资源、会过期，排在付费节点之前会让用户误以为那是主推。付费节点在前、免费垫底，与「付费优先、免费兜底」的产品口径一致。

---

## 3. 要做的事

1. `src/components/ConnectionStage.tsx`：分组依据从 `source === "seed"` 二分，改成三分；组标题与顺序按上表。
2. i18n：`console.group.owned` 保持「我的服务器」，新增 `console.group.custom`「自定义节点」；`console.group.free` 保持「免费节点」。
3. 行内「自定义」小标只出现在第二组（`url` / `manual`），第一、三组不出现。
4. 空组不渲染标题（沿用现状）。
5. 分割线：三组之间统一用同一条样式，与现在两组之间的保持一致。

---

## 4. 验收

1. 三台机器（各类型各一台）时，列表按「我的服务器 → 自定义节点 → 免费节点」顺序显示，组间有分割线。
2. 只有一类节点时，只出现那一组的标题，没有空标题。
3. 「自定义」小标只在第二组出现。
4. 选中态、测速值、失败行按钮（`owned` 才有「智能分析」）与现在逐字不变。
5. 中英文标题都不换行、不裁字。

---

## 5. 相关但不在本文范围

**自定义节点无法删除**：界面与 Host 都没有移除 `url` / `manual` 节点的路径（`node_forget` 只服务托管节点的停机墓碑）。这需要新命令 + 契约 + 行内入口，单独立项；本文只登记，不实现。

## 6. 2026-11-25 修订：来源改为分段标签

§3 / §4 的「三组同屏堆叠」已被以下方案取代（实现见 `ConnectionStage.tsx`）。

### 6.1 骨架

客户端 destination 的整列改为三段固定骨架：

| 位置 | 内容 | 滚动 |
|---|---|---|
| 顶部 Hero | 状态、主按钮、连接参数（接管方式 / 流量范围 / 问 AI） | 不滚动 |
| Hero 下 | 节点卡（当前节点行 + 来源标签 + 当前组列表） | 卡片固定，列表内部滚动 |
| 底部 | AI 编排区（action_card / 空态） | 唯一滚动区 |

主按钮不再排在节点列表之后，节点再多也留在首屏；节点卡是定高板块，固定在 Hero 下方。

### 6.2 来源标签

- 标签顺序仍为 `我的服务器` → `自定义节点` → `免费节点`，每段带数量（含待接入行）。
- **只要这条配置还有节点，三个来源标签就常驻**，空组显示 `0`；切到空组时列表位置给一句空态（`还没有服务器节点` / `还没有添加自己的节点` / `没有免费节点`）。自定义组空态带一个 `添加节点` 文字入口，打开导入弹层。整条配置没有节点时不显示标签，只留 `这条配置没有节点了`。
- **同一时刻只渲染一组**；切换标签只改视图，不换节点、不连接、不断开。
- 键盘：`tablist` / `tab`，左右方向键切换。

### 6.3 当前节点

- 当前节点名显示在 Hero 状态词后面：`● 已连接  美国 01`（未连接时同样跟在状态词后）。
- 切到别的来源标签时，状态行仍显示真实当前节点；点这个节点名会回到它所在分组并滚到该行。
- 它只做导航，不换节点；节点卡里不再单独占一行。

### 6.4 容量

- 当前组列表最高约 `clamp(96px, calc(100vh - 460px), 312px)`（约 6 行，窗口矮时先压列表）。
- 当前组超过 12 个节点时才出现搜索框，只过滤当前组；无结果给 `没有匹配的节点` + `清除搜索`。
- 免费组被选中时，试用口径（`3 天后到期` / `试用中` / `已到期`）显示在卡片底部。

### 6.5 未变

- 行内「自定义」小标仍只属于 `url` / `manual`。
- 待接入行仍只出现在「我的服务器」组末尾。
- 选中态、测速值、失败行按钮与 §4.4 一致。

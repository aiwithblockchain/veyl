# 中英文切换（任务）

> 日期：2026-11-21
> 状态：**需求已定，待实现**。本文是开发任务书；交互细节里有几处标「待定」，实施前先拍。
> 来源：产品负责人口述。相关：`docs/design/ai-docs-management.md` §7、`docs/notes/pending-topics.md` #2。

---

## 1. 目标

系统设置里增加语言选项（中文 / English）。切换后：

1. **界面文案**按所选语言展示；
2. **AI 对话**的回复按所选语言；
3. **AI 的思考过程**也按所选语言展示。

## 2. 范围

**做**

- 前端所有用户可见文案：引导页、主控制台、左栏、我的服务器、设置、账户菜单、弹层、按钮、空态、错误与提示、确认文案。
- AI 的系统提示词与用户提示词：按语言选择 `resources/prompts/zh/` 或 `resources/prompts/en/`（两套目录与文件已建立）。
- AI 回复与思考过程的语言约束：在系统提示词里明确「始终使用 {语言} 回答，思考过程也用该语言」。

**不做（本期）**

- 官网、文档站、GitHub 仓库的英文版。
- 邮件正文的双语（验证码邮件是否要双语，见 §6 待定）。
- 第三语言；只支持中文、English 两档。

## 3. 交互

| 项 | 方案 |
|---|---|
| 入口 | 设置 › **高级** 新增一行「语言」，两档：`中文` / `English`（放 `关于` 也可，见 §6） |
| 默认值 | 首次启动跟随系统语言（`zh*` → 中文，其它 → English）；用户改过之后以用户选择为准 |
| 生效时机 | 界面：立即生效，不需要重启或重新登录。AI 会话：见 §6 待定 |
| 持久化 | 与现有设置同一存储（Rust 侧 settings），前端启动时读取 |
| 切换影响 | 不重连、不登出、不清配置 |

## 4. 实现要点

### 4.1 前端

- 现在文案直接写在组件里（中文）。建议自建轻量字典 `src/i18n/`：`zh.ts` / `en.ts` + `t(key)`，不引入外部 i18n 依赖（离线约束、体积可控）。
- 需要先把现有中文文案抽成 key——量最大的一步，建议按屏幕分批：引导页 → 主控制台 → 我的服务器 → 设置 → 账户菜单 → 错误与提示。
- 日期、金额、数字：金额固定 USD（`$8.30`），不做 locale 化；时间显示统一用 `YYYY-MM-DD HH:mm` 或相对时间（现有写法即可）。
- 缺失 key 的回退：**不显示 key 本身**，回退中文并在日志里记一行 `i18n missing key=… lang=en`，便于补齐。

### 4.2 后端与提示词

- 提示词文件按语言二选一，参考 TweetPilot 的 `prompt_lang_dir()`：语言前缀归一（`en-GB`、`en-AU` 都算 `en`），只认 zh / en 两档。
- 语言值从设置读取，在新建 AI 会话时决定用哪套系统提示词；系统提示词末尾追加一行语言约束。
- **错误文案的归属**要定：现在后端会直接返回中文句（如「登录后才能创建服务器」）。两种做法：
  - A（推荐）：后端只返回稳定的错误码，前端按语言映射文案；
  - B：后端按请求里的语言返回对应文案。
  A 的改动面更大但文案集中、可测试；B 快，但后端要维护两套字符串。

### 4.3 AI 思考过程

- 思考过程的语言由模型决定，我们能做的是在系统提示词里明确要求。若模型仍用英文思考，界面如实展示，不做二次翻译（不额外调用模型）。

## 5. 验收

1. 在设置里切到 English：所有界面文案变英文，无需重启；重启后仍是 English。
2. 新建 AI 会话：回复是英文，思考过程也是英文；后端加载的是 `resources/prompts/en/` 的提示词。
3. 切回中文：同上，行为对称。
4. 切换语言不影响：登录状态、正在进行的连接、已创建的服务器、节点池。
5. 不存在「中英混杂」的界面（专有名词如 Veyl、DeepSeek、sing-box 除外）。
6. 缺失翻译时界面回退中文且不裂开，日志有 `i18n missing key` 记录。

## 6. 实施前要拍的四件事

| # | 问题 | 建议 |
|---|---|---|
| Q1 | 切换语言后，**已经存在的 AI 会话**跟着换，还是新会话才生效？ | 新会话生效；老会话在标题栏标注原语言，避免上下文半中半英 |
| Q2 | 语言开关放 `高级` 还是 `关于`？ | `高级`（`关于` 只放版本与开源信息） |
| Q3 | 首次启动默认跟随系统，还是固定中文？ | 跟随系统，但「不猜」：系统语言不是 zh/en 时用 English |
| Q4 | 后端错误文案走「错误码 + 前端映射」还是「后端按语言返回」？ | 错误码 + 前端映射（长期更稳） |

## 7. 分批与工作量

| 批次 | 内容 | 依赖 |
|---|---|---|
| 1 | 语言设置项 + 持久化 + 提示词按语言选择 + AI 语言约束 | 无 |
| 2 | 前端字典骨架 + 引导页与控制台 | 批次 1 |
| 3 | 我的服务器、设置、账户菜单 | 批次 2 |

# Veyl 主界面重塑原型

直接用浏览器打开 `index.html`，不需要服务器、不需要联网。

- 顶部黑色条是评审工具条，不是产品界面的一部分；点它可以切换 10 个状态。
- 默认显示 01 首启；也支持直接打开 `index.html#s04` 这样的锚点。
- 所有状态是同一份 HTML/CSS 的静态画面，不接后端、没有脚本。
- 字体只使用系统字体；没有外部图片、字体或 CDN。

## 状态

| 锚点 | 状态 |
|---|---|
| `#s01` | 首次启动、没有配置 |
| `#s02` | 有配置、未连接（浏览器代理） |
| `#s03` | 正在连接 |
| `#s04` | 已连接（浏览器代理） |
| `#s05` | 已连接（全部软件） |
| `#s06` | 连接降级 |
| `#s07` | 连接失败 |
| `#s08` | 无节点 |
| `#s09` | 三级代理已连接 |
| `#s10` | 窄窗口 1100，助手收起 |

## 文件

- `index.html` — 10 个状态与评审工具条
- `app.css` — token、三栏骨架、组件与状态
- `screenshots/` — 1568×980（`s10` 为 1100×900）的渲染截图

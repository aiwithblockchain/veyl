# 账户区：导航头像 + 账号菜单

> **2026-11-26 起废弃**：头像浮层已删除，账号入口与退出登录见 `account-billing-ui.md`。
>
> 日期：2026-11-17（同日修订：全局唯一账号入口；2026-11-21 修订：余额刷新口径）
> 状态：设计定稿，待实现。只出方案与文案，不改 React 代码。
> 依据：`docs/design/ai-first-product.md`（登录只在购买服务器与查看账单时需要）、`veyl-ui` §2.1 / §2.2 / §3.1 / §6、`docs/design/stage-pages-review.md` §1.1。
> 本次修订要解决的问题：未登录时导航人物图标与「我的服务器」左栏底部「头像 + 未登录 + 登录」同时出现，两个未登录入口。

---

## 0. 结论

1. **全局只有一个账号入口：56px 导航底部的头像。** 未登录点它直接开登录弹窗，已登录点它开账号菜单。
2. **「我的服务器」左栏底部不出现任何账号块**：没有头像、没有「未登录」、没有邮箱、没有余额、没有登录按钮。
3. **未登录时左栏也不写空态**：不出现 `登录后查看你的服务器`、不出现头像。未登录/零台的说明与 `登录` 只在中间呈现（`stage-pages-review.md` §6）——一屏只有一个登录动作。
4. 已登录时左栏**不显示邮箱与余额**；这两样只在导航菜单里。
5. 登出不二次确认；`退出登录` 是菜单里唯一的危险动作。

## 1. 唯一入口

| 位置 | 内容 | 说明 |
|---|---|---|
| 56px 导航底部 | 头像按钮（人形 / 首字母） | **全局唯一账号入口**；每个 destination 都在 |
| 「我的服务器」左栏底部 | 无 | 账号块整块删除（含 72px 抽屉里的身份行） |
| 「我的服务器」左栏空态 | 无 | 左栏只保留标题行 `我的服务器 0 ＋`；空态与 `登录` / `新建节点` 都由中间承担 |

「一个入口」指**一个账号界面**：头像与菜单只出现在导航；登录状态与登录动作只在中间空态出现一次，左栏不再重复。

## 2. 头像规则

| 状态 | 图形 | 尺寸 | 颜色 |
|---|---|---|---|
| 已登录 | 邮箱首字母 | 24×24 圆 | 底 `#5B5850`、字 `#FFFFFF`（7.1:1） |
| 未登录 | 空心人形 | 24×24 | 1px `--hair-strong` 描边，人形 `--ink-3`，无填充 |
| 读取中 | 无字骨架 | 24×24 | `--hair` 填充 |

- 首字母取 `email.trim()` 第一个字符；拉丁字母转大写；数字/中文原样；取不到退回人形。
- 字 11 / 600 / 行高 1，居中。同一邮箱头像固定，不随机配色。
- 按钮热区仍是 40×40（`activity__item`），头像 24 居中。

## 3. 左栏：只剩标题行

### 3.1 删除范围

- 删 `MyServersAccount` 在 `MyServersRail` 里的渲染，以及它的全部状态（展开、登出确认、钱包加载）。
- 删 72px 抽屉/图标栏里的身份行（`rail__identity` 那一个）。
- 保留 `我的服务器` 标题行与 `＋`；`＋` 的行为见 §6。

### 3.2 未登录

```
┌ 我的服务器            0   ＋ ┐
└──────────────────────────────┘
```

- 左栏不写任何空态文字，也不放登录链接：登录状态与 `登录` 由中间空态承担（`stage-pages-review.md` §6）。
- 读取中显示三行骨架；读取失败也不在左栏写「账户暂时读不到」——账户错误只出现在中间。
- 左栏的列表读取失败仍就地显示 `连不上服务器，稍后再试` + `重试`（那是列表错误，不是账户错误）。

### 3.3 已登录

| 情况 | 左栏 |
|---|---|
| 有服务器 | 只有列表；底部留空，没有邮箱、余额、充值、登出 |
| 零台 | 只有标题行 `我的服务器 0 ＋`；不写 `还没有服务器`（中间承担空态与 `新建节点`） |
| 账户读取失败 | 不写任何账号提示；中间显示 `账户暂时读不到` + `重试` |

- 余额摘要不留在左栏：导航菜单一开就能看到，左栏重复会让同一事实有两个住处。
- 未登录时左栏不显示任何余额占位（没有 `—`、没有 `余额 --`）。

## 4. 导航头像的点击行为

| 账户状态 | 点击 | 结果 |
|---|---|---|
| 未登录 | 直接开登录弹窗 | 不展开菜单——菜单里没有可看的内容 |
| 已登录 | 展开账号菜单 | 菜单锚在图标右侧，间距 12 |
| 读取中 | 展开菜单，显示 `正在读取账户…` | 不出现死点击 |
| 读取失败 | 展开菜单，显示 `账户暂时读不到` + `重试` | 重试成功后按真实状态切换 |
| 登录过期 | 切回未登录，**不自动弹窗** | 一次 toast `登录已过期，请重新登录。`；下次点头像再开登录弹窗 |

- 菜单开着时再点头像 = 收起；`Esc`、点外部也收起。
- `aria-label`：未登录 `登录`；已登录 `账户`；有未读提示时（如余额不足）在 `aria-label` 末尾加一句，不加角标。

## 5. 账号菜单

从导航头像展开，锚在图标右侧，垂直对齐图标。

```
┌ 280 ──────────────────────────────┐
│  buyer@example.com                │   高 36
├───────────────────────────────────┤
│ 余额   $9.20               [充值]  │   高 48
├───────────────────────────────────┤   1px --hair
│ 退出登录                           │   高 36，--red
└───────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 容器 | 280 宽、`--card` 底、1px `--hair-strong`、圆角 10、`0 8px 24px rgba(23,22,20,.12)`、内边距 8 |
| 头部 | **只放邮箱**：13 / `--ink-2` / 500，单行末尾省略，`title` 全名；高 36，内边距 0 12。不再放头像与 `已登录 · 这台设备`——头像就在锚点旁，状态由「菜单能打开」本身说明 |
| 余额 | 标签 `余额` 11/`--ink-3`；金额 **20 mono** `--ink`、`letter-spacing: 0`；右侧 `充值` ghost，高 28、内边距 0 12 |
| 分隔 | 1px `--hair`，上下 8 |
| 退出登录 | 文字按钮，13 / 500 / `--red`，高 36，左对齐，无填充；hover 底色 `--bg-hover` |
| 账单 | **本轮不放**：还没有页面，现在点只弹「下一版接入」 |

- 菜单里没有「设置」「个人资料」「切换账户」。
- 不出现第二个主按钮：`充值` 只是 ghost。
- 加载 / 失败：
  - 账户读取中：头部骨架 + `正在读取账户…`，余额行 `读取中`；
  - 余额读取中：金额位 `读取中`（不写 `—`）；
  - 余额失败：按 `wallet-refresh.md` §3.3 分「从未取到值」与「已有旧值」两种；旧值不清空、不换成 `—`；
  - 未登录（从加载态落下来）：头部人形 + `未登录`，底部 `登录` 按钮；
  - 登出失败：菜单内 `role="alert"`，`没能退出登录，稍后再试。` + `重试`，菜单保持打开。
- 登出**不做二次确认**：不删除服务器、配置或节点，重新登录即恢复。成功收菜单 + toast `已退出登录`。

## 6. 与「我的服务器」左栏的关系

`stage-pages-review.md` §1.1（**2026-11-18 修订**）把「我的服务器」的 `＋` 改回**原地打开建机向导**——不切 destination，左栏在向导期间保留但禁用。路径仍然闭合：

```
未登录 · 任意 destination
  └─ 导航头像（左下，始终可见）──▶ 登录弹窗 ──▶ 已登录

未登录 · 我的服务器
  ├─ 左栏只有 `我的服务器 0 ＋`
  └─ 中间空态 `先登录` + `登录`（唯一登录动作）
已登录 · 我的服务器
  ├─ 左栏列表（无账号块、无空态文字）
  ├─ 标题行 ＋ ──▶ 在本页打开「新建节点」，左栏禁用；`返回` 回列表
  └─ 导航头像 ──▶ 菜单（余额 / 充值 / 退出登录）
```

- 登录入口不会消失：导航头像在每个 destination 都在，位置固定、热区 40×40；服务器页未登录时，中间的 `登录` 是第二处入口，但它是那一屏的主按钮，不是账号界面。
- 左栏不再有登录链接；登录后它只是列表，没登录时它只有计数 0。
- 新建节点页需要登录时（创建前校验），仍走现有就地登录，与导航入口是同一个弹窗。

## 8. 文案原文

- `先登录`（中间空态标题）
- `登录后可以买服务器；服务器装好后，节点会出现在节点池里。`
- `账户暂时读不到`
- `正在读取账户…`
- `未登录`（菜单加载后落到未登录时）
- `登录`
- `余额`
- `余额读取中…`
- `余额暂时读不到。`
- `读取中`
- `充值`
- `退出登录`
- `已退出登录`
- `没能退出登录，稍后再试。`
- `登录已过期，请重新登录。`

统一用 `退出登录`，不用「登出」；不加感叹号。

余额刷新的其余文案（`刷新中` / `没刷新成功，显示的是上次的余额。`）见 `wallet-refresh.md` §3.6，不在此重复。

## 10. 余额在两处：一条数据，两种用途

| 位置 | 显示 | 动作 | 用途 |
|---|---|---|---|
| 账号菜单（280 浮层） | 邮箱 + 余额 + 充值 + 退出登录 | `充值`、`退出登录` | 随手看一眼、充钱、退出 |
| 设置 › 账户 | 邮箱 + 余额 + 充值 + 账单（待有页面） | `充值`、`查看账单` | 账户明细与账务 |

**结论：两处都保留余额，但只有一份数据、一套刷新规则。**

- 刷新时机、节流、自动刷新与失败文案的完整口径见 `wallet-refresh.md`；本节只定两处的分工。
- 两处读同一个 `wallet` 状态（`useMyServers` 的同一份），不各自缓存、不各自格式化；金额统一 `formatUsdCents` + `.num`，菜单与设置都显示 `$9.20`。
- 打开任一面时刷新一次钱包；刷新期间保留旧值，不闪 `—`。
- 读取失败分两种状态：**从未取到值** / **已有旧值但刷新失败**。文案与入口以 `wallet-refresh.md` §3.3 为准，不在本节重复；不出现一处有值、一处空白。
- 两处展示是「快照 + 明细」，不是两个事实源：写操作（充值、退出）只有一个入口，读操作允许两个上下文。
- **不上第三处**：连接舞台、服务器详情、建机页都不显示余额；建机页余额不足时就地展开充值，不预先显示余额。

## 11. 设置 › 账户

```
邮箱
ribencong@gmail.com
────────────────────────────
余额                        [充值]  查看账单
$9.20
余额按天扣费，每台服务器单独计费。
```

| 元素 | 规格 |
|---|---|
| 邮箱标签 | 12 / `--ink-3` |
| 邮箱值 | 15 / `--ink`；单行省略，`title` 全名 |
| 分隔 | 1px `--hair`，上下 16 |
| 余额标签 | 12 / `--ink-3` |
| 金额 | **20 mono** / `--ink`，与菜单一致（现在 15，菜单 28，两处要统一） |
| 充值 | **primary**（`--ink` 实心，高 32，内边距 0 14）：账户页唯一实心主按钮；与菜单是同一个充值弹层 |
| 查看账单 | **本轮隐藏**：还没有页面，点了只弹「下一版接入」。有页面后再加，样式 13 / `--ink-2` + 下划线，**不用粉色** |
| 说明 | 余额下 4：`余额按天扣费，每台服务器单独计费。` 12 / `--ink-3` |
| 退出登录 | **不放**。它是账号动作，只在菜单里出现一次 |
| 加载 | 金额位 `读取中`，不显示 `—` |
| 失败 | 分两种状态（从未取到值 / 已有旧值），文案与入口见 `wallet-refresh.md` §3.3；金额不清空、不用 `—` |

**关于「最近一次扣费 / 下次扣费日期」：不显示。** 账户层没有统一的扣费日：每台服务器各自 `本期有效至 …`（详情里已有），余额按天对每台分别扣；把它们汇总成一个「下次扣费」需要额外口径，容易算错。等账单页存在后，历史明细在那里看。

## 12. 两处的文案与动作

| 项 | 规则 |
|---|---|
| 金额格式 | 两处都是 `$9.20`，mono；不加「USD」「美元」 |
| `充值` | 两处都叫 `充值`，打开同一个弹层 |
| `退出登录` | **只在菜单**；设置里不出现 |
| `查看账单` | **只在设置**（有页面后）；菜单里不出现 |
| `登出` | 不用，统一 `退出登录` |
| 余额说明 | 只在设置里出现一行；菜单不解释计费规则 |

这样每个动作只有一个入口，每个值只有一份来源；两处只是「快照」与「明细」的区别。

## 13. 必须改 / 建议改 / 不改

### 必须改（P1）

1. 菜单补一行邮箱（13 / `--ink-2`，高 36，无头像），不再直接以 `余额` 开头。
2. 菜单金额从约 28 降到 **20 mono**，`letter-spacing: 0`；设置金额从 15 提到 **20 mono**——两处一致。
3. 菜单 `充值` 从 44 降到 **28 ghost**；`退出登录` 用 13 / 500 / `--red`，高 36。
4. `查看账单` 本轮从设置里隐藏（死入口）；有页面后再加，改成 `--ink-2` 下划线。
5. 设置里不加 `退出登录`。

### 建议改（P2）

6. 设置余额下加 `余额按天扣费，每台服务器单独计费。`（12 / `--ink-3`）。
7. 两处打开时共用一次钱包刷新；失败按 `wallet-refresh.md` §3.3 的两种状态处理。
8. 菜单与头像间距 12、宽 280、内边距 8；金额与 `充值` 同一基线。

### 不改

| 项 | 理由 |
|---|---|
| 两处都显示余额 | 读操作允许两个上下文；同一份状态、同一格式，不会不同步。 |
| 菜单不显示头像 | 头像就是锚点，重复只会缩小邮箱可用宽度。 |
| 设置显示邮箱 | 这是账户明细页，身份必须写全。 |
| 菜单显示退出登录 | 账号动作的唯一入口；设置里重复会让「退出」出现两次。 |
| 设置不显示下次扣费 | 没有账户级扣费日；每台服务器的 `本期有效至` 已在详情里。 |

# 账户区：导航头像 + 账号菜单

> 日期：2026-11-17（同日修订：全局唯一账号入口）
> 状态：设计定稿，待实现。只出方案与文案，不改 React 代码。
> 依据：`docs/design/ai-first-product.md`（登录只在购买服务器与查看账单时需要）、`veyl-ui` §2.1 / §2.2 / §3.1 / §6、`docs/design/stage-pages-review.md` §1.1。
> 本次修订要解决的问题：未登录时导航人物图标与「我的服务器」左栏底部「头像 + 未登录 + 登录」同时出现，两个未登录入口。

---

## 0. 结论

1. **全局只有一个账号入口：56px 导航底部的头像。** 未登录点它直接开登录弹窗，已登录点它开账号菜单。
2. **「我的服务器」左栏底部不出现任何账号块**：没有头像、没有「未登录」、没有邮箱、没有余额、没有登录按钮。
3. 未登录时左栏的 `登录后查看你的服务器` **改成可点的文字链接**，不再配头像——它是「看列表需要登录」的任务提示，不是第二个账号入口。
4. 已登录时左栏**不显示邮箱与余额**；这两样只在导航菜单里。
5. 登出不二次确认；`退出登录` 是菜单里唯一的危险动作。

---

## 1. 唯一入口

| 位置 | 内容 | 说明 |
|---|---|---|
| 56px 导航底部 | 头像按钮（人形 / 首字母） | **全局唯一账号入口**；每个 destination 都在 |
| 「我的服务器」左栏底部 | 无 | 账号块整块删除（含 72px 抽屉里的身份行） |
| 「我的服务器」左栏空态 | `登录后查看你的服务器` 文字链接（仅未登录） | 任务提示，点击开同一个登录弹窗；不带头像、不显示状态 |

「一个入口」指**一个账号界面**：头像与菜单只出现在导航。左栏那句链接是「这列内容需要登录」的说明，作用等同于「配置读取失败 → 重新读取」，不承担身份展示。

---

## 2. 头像规则

| 状态 | 图形 | 尺寸 | 颜色 |
|---|---|---|---|
| 已登录 | 邮箱首字母 | 24×24 圆 | 底 `#5B5850`、字 `#FFFFFF`（7.1:1） |
| 未登录 | 空心人形 | 24×24 | 1px `--hair-strong` 描边，人形 `--ink-3`，无填充 |
| 读取中 | 无字骨架 | 24×24 | `--hair` 填充 |

- 首字母取 `email.trim()` 第一个字符；拉丁字母转大写；数字/中文原样；取不到退回人形。
- 字 11 / 600 / 行高 1，居中。同一邮箱头像固定，不随机配色。
- 按钮热区仍是 40×40（`activity__item`），头像 24 居中。

---

## 3. 左栏：删账号块，空态用链接

### 3.1 删除范围

- 删 `MyServersAccount` 在 `MyServersRail` 里的渲染，以及它的全部状态（展开、登出确认、钱包加载）。
- 删 72px 抽屉/图标栏里的身份行（`rail__identity` 那一个）。
- 保留 `我的服务器` 标题行与 `＋`；`＋` 的行为见 §6。

### 3.2 未登录

```
┌ 我的服务器            0   ＋ ┐
│                              │
│ 登录后查看你的服务器         │   13 / --link，可点
│                              │
└──────────────────────────────┘
```

- 文案：`登录后查看你的服务器`（沿用 `my-servers.md` §7.5，不改字）。
- 样式：13 / 500 / `--link`（`#C2185B`，深色 `#F48FB1`）；左对齐，行内边距 `12px 16px`，**最小高度 44**；静止无下划线，hover / `:focus-visible` 加下划线，focus 环 `--focus`、offset 2。
- 位置：列表区内容起点（与服务器行同一左边距 16），不固定在底部。
- 点击：打开现有登录弹窗（与导航头像同一个入口函数）；登录成功后左栏自动刷新为服务器列表。
- 不带头像、不带「未登录」二字、不显示 loading 占位：读取中直接显示三行骨架（现有逻辑），骨架消失后再决定是这句还是列表。

### 3.3 已登录

| 情况 | 左栏 |
|---|---|
| 有服务器 | 只有列表；底部留空，没有邮箱、余额、充值、登出 |
| 零台 | `还没有服务器`（13 / `--ink-3`），不加按钮；上方的 `＋` 就是新建入口 |
| 账户读取失败 | `账户暂时读不到` + `重试`（13 / `--ink-3` + 文字链接），不冒充「未登录」 |

- 余额摘要不留在左栏：导航菜单一开就能看到，左栏重复会让同一事实有两个住处。
- 未登录时左栏不显示任何余额占位（没有 `—`、没有 `余额 --`）。

---

## 4. 导航头像的点击行为

| 账户状态 | 点击 | 结果 |
|---|---|---|
| 未登录 | 直接开登录弹窗 | 不展开菜单——菜单里没有可看的内容 |
| 已登录 | 展开账号菜单 | 菜单锚在图标右侧，间距 12 |
| 读取中 | 展开菜单，显示 `正在读取账户…` | 不出现死点击 |
| 读取失败 | 展开菜单，显示 `账户暂时读不到` + `重试` | 重试成功后按真实状态切换 |
| 登录过期 | 切回未登录，**不自动弹窗** | 一次 toast `登录已过期，请重新登录。`；下次点头像再开登录弹窗 |

- 菜单开着时再点头像 = 收起；`Esc`、点外部也收起。
- `aria-label`：未登录 `登录`；已登录 `账户`；有未读提示时（如余额不足）在 `aria-label` 末尾加一句，不加角标。

## 5. 账号菜单

从导航头像展开，锚在图标右侧，垂直对齐图标。

```
┌ 280 ──────────────────────────────┐
│ (V)  buyer@example.com            │   高 48
│      已登录 · 这台设备             │
├───────────────────────────────────┤
│ 余额   $12.30              [充值]  │   高 48
├───────────────────────────────────┤   1px --hair
│ 退出登录                           │   高 36，--red
└───────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 容器 | 280 宽、`--card` 底、1px `--hair-strong`、圆角 10、`0 8px 24px rgba(23,22,20,.12)`、内边距 8 |
| 头部 | 28 头像 + 间距 10 + 两行：邮箱 13/`--ink`/500（单行末尾省略，`title` 全名）、`已登录 · 这台设备` 11/`--ink-3` |
| 余额 | 标签 `余额` 11/`--ink-3`；金额 20 mono `--ink`；右侧 `充值` ghost，高 28 |
| 分隔 | 1px `--hair`，上下 8 |
| 退出登录 | 文字按钮，`--red`，高 36，左对齐，无填充 |
| 账单 | **本轮不放**：还没有页面，现在点只弹「下一版接入」 |

- 菜单里没有「设置」「个人资料」「切换账户」。
- 不出现第二个主按钮：`充值` 只是 ghost。
- 加载 / 失败：
  - 账户读取中：头部骨架 + `正在读取账户…`，余额行 `读取中`；
  - 余额读取中：金额位 `读取中`（不写 `—`）；
  - 余额失败：`余额暂时读不到。` + `重试`；
  - 未登录（从加载态落下来）：头部人形 + `未登录`，底部 `登录` 按钮；
  - 登出失败：菜单内 `role="alert"`，`没能退出登录，稍后再试。` + `重试`，菜单保持打开。
- 登出**不做二次确认**：不删除服务器、配置或节点，重新登录即恢复。成功收菜单 + toast `已退出登录`。

## 6. 与「我的服务器」左栏的关系

`stage-pages-review.md` §1.1 把「我的服务器」的 `＋` 改为切到 client 舞台的新建节点页后，左栏只剩列表。路径仍然闭合：

```
未登录 · 任意 destination
  ├─ 导航头像（左下，始终可见）──▶ 登录弹窗 ──▶ 已登录
  └─ 我的服务器 · 左栏空态「登录后查看你的服务器」──▶ 同一个登录弹窗
已登录 · 我的服务器
  ├─ 左栏列表（无账号块）
  ├─ 标题行 ＋ ──▶ client 舞台「新建节点」
  └─ 导航头像 ──▶ 菜单（余额 / 充值 / 退出登录）
```

- 左栏没有账号块，不会让登录入口消失：导航头像在每个 destination 都在，位置固定、热区 40×40。
- 左栏空态链接只在未登录时出现，登录后自动变成列表或 `还没有服务器`，它不是常驻的第二入口。
- 新建节点页需要登录时（创建前校验），仍走现有就地登录，与导航入口是同一个弹窗。

## 8. 文案原文

- `登录后查看你的服务器`（左栏空态链接）
- `还没有服务器`（已登录零台）
- `账户暂时读不到`
- `正在读取账户…`
- `未登录`（菜单加载后落到未登录时）
- `登录`
- `余额`
- `余额读取中…`
- `余额暂时读不到。`
- `读取中`
- `充值`
- `退出登录`
- `已退出登录`
- `没能退出登录，稍后再试。`
- `登录已过期，请重新登录。`

统一用 `退出登录`，不用「登出」；不加感叹号。

---

## 9. 不做

- 不在左栏放头像、邮箱、余额、登录按钮或账号块。
- 不做第二套账号菜单（左栏不再有自己的展开层）。
- 不做随机彩色头像、上传头像、多账户切换。
- 不在菜单里放「设置」「个人资料」「账单」（账单等页面存在再加）。
- 不改导航宽度、图标尺寸与选中态。

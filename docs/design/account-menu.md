# 账户区：导航头像 + 账号菜单

> 日期：2026-11-17
> 状态：设计定稿，待实现。只出方案与文案，不改 React 代码。
> 依据：`docs/design/ai-first-product.md`（登录只在购买服务器与查看账单时需要）、`veyl-ui` §2.1 / §2.2 / §3.1 / §6、`docs/design/prototype/servers.html`。
> 现状问题：设置出现两次（`App.tsx` 活动栏一个、`MyServersRail.tsx` 左栏底部一个）；账号块只有邮箱，没有身份图形；导航的账户图标点击后跳到「我的服务器」，不是账户。

---

## 0. 结论

1. **删掉左栏底部的「设置」**，设置只保留在 56px 导航；左栏底部只剩账户行。
2. **账户行用头像 + 身份 + 余额摘要**；点头像行才展开菜单，菜单里放余额、充值、退出登录。
3. **导航头像就是账户入口**：点击打开同一个账号菜单（右侧浮层），不再跳「我的服务器」；未登录时它显示人形，登录后显示首字母头像。
4. **不保留登出二次确认**：登出不删除任何服务器、配置或节点，重新登录即恢复；按 GitHub / VS Code / Slack 的做法直接退出，给一次 toast。
5. **本轮不放「账单」**：账单页还没有实现，现在点只弹「下一版接入」；等页面存在再加进菜单。

## 2. 头像规则

| 状态 | 图形 | 尺寸 | 颜色 | 说明 |
|---|---|---|---|---|
| 已登录 | 邮箱首字母 | 28×28 圆 | 底 `#5B5850`、字 `#FFFFFF` | 白字对比度 **7.1:1**；不引入新色相（与 `--ink-2` 同族） |
| 未登录 | 空心人形 | 28×28 圆 | 1px `--hair-strong` 描边、人形 `--ink-3`、无填充 | 中文界面不出现 `login` / `sign in` |
| 读取中 | 无字骨架 | 28×28 圆 | `--hair` 填充 | 不显示字母，避免读错身份 |

**首字母取值**：`email.trim()` 的第一个字符；拉丁字母转大写；数字或中文原样保留；取不到字符时退回人形图标。

**字重与字号**：12 / 600 / 行高 1，居中；不加 `text-transform` 以外的样式。邮箱相同则头像相同，不按会话变化。

**导航头像**：同一规则缩小到 24×24（字 11/600），点击热区仍是 40×40 的 `activity__item`。

## 3. 账号行（左栏底部）

### 3.1 未登录

```
┌ 248 ─────────────────────────────────────┐
│ (人形)  未登录                       [登录] │   高 44
└──────────────────────────────────────────┘
```

- 头像 28 + 间距 8 + `未登录` 13 / `--ink-2`；右侧 `登录` 次按钮：高 28、内边距 0 10、圆角 6、1px `--hair-strong`、13/500、文字 `--ink`。
- 整行不是按钮；只有 `登录` 可点（点行不做任何事，避免出现一个没有反馈的热区）。
- 读取中：行内文字 `正在读取账户…`（13 / `--ink-3`），**不显示** `登录`，避免登录与已登录之间闪一下。

### 3.2 已登录

```
┌ 248 ─────────────────────────────────────┐
│ (V)  buyer@example.com              ⌄    │   高 52
│      余额 $12.30                          │
└──────────────────────────────────────────┘
```

- 头像 28 + 横向 8；两行文本列：第一行邮箱 13 / `--ink` / 500，第二行 `余额 $12.30` 12 / `--ink-3`（数字套 `.num`）。
- 邮箱**单行末尾省略**，可显示宽度 = 248 − 12×2 − 28 − 8 − 12(chevron) ≈ 164px；`title` 放完整邮箱。`@` 后域名优先保留（先截 local part），实现不了就整串末尾省略。
- 右侧 chevron 12 / `--ink-3`，展开 `⌃`、收起 `⌄`（现有写法不变）。
- 整行是按钮：`aria-expanded` / `aria-controls`；点击展开或收起。
- 余额摘要**不允许长期停在 `—`**：读取中写 `余额读取中…`；失败写 `余额读不到`（`--amber`，不点击，点行展开重试）。

### 3.3 72px 图标栏

只放 24×24 头像，居中；不显示文字与余额；`aria-label` 为 `账户，未登录` / `账户，buyer@example.com`；点击直接打开账号菜单（浮层），不展开左栏。

## 4. 账号菜单（展开层）

### 4.1 位置与尺寸

- 从账号行**向上**展开（左栏底部），宽度 248（与左栏内容同宽），与行间距 6；`--card` 底、1px `--hair-strong`、圆角 10、`box-shadow: 0 8px 24px rgba(23,22,20,.12), 0 1px 2px rgba(23,22,20,.06)`。
- 从导航头像打开时：锚在图标右侧，间距 12，宽度 280，垂直居中对齐图标；同一个组件，只换锚点。
- 同一时刻只有一个菜单；从另一入口打开会先关掉旧的。
- `Esc`、点遮罩/外部、再点一次触发按钮都收起；菜单内焦点按 Tab 顺序移动，打开时焦点落在第一项。

### 4.2 内容与顺序

```
┌ 余额 ────────────────────────┐
│ $12.30                  [充值] │   高 40
├───────────────────────────────┤   1px --hair，上下 8
│ 退出登录                       │   高 36，危险色文字
└───────────────────────────────┘
```

| 项 | 位置 | 行为 | 样式 |
|---|---|---|---|
| 余额 | 第 1 行 | 只读；读取失败时这一行变成 `余额暂时读不到。` + `重试` 文字按钮 | 标签 `余额` 11/`--ink-3`；金额 20 mono `--ink`；`充值` ghost 高 28 |
| 充值 | 第 1 行右侧 | 打开现有充值弹层 | `.btn--ghost`，不抢主按钮 |
| 退出登录 | 分隔线后，唯一项 | 直接执行；成功后收菜单 + toast `已退出登录`；失败留在菜单里给原因 | 文字按钮，`--red`，高 36，左对齐；不用红色填充 |
| 账单 | — | **本轮不放**；有页面后再加在「充值」下面 | 预留 |

- 菜单里没有「设置」「头像」「邮箱」重复行：邮箱在上面的行里已经显示。
- 菜单**不出现第二个主按钮**：充值只是 ghost；这一屏没有实心按钮。

### 4.3 登出确认

**不做二次确认。** 理由：登出不删除服务器、配置或节点（现有文案也已写明），重新登录即恢复；GitHub、VS Code、Slack 都是直接退出。误点的代价是再登录一次，不是丢东西。失败时才给结果，不留假确认。

登出成功文案：toast `已退出登录`。失败文案：菜单内 `role="alert"`，`没能退出登录，稍后再试。` + `重试`。

## 5. 加载与错误

| 状态 | 账号行 | 菜单 | 备注 |
|---|---|---|---|
| 账户读取中 | 骨架头像 + `正在读取账户…` | 不可展开 | 不显示「登录」 |
| 未登录 | 人形 + `未登录` + `登录` | 不展开（没有可看的） | 点「登录」走现有登录弹窗 |
| 已登录 · 余额读取中 | 第二行 `余额读取中…` | 金额位 `读取中` | 不写 `—` |
| 已登录 · 余额失败 | 第二行 `余额读不到`（`--amber`） | `余额暂时读不到。` + `重试` | 重试只重拉钱包，不重登 |
| 登录过期（`auth_required` / `token_invalid`） | 切回未登录态，头像换人形 | 关闭 | 一次 toast `登录已过期，请重新登录。`；不显示旧邮箱 |
| 登出失败 | 保持登录态 | 菜单内错误 + `重试` | 不关闭菜单 |
| 网络失败读账户 | 人形 + `账户暂时读不到` + `重试` | 不可展开 | 不冒充「未登录」 |

## 6. 导航账户图标

**改：点导航头像打开账号菜单，不再切换到「我的服务器」。**

理由：

1. 账户是全局对象，不属于「我的服务器」这一个 destination；现在的行为让「账户」变成「服务器」的同义词，用户想充值却先看到服务器列表。
2. 未登录时点它跳过去只能看到「未登录 + 登录」，多一次无意义跳转；登录后它又不告诉用户余额。
3. GitHub、VS Code、Slack 的左下/右上头像都是菜单，不是页面跳转。

用户路径：

```
任意 destination → 点左下头像 → 浮层：余额 / 充值 / 退出登录 → Esc 回到原处
「我的服务器」destination → 左栏底部账号行 → 同一个浮层（锚在行上）
```

- 未登录点导航头像：直接打开登录弹窗（菜单里没有内容可看），不切 destination。
- 已登录点导航头像：打开菜单；若在「我的服务器」，左栏账号行同时展开同一个菜单（只开一个）。
- 图标在登录后显示首字母头像，未登录显示人形；`aria-label` 分别为 `账户` / `账户，未登录`。

## 8. 文案原文

- `未登录`
- `正在读取账户…`
- `账户暂时读不到`
- `登录`
- `余额`
- `余额读取中…`
- `余额读不到`
- `余额暂时读不到。`
- `重试`
- `充值`
- `退出登录`
- `已退出登录`
- `没能退出登录，稍后再试。`
- `登录已过期，请重新登录。`

不用「登出」，统一用 `退出登录`；不用「请」以外的客套，不加感叹号。

## 9. 不做

- 不做设置头像（没有上传与存储）。
- 不做随机彩色头像：一屏已有状态点与强调色，再加一组身份色会破坏「一屏不超过两种彩色」。
- 不做多账户切换。
- 不在账号菜单里放「账户设置 / 个人资料」等空入口。
- 不改活动栏的高度、图标尺寸与选中态。

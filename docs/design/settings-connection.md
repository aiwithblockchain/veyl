# 设置 · 连接：一屏收干净

> 本文替换 `settings-advanced.md` §2.2 里「连接」这一屏的布局与文案，其余 tab 不动。
> 目标：端口只出现一次，能复制也能改；每行只留用户不知道的那句话；标题不再和 tab 名重复。

## 1. 这一屏只回答四个问题

1. 现在怎么连（全部流量 / 只有代理软件）
2. 用哪个节点
3. 别的软件要填什么地址（可复制、可改端口）
4. 节点从哪来（更新试用节点、导入文件）

「连接 / 断开」按钮只在主界面，这里不放。

## 2. 默认态

```
 设置                                          连接
 ──────────────────────────────────────────────────────

 现在怎么连
 只有设置了代理的软件走 VPN
 要换方式：新建一套配置
 ──────────────────────────────────────────────────────
 用哪个节点                                       ›
 东京 01
 ──────────────────────────────────────────────────────
 本地代理端口                         [复制] [编辑]
 127.0.0.1:7890
 别的软件要填代理地址时，填这个。
 ──────────────────────────────────────────────────────
 更新试用节点                       [检查更新]
 2 个节点 · 6 小时前检查过
 ──────────────────────────────────────────────────────
 导入节点文件                            [导入]

```

- 没有页内大标题。tab 已经叫「连接」，内容直接从第一行开始。
- 端口行是唯一出现地址的地方。地址用 mono、`--ink-2`，一行读完。
- 右侧只有 ghost 按钮，不新增控件形态。
- 节点行可点时整行是按钮：鼠标悬停有底色，行右侧一个弱化的 `›`（与折叠区的 `▸` 同一档重量）。不可点时没有 `›`，也没有悬停。

## 3. 编辑态

点「编辑」后，同一个位置换掉值行，其余行不动：

```
 本地代理端口                            [保存] [取消]
 127.0.0.1:[7890]
```

```
 本地代理端口                            [保存] [取消]
 127.0.0.1:[7890]
 小于 1024 的端口通常要管理员权限，不建议用。      ← 输入 80 时
```

- 主机部分固定，只改端口号。不让人手打一个地址，也不会出现非法主机。
- 输入框宽度按 5 位数字定死，切换编辑态时行高与右侧按钮位置不跳。
- 复制在编辑态隐藏：地址正在改，复制旧值会误导。

## 4. 状态变体

| 情况 | 地址显示 | 行下 |
|---|---|---|
| 未连接 | 保存的端口 | 代理配置：「别的软件要填代理地址时，填这个。」 |
| 已连接，端口没顺延 | 实际端口（同保存值） | 代理配置且系统代理已设：「浏览器已经设好了；其它软件填这个地址。」代理配置但系统代理没设：用上面那句通用说明 |
| 已连接，端口被占而顺延 | 实际端口 | 代理配置：「保存的是 7890；现在是顺延后的端口。」 |
| 全部流量配置 | 保存的端口 | 无说明 |
| 端口保存后返回「被占用」 | 保存的值 | 黄字：「现在被别的软件占用，连接时会自动顺延。」 |
| 端口保存后返回「绑不上」 | 保存的值 | 黄字：「这台机器绑不了这个端口（需要管理员权限），连接时会自动顺延。」 |

复制按钮永远复制地址行上显示的那个端口——已连接时是能用的那个，不是保存值。

## 5. 逐行最终文案

| 行 | 标签 | 值 / 说明 | 右侧 |
|---|---|---|---|
| 1 | 现在怎么连 | `全部流量走 VPN` 或 `只有设置了代理的软件走 VPN` | — |
| | | 有配置：`要换方式：新建一套配置`（「新建一套配置」可点） | |
| | | 无配置：`还没有配置` / `先在左侧新建一套配置，再回来这里看。` | |
| 2 | 用哪个节点 | 节点名；多个节点时整行可点 | `›` |
| | | 无节点：`还没有节点` / `先导入节点或更新试用节点。` | |
| 3 | 本地代理端口 | `127.0.0.1:7890` | `复制` `编辑` |
| | | 代理配置时一句：`别的软件要填代理地址时，填这个。` | |
| | | 编辑态：`127.0.0.1:[7890]` | `保存` `取消` |
| 4 | 更新试用节点 | `2 个节点 · 6 小时前检查过`；没有节点时 `还没有试用节点 · 从未检查过` | `检查更新` |
| 5 | 导入节点文件 | 无 | `导入` |

按钮词固定：`复制` / `编辑` / `保存` / `取消` / `检查更新` / `导入`。同一动作前后同一个词。

## 6. 端口编辑的交互

**进入**
- 点「编辑」，或键盘聚焦「编辑」后回车 → 输入框出现、自动聚焦并全选端口号。
- 任何时刻只有这一行进入编辑态。

**退出**
- 保存：点「保存」或输入框内回车。
- 取消：点「取消」或 Esc。Esc 只退出编辑，**不关闭设置**（编辑态先拦下 Esc）。
- 点行外：**不退出编辑**，输入保留。刚输入的端口不能因为点了别的行就静默消失。
- 切 tab、关设置：放弃未保存的改动。
- **不再失焦自动保存。** 改端口从「随手一改就生效」变成一次明确的保存。
- 保存或取消后，焦点回到「编辑」按钮。输入框消失时焦点不能掉到页面上，键盘用户要能接着操作。

**保存中**
- 「保存」变「保存中…」并禁用，「取消」禁用，输入只读。
- 其它行不受影响。

**保存成功**
- 退出编辑，地址立即更新。
- 未连接：行下 `已保存`。
- 已连接：行下 `已保存，下次连接生效`；地址仍是当前实际端口。这句提示保留到再次编辑或离开这个 tab，让「输入值 ≠ 显示值」有解释。

**保存失败**（后端报错）
- 留在编辑态，输入内容不丢。
- 行下红字：优先用后端给的 message；没有就用 `没有保存，端口还是原来的。再试一次。`
- App 里的端口、地址行都不变。

**校验失败**
- 空、0、超过 65535、非整数：不发请求，留在编辑态，红字 `端口要填 1–65535 之间的整数。`

**读屏与标签**
- 可见的「本地代理端口」用 `label for` 绑到输入框，不靠 `aria-label` 另起一个名字。
- 当前生效的那条提示或错误用 `aria-describedby` 挂到输入框上。
- 错误用 `role="alert"`（会打断朗读），保存成功用 `role="status" aria-live="polite"`。颜色只是辅助，文字本身说清结果。

## 7. 三种端口提示放在哪

| 提示 | 什么时候知道 | 放哪 | 文案 |
|---|---|---|---|
| 小于 1024 | 输入时就知道 | **编辑态**，输入行下方 | `小于 1024 的端口通常要管理员权限，不建议用。` |
| 被别的软件占用 | 保存返回时才知道 | **默认态**，行下方 | `现在被别的软件占用，连接时会自动顺延。` |
| 这台机器绑不上 | 保存返回时才知道 | **默认态**，行下方 | `这台机器绑不了这个端口（需要管理员权限），连接时会自动顺延。` |

- 小于 1024 是「改之前」的提醒，只在编辑态出现；保存后不再常驻。
- 另外两条是「保存那一刻」的探测结果，只在本次打开设置期间保留；关闭后不显示，连接时会重新判断。界面不假装它是永久结论。
- 两条同时成立时只显示「绑不上」那条（低端口提示不再叠上去）。

## 8. 删掉了什么，为什么

| 删掉 | 为什么 |
|---|---|
| 第 1 行的 `127.0.0.1:7890` + `复制` | 同一个事实出现两次；地址与端口合成一行 |
| `点这里可以换节点。` | 整行可点 + `›` + 悬停底色已经说明；点击行为由「点这里」变成整行 |
| `这套配置只有一个节点。` | 只有一个节点时行不可点、也没有 `›`，不需要解释为什么点不动 |
| 端口行的长解释：`别的软件要填代理地址时，用的是这个端口。改一次，以后每次连接都用它。` | 压成半句 `别的软件要填代理地址时，填这个。`；「以后每次都用」是默认预期，不用写 |
| 常驻输入框与 `保存` 按钮 | 平时是只读地址 + 复制；要改才进编辑态 |
| 试用节点摘要里的 `Veyl 提供的` | 标签已经叫「试用节点」，归属不用再说一次 |
| 页面上的 `导入不需要联网。` | 挪进导入弹层，和「文件里有节点密码，不要外传」放在一起 |
| 小节标题 `连接` | 与 tab 名重复，白占一行 |

保留没动的：`要换方式：新建一套配置`（唯一换方式的出口）、浏览器已设好的说明（只在代理模式已连接时出现）、更新试用节点的检查结果行、导入弹层的全部内容。

## 9. 10 秒自评

扫一眼这一屏，应该能说出：走的是全部流量还是代理、当前是哪个节点、地址是多少、地址能复制、端口怎么改、节点从哪来。任何一行都不需要读第二遍。

## 10. 不做什么

- 不改四个 tab 的信息架构，不动 AI 助手 / 遇到问题 / 关于。
- 不新增组件：仍是行、ghost 按钮、行内反馈；`›` 与折叠区的 `▸` 同一档。
- 不移走「连接 / 断开」以外的任何主界面功能；不在设置里加连接按钮。
- 不引入 `proxy`、`TUN`、`分流`、`规则集` 这些词。
- 不改后端的端口探测与顺延逻辑，只改展示与保存入口。

## 11. 依据（ui-ux-pro-max，按优先级低于 veyl-ui）

这次真正影响取舍的几条：

| 规则 | 落在哪 |
|---|---|
| Forms · Submit Feedback：提交要有 loading → 成功/失败三态 | 保存中… / 已保存 / 红字失败，且都留在原地 |
| Interaction · Loading Buttons：异步中禁用按钮，防重复提交 | 保存中禁用「保存」与「取消」 |
| Forms · Error Placement：错误贴在对应字段下，并用 aria-describedby 关联 | 端口错误在输入行下方，不放到页面顶部 |
| Accessibility · Error Messages：错误要能被读屏播报 | 错误 role=alert，成功 role=status |
| Interaction · Hover States + Compact Control Semantics：可点元素要有悬停反馈，且不能只靠悬停暴露动作 | 节点行是原生按钮 + 悬停底色 + `›` |
| Accessibility · Keyboard Navigation / Focus States：每个操作都能用键盘完成，焦点始终可见 | Esc 只退编辑，保存/取消后焦点回到「编辑」 |

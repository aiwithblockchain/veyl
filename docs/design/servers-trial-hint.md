# 「我的服务器」里的免费节点：一行只读说明

> 日期：2026-11-18
> 状态：设计定稿，待评审。只出文档，不改代码。
> 依据：`veyl-ui` §2.1（一屏一个主动作）/ §2.2（一个事实一个住处）/ §6、`ui-ux-pro-max` §9 `empty-nav-state` / `progressive-disclosure` / `navigation-consistency`、`servers-list-detail.md` §1.2–§1.4、`account-menu.md` §3、`node-card-sources.md` §2。
> 问题：要不要在「我的服务器」里也显示免费试用中的节点？怎么显示？

---

## 0. 结论

**不做成服务器行，也不做顶部提示条；做成空态里的一行只读说明 + 一个 `去控制台` 文字链接。**

```
还没有服务器
买一台装好后，节点会出现在这里，也能直接用来连接。
还有 2 个免费节点，6 天后到期。 去控制台
[ 新建节点 ]
```

- **只在用户自己的服务器为 0 时出现**；一旦有自建服务器，这行连同整个空态一起消失。
- **句子随试用状态变**：还没首次连接写 `还有 2 个免费节点，试用 7 天。`（此时没有到期时间）；进行中写 `…，6 天后到期。`；已到期整行消失。
- 它不是资产行：没有 hover 底、没有箭头、不能选中、不能右键、没有销毁。
- 唯一的可交互物是 `去控制台`——切到连接 destination，不做别的事。

一句话：**它不回答「我有哪些资产」，只回答「这页为什么是空的、以及你不是没得用」。**

---

## 1. 形态：为什么是空态里的一行

| 候选 | 判断 |
|---|---|
| **空态里的一行只读说明** | **采用。** |
| 服务器列表里的一行（分组行） | 否。列表的行意味着「可选中 → 中间出详情」；试用节点没有详情、不能重建、不能销毁。做成行就是「点得动但什么也不发生」，是这一页最不该出现的东西（`ui-ux-pro-max` `navigation-consistency`）。 |
| 页面顶部提示条 | 否。提示条要和列表并存，但这条信息**只在没有列表时才需要**——有自建服务器时我们本来就要让它消失。为一段「只在空页出现」的内容做一个横幅，等于给一个不存在于有内容状态下的元素设计一个新组件。 |
| 左栏里加一行 | 否。左栏的职责是「资产列表 + 计数」。试用节点不是资产，进左栏会让 `我的服务器 0` 这个计数变成假话。 |

**为什么放在空态里而不是页顶**：空态是垂直居中的（`stage-pages-review.md` §6.2）。在它上面再压一条横幅，一屏会出现两个视觉重心，中间还空着一大块；放进去以后，整页只有一个块，顺序是「你为什么空 → 你其实还有东西 → 下一步做什么」。

## 2. 位置与规格

插在空态说明与主按钮之间：

| 元素 | 值 |
|---|---|
| 位置 | `.myservers__empty` 内，说明句之后、主按钮之前 |
| 与说明的距离 | **12** |
| 与主按钮的距离 | **16** |
| 字号 / 行高 | 13 / 1.6 |
| 事实句颜色 | `--ink-3`（比说明句 `--ink-2` 弱一档：它不是这一页的主题，是旁注） |
| 链接 | `去控制台`，13 / 500 / `--link`；距句号 8；hover / focus 加下划线 |
| 链接命中区 | `::after { inset: -12px -6px }` → 约 44 高，不改行高、不推动布局 |
| 最大宽 | 400（与说明句一致），**不折行**——句子长度按最多 `两位数天数` 预留 |
| 无障碍 | **不加额外 `aria-label`**：可见文字 `去控制台` 已经够用，它紧跟在「还有 2 个免费节点，6 天后到期。」后面，读屏按顺序念下来就是完整的一句话。用 `aria-label` 覆盖，反而会把这层上下文切掉。不加 `role="status"`——它不是状态变更 |

- 不加底色、不加描边、不加图标、不加箭头。
- 深色主题无需单独取值：`--ink-3` 与 `--link` 都已有深色定义。

## 3. 文案

### 3.1 原文

| 场景 | 文案 |
|---|---|
| 已加入、还没首次连接 | `还有 2 个免费节点，试用 7 天。` + `去控制台` |
| 进行中 · 2 个、剩 6 天 | `还有 2 个免费节点，6 天后到期。` |
| 进行中 · 1 个、剩 6 天 | `还有 1 个免费节点，6 天后到期。` |
| 进行中 · 剩不足 1 天 | `还有 2 个免费节点，不到 1 天后到期。` |
| 链接 | `去控制台` |

- **统一叫 `免费节点`**，与节点卡的组名一致；不用「免费试用节点」。组名是 `免费节点`、这里也是 `免费节点`，用户在两屏看到的是同一个名字。是不是试用，由句尾的 `试用 7 天` / `N 天后到期` 说明。
- 不用「免费节点剩余 2 个」这种倒装；不用「你将失去」这类恐吓；不加感叹号。
- 不在这一行写「免费节点不保证稳定」——那是连接页的事，这里只说数量和期限。

**为什么未开始要单独一句**：试用的 7 天是从**首次连接种子节点**才开始计的（`src-tauri/src/trial.rs:52-58`：`started_at` 为空时返回 `Phase::Available`、`expires_at = null`）。所以「节点已经在卡片里、能连，但还没有到期时间」是一个真实存在的状态。这时写不出「N 天后到期」，只能写期限本身——`试用 7 天`，与节点卡副行的 `· 7 天试用` 同词，读起来是同一件事。

### 3.2 「N 天后到期」的取整规则（**两地共用**）

- 剩余时间 ≥ 24 小时：**向下取整**。剩 6 天 9 小时 → `6 天后到期`。
  - 取整方向选向下，是因为**少报是安全的、多报不是**：用户按「还剩 6 天」安排，实际有 6.4 天；反过来按 7 天安排就会措手不及。
- 剩余 < 24 小时：`不到 1 天后到期`。
  - 不用「今天到期」：到期时刻可能是明天凌晨 3 点，说「今天」就是错的。
- 已经到期：这一行**直接消失**，不出现 `已到期` 这个状态——到期后节点已被移除，这里没有可说的对象。
- **这条规则同时约束 `node-card-sources.md` §2 的组标题右侧文字**；那份文档已按同一规则改写，两处必须同一个数。
- ⚠️ **实现现状与本文不一致**：`ConnectionStage.tsx:359-366` 现在是 `Math.ceil` + `今天到期`。落地时两处要一起改成向下取整 + `不到 1 天后到期`，否则设计文档和界面各说一套。

## 4. 状态

### 4.1 试用自身：三种状态，决定这一行写什么

| 试用状态 | 节点池 | 这一行 |
|---|---|---|
| `available`：已加入、**还没首次连接** | 种子节点已在池里、可连 | `还有 2 个免费节点，试用 7 天。` |
| `active`：进行中 | 同上 | `还有 2 个免费节点，6 天后到期。` |
| `expired`：已到期 | 种子节点已移除 | **不显示** |

- 三种状态都读同一个 `trial` 状态（`useVpnSession` / `trial_status`），**不在这一页自己算时间**。
- `available` 是一个真实存在的状态，不是边界：时钟从首次连接种子节点才起。

### 4.2 页面状态

| 状态 | 左栏 | 中间 | 这一行 |
|---|---|---|---|
| 未登录 + 池里有免费节点 | `我的服务器 0 ＋` | `先登录` + 说明 + `登录` | **显示**（在说明与 `登录` 之间） |
| 已登录 · 0 台 + 池里有免费节点 | `我的服务器 0 ＋` | `还没有服务器` + 说明 + `新建节点` | **显示** |
| 已有 ≥1 台服务器 | 列表 | 第一台详情 | **不显示**（整个空态都不在） |
| 账户读取中 / 读取失败 | 三行骨架 / 不写账号提示 | 骨架 / `账户暂时读不到` + `重试` | **不显示**：错误态不该夹带旁注 |
| 池里没有免费节点（从没领过 / 已到期） | — | 空态照常 | **不显示** |

- **未登录也显示**：免费节点是**本地**的，与账号无关（`stage-empty-logged-out.md` §5）。但它的对象不是「刚打开产品的人」——那种情况还没加入试用，池里 `seed = 0`，这行根本不会出现。它的对象是**已经领了试用、还没建自己服务器的人**：在这一页看到一句「你其实已经有能用的东西」，比整页只有「先登录」更诚实。
- 左栏计数**不包含**免费节点：`我的服务器 0` 说的是服务器台数，不是节点数。这一点要在实现里守住，否则同一个 `0` 会有两种含义。

## 5. 点击与键盘

| 操作 | 行为 |
|---|---|
| 点 `去控制台` / `Enter` / `Space` | **切到 client destination**，落在连接舞台；不新建页面、不弹窗、不滚动到某一行 |
| 键盘可达 | `去控制台` 是 `<button>`，Tab 顺序在说明句之后、主按钮之前 |
| 焦点样式 | `:focus-visible` 2px `--focus`，offset 2 |
| 其他区域 | 整段文字**不可点**：没有 hover 底、没有 pointer 光标；点句子里的空白什么也不发生 |

**为什么不做成整行可点**：整行可点会让它读起来像一条列表项，而它并不是——列表项点下去会在中间出详情，这里点下去是换 destination。同一个页面里，「点一行」不该有两种结果。链接单独标出来，指向明确。

### 5.1 「不可编辑」的具体表达

明确不做下面这些，做任何一个都会让它变成资产行：

- 不可选中（无选中竖条、无 `aria-selected`）
- 不可展开（无箭头、无详情）
- 不可右键（无上下文菜单）
- 不可销毁、不可重建、不可改名
- 不可拖拽、不可勾选
- 不显示 IP、端口、流量、费用——这些是服务器详情的事实，试用节点一个都没有

### 6.1 到期的那一刻

- **靠事件，不靠本地计时**：Host 清理完试用会发 `trial-expired`（`App.tsx:949-957` 收事件后重读试用状态与节点池）。这一页不设 `setInterval` 自减天数、不自己判断「现在过了零点没有」——秒级的时间推演迟早会和库里不一致，而事件只有一个来源。
- 收到事件后：池里没剩免费节点 → 这一行消失；剩着 → 照常。
- 用户正停在这一页时到期：这一行**直接消失**，空态保留，主按钮不变。
- **不弹 toast、不播报**：「免费节点已到期」的提示归连接舞台（`node-card-sources.md` §5.3），在两个地方同时喊一次是噪声。
- 若用户点 `去控制台` 时试用刚好已结束：落到 client 的 `trial_expired` 屏，那是它该管的事。

## 7. 必须改 / 建议改 / 不改

### 必须改（P1）

1. 在 `MyServersPage` 的两处空态（未登录 / 零台）里插入这一行，**位置在说明与主按钮之间**，与说明 12、与按钮 16。
2. 显示条件：`池里免费节点数 > 0` 且 `自建服务器数 == 0`（未登录时按「自建 0」处理）；账户读取中 / 读取失败时不显示。
3. **三种试用状态都要覆盖**（§4.1）：`available` 写 `还有 N 个免费节点，试用 7 天。`；`active` 写 `…，N 天后到期。`；`expired` 不显示。别只做 `active`——`expires_at` 为 null 时界面会没有句子可写。
4. 取整规则按 §3.2（向下取整、< 1 天写「不到 1 天」），**并与 `node-card-sources.md` §2 统一**；**代码现状是 `Math.ceil` + 「今天到期」（`ConnectionStage.tsx:359-366`），要一起改**。
5. 术语统一用 `免费节点`（与节点卡组名一致），不用「免费试用节点」。
6. 只有 `去控制台` 可交互，整段文字不可点；链接是 `<button>`，Tab 顺序在说明之后、主按钮之前；不加 `aria-label`。
7. 到期靠 `trial-expired` 事件重读（`App.tsx:949-957`），不设本地计时。
8. 左栏计数不含免费节点。

### 建议改（P2）

9. 到期时静默消失，不 toast、不播报（由连接舞台负责）。
10. 句子宽度按最多两位数天数预留，不折行。
11. `servers-list-detail.md` §1.2 / §1.3 的两处空态同步补上这一行，避免屏幕规格两处打架。

### 不改

| 项 | 理由 |
|---|---|
| 不做成服务器行 / 分组行 | 没有详情可看，点了什么也不发生——「点得动但没用」是这一页最不该有的东西。 |
| 不做顶部提示条 | 这条信息只在没有内容时需要；有内容时它自己就该消失，不需要一个并存的横幅。 |
| 不改空态的主按钮与说明 | 仍然是 `登录` / `新建节点`，这一行是旁注。 |
| 不把试用节点计入左栏计数 | `我的服务器 0` 是台数，不是节点数。 |
| 不在这一页显示到期 toast | 一处提醒就够，连接舞台已经有。 |

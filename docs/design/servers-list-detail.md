# 「我的服务器」：纯列表 + 详情

> 日期：2026-11-17
> 状态：设计定稿，待实现。只出架构与文案，不改代码。
> 前提：`stage-pages-review.md` §1.1 的单宿主改造落地——建机向导移到 client 舞台，「我的服务器」只剩**列表 + 详情**；左栏账号块已按 `account-menu.md` 删除，底部不再有「设置」。
> 依据：`my-servers.md` §7.1 / §7.2 / §7.4 / §17.3、`ai-first-product.md` §我的服务器、`veyl-ui` §1.3 / §2.2。
> 截图 22 是改造前的混合页（服务器左栏 + 建机向导），本文件只描述改造后的三种状态。

---

## 0. 三种状态

| 状态 | 左栏 | 中间 |
|---|---|---|
| A 列表 · 没有选中 | 服务器列表（有服务器时默认选中第一台） | 有服务器 = 第一台详情；零台 / 未登录 = 空态（**不留白**） |
| B 选中一台 | 列表 + 选中态 | 这台的事实与操作 |
| C 进入建机 | **不出现**（已切到 client 舞台） | client 舞台的「新建节点」 |

一句话：**中间永远有内容**——有列表就一定有详情（默认第一台），没有列表就有空态。

---

## 1. 状态 A：列表与空态

### 1.1 有服务器时没有「未选中」

- 进入 destination：选中上次那台；没有记录就选第一台（`my-servers.md` §7.1「默认第一台」）。
- 选中的服务器被销毁/消失：选下一台；列表空了 → 零台空态。
- 不提供「取消选中」，因此不存在「左边有列表、中间空白」的中间态。
- 点行只换中间详情：不推栈、不动连接、不改变连接状态。

### 1.2 未登录

左栏：只有标题行 `我的服务器 0 ＋`，不写空态文字、不放登录链接（`account-menu.md` §3.2）。

中间：

```
先登录
登录后可以买服务器；服务器装好后，节点会出现在节点池里。
[ 登录 ]                  ← 唯一主按钮
```

- 一屏只有一个登录动作：中间的主按钮。左栏不重复同义提示。
- 中间不显示地区、价格、任何服务器占位行——没登录就没有可看的资产。

### 1.3 已登录 · 零台

左栏：只有 `我的服务器 0 ＋`，不写 `还没有服务器`。

中间：

```
还没有服务器
买一台装好后，节点会出现在这里，也能直接用来连接。
[ 新建节点 ]              ← 唯一主按钮
```

- `新建节点` 与左栏 `＋` 是同一个动作的两个入口（`＋` 是图标动作，不算主按钮）。
- 空态不写「云服务器」「VPS」「实例」这些词，也不写价格。

### 1.4 读取中 / 读取失败

| 状态 | 左栏 | 中间 |
|---|---|---|
| 账户读取中 | 三行骨架 | 与详情同形的骨架，`aria-busy` |
| 账户读取失败 | 不写账号提示 | `账户暂时读不到` + 一句 `检查网络后再试。` + ghost `重试` |
| 服务器列表加载中 | 三行骨架 | 骨架，不闪空态 |
| 列表读取失败 | `连不上服务器，稍后再试` + `重试` | 同一句 + `重试`（与左栏同一个动作，只保留中间这一个按钮） |

- 任何失败都不显示 `—` 或 0 台；「读不到」与「没有」是两件事。

## 2. 状态 B：列表与详情的分工

### 2.1 左栏行（280，两行）

```
● 东京 1 号
  运行中 · 东京 · $0.20/天
```

| 位置 | 内容 | 规格 |
|---|---|---|
| 第一行 | 名称 + 右侧状态点 | 15 / 500；状态点 6×6，`--green` 可用 / `--cobalt` 进行中 / `--amber` 欠费 / `--red` 失败 |
| 第二行 | 状态词 · 地区 · 每日价 | 12 / `--ink-3`；进行中写 `安装中 62%`，失败写 `创建失败`，欠费写 `已欠费` |
| 选中 | 同一套选中态 | `--card` 底 + 左侧 2px `--cobalt` + 名称 600 |
| 不显示 | 创建时间、IP、规格、流量 | 留在详情；列表只回答「哪台、什么状态、多少钱」 |

- 价格只用于区分不同档位；同价时不隐藏，保持一致的可扫描结构。
- 列表里**不显示「正在使用」**：当前节点只住在连接舞台的节点卡（`veyl-ui` §2.2）。
- 行高 64，与配置行 / 组行同构；不用紧凑行。

### 2.2 中间详情

```
东京 1 号                      ● 可用
────────────────────────────────────
地区      日本 · 东京
节点      已就绪
费用      每天 $0.20 · 本期有效至 12-03
流量      每月 1000 GB
────────────────────────────────────
[ 销毁 ]                          [ 连接 ]
```

| 区块 | 内容 | 说明 |
|---|---|---|
| 头部 | 名称 20/600 + 状态（点 + 词） | 状态只在这里出现一次 |
| 事实 | 地区 / 节点 / 费用 / 流量 | 每行 label 11 / `--ink-3`，value 14 / `--ink`；行距 12 |
| 操作 | 左下 `销毁`（danger ghost），右下主按钮 | 一屏一个主按钮 |
| 不显示 | IP、端口、协议、用户名、密码、创建时间、规格 | `my-servers.md` §17.3；规格也未在 §7.4 列出，本轮不加（见 §5） |

### 2.3 主按钮按状态

| 状态 | 主按钮 | 其他 |
|---|---|---|
| 可用（`healthy` / `active`） | **`连接`**：把这台的节点设为当前并连接 | `销毁` danger ghost |
| 正在连接 / 已连接的就是这台 | 主按钮变 `断开` | `销毁` 仍可点（先断再销毁由后端收口） |
| 已连接，但连的是别的节点 | `连接`（先停旧的再连这台，与 `config-switch.md` 一致） | 不弹确认 |
| 安装中（`creating` / `booting` / `installing` / `verifying`） | 不显示；显示四段进度 | `销毁` 唯一出口；进度与左栏 `安装中 62%` 同源 |
| 出错（`error`） | `重新建一台` | `销毁` danger ghost |
| 已失效（`gone`） | `重新购买` | `改用自己的节点` 文字链接 |
| 已销毁（`destroyed`） | 列表不出现，详情不可达 | — |

- 主按钮位置：详情底部的操作行，**右下**；`销毁` 在最左，与主按钮隔开（`veyl-ui` 危险动作分离）。
- 不把主按钮放进左栏行：选中态与「要执行的动作」是两件事，混在一起会让点行变成危险操作。
- 连接动作与连接舞台共用一条运行时路径；服务器页不显示计时器、出口、流量（那些只在 client hero）。

## 3. 状态 C：进入建机与返回

### 3.1 进入

- `＋` 与零台空态的 `新建节点`：**切到 client destination + 打开「新建节点」舞台**；「我的服务器」左栏随之消失（client 是 solo 布局）。
- 记住来源：`from = "servers"` 与进入前的选中服务器。

### 3.2 返回

| 结果 | 去向 |
|---|---|
| `返回` / `Esc`（没有创建） | 回到 `我的服务器`，恢复进入前的那台选中 |
| 创建成功 | **留在 client 舞台**，收敛成节点卡 + `连接`（`ai-first-product.md` §第一次选择自建节点第 5 步）；下次进「我的服务器」时新服务器在第一行 |
| 从节点组带目标组进入 | 保持现有行为：创建成功回组详情 |

- 建机过程中左栏不出现「正在创建」占位行：它不可见，占位没有意义；状态由 client 舞台的步骤流承担。
- 创建失败：留在 client 舞台的失败态，不回服务器列表（用户还在同一个任务里）。

## 4. 直接回答四个问题

| 问题 | 结论 |
|---|---|
| 中间没选中时要不要内容 | **不允许留白**。有服务器就默认选中第一台；没有就是 §1.2–§1.3 的空态。不做「最近操作」「引导块」。 |
| 280 够不够、要不要压成两行 | **280 保留**；行本来就是两行：名称 + 状态点 / 状态词 · 地区 · 每日价。创建时间、规格、流量不进列表（低价值且会截断）。 |
| 「Veyl / 网络控制台」是否保留 | **整块删除**。窗口标题栏已经有 `Veyl`；`网络控制台` 是 client 的副标题；下面一行 `我的服务器 0 ＋` 已经是这一列的名字。删除后列表上移约 56px。 |
| 「我的服务器 0 ＋」与列表是否合并 | **不合并**。它是列表标题 + 计数 + 新建入口，合并到首行会丢掉计数与 `＋`。保留，但 `＋` 的命中区补到 44×44。 |

## 5. 必须改 / 建议改 / 不改

### 必须改（P1）

1. **删掉 servers destination 里的向导分支**（`MyServersPage.tsx:98`），建机只走 client 舞台；`＋` 与零台 CTA 都切过去并记住来源。
2. **中间补空态**：未登录 `先登录` + `登录`；零台 `还没有服务器` + `新建节点`；读取失败 `账户暂时读不到` + `重试`。不能靠向导填充。
3. **左栏去掉品牌块**（`Veyl / 网络控制台`），标题行只留 `我的服务器 0 ＋`。
4. **详情主按钮改为 `连接`**（按状态变 `断开` / `重新建一台` / `重新购买`），放在底部操作行右侧；`销毁` 在左侧。
5. **行第二行补状态词**：`运行中 / 安装中 62% / 创建失败 / 已欠费` · 地区 · 每日价。

### 建议改（P2）

6. 详情事实用两列（label/value），行距 12；不要做成大卡片或分组标题。
7. `＋` 的命中区 44×44（现在偏小），`aria-label="新建节点"`。
8. 空态正文按 §1.2 / §1.3 的短句替换 `my-servers.md` §7.2 的长句（原文提到「云服务器」，界面不出现这个词）。
9. 列表失败与详情失败共用同一个 `重试`，只保留一个按钮。

### 不改

| 项 | 理由 |
|---|---|
| 详情显示 IP / 端口 / 规格 / 创建时间 | `my-servers.md` §17.3 明确不显示 IP、端口、协议、用户名、创建时间；规格也未在 §7.4 列出。要加需先改契约。 |
| 左栏宽度 280（窄屏 260/240） | 两行足够；与其他列表同宽、同一套拖拽范围。 |
| 左栏显示「正在使用」 | 当前节点的唯一住处是连接舞台的节点卡（`veyl-ui` §2.2）。 |
| 列表里显示流量额度 | 低价值；详情有一行。 |
| 选中行点击后立即连接 | 连接是显式动作，点行只换详情。 |
| 服务器页显示计时器 / 出口 | 连接状态只在 client hero。 |

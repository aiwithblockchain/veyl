## 0. 三种状态

| 状态 | 左栏 | 中间 |
|---|---|---|
| A 列表 · 没有选中 | 服务器列表（有服务器时默认选中第一台） | 有服务器 = 第一台详情；零台 / 未登录 = 空态（**不留白**） |
| B 选中一台 | 列表 + 选中态 | 这台的事实与操作 |
| C 进入建机 | 保留列表，但行禁用（`aria-disabled`、45% 透明） | 建机向导——**原地打开，不换 destination** |

一句话：**中间永远有内容**——有列表就一定有详情（默认第一台），没有列表就有空态，正在建机就是向导。

## 1. 状态 A：列表与空态

### 1.1 有服务器时没有「未选中」

- 进入 destination：选中上次那台；没有记录就选第一台（`my-servers.md` §7.1「默认第一台」）。
- 选中的服务器被销毁/消失：选下一台；列表空了 → 零台空态。
- 不提供「取消选中」，因此不存在「左边有列表、中间空白」的中间态。
- 点行只换中间详情：不推栈、不动连接、不改变连接状态。

### 1.2 未登录

左栏：只有标题行 `我的服务器 0 ＋`，不写空态文字、不放登录链接（`account-menu.md` §3.2）。

中间：

```
先登录
登录后可以买服务器；装好后节点会出现在这里，也能直接用来连接。
还有 2 个免费节点，6 天后到期。 去连接
[ 登录 ]                  ← 唯一主按钮
```

- 一屏只有一个登录动作：中间的主按钮。左栏不重复同义提示。
- 中间不显示地区、价格、任何服务器占位行——没登录就没有可看的资产。
- 第三行是免费节点的只读旁注，只在池里有免费节点时出现；`去连接` 切到连接 destination，不引入第二个登录入口。规格见 `servers-trial-hint.md`。

### 1.3 已登录 · 零台

左栏：只有 `我的服务器 0 ＋`，不写 `还没有服务器`。

中间：

```
还没有服务器
买一台装好后，节点会出现在这里，也能直接用来连接。
还有 2 个免费节点，6 天后到期。 去连接
[ 新建节点 ]              ← 唯一主按钮
```

- `新建节点` 与左栏 `＋` 是同一个动作的两个入口（`＋` 是图标动作，不算主按钮）。
- 空态不写「云服务器」「VPS」「实例」这些词，也不写价格。
- 第三行同上：只在池里有免费节点时出现，规格见 `servers-trial-hint.md`。

### 1.4 读取中 / 读取失败

| 状态 | 左栏 | 中间 |
|---|---|---|
| 账户读取中 | 三行骨架 | 与详情同形的骨架，`aria-busy` |
| 账户读取失败 | 不写账号提示 | `账户暂时读不到` + 一句 `检查网络后再试。` + ghost `重试` |
| 服务器列表加载中 | 三行骨架 | 骨架，不闪空态 |
| 列表读取失败 | `连不上服务器，稍后再试` + `重试` | 同一句 + `重试`（与左栏同一个动作，只保留中间这一个按钮） |

- 任何失败都不显示 `—` 或 0 台；「读不到」与「没有」是两件事。

### 1.5 左栏底部的新建入口（2026-11-18）

产品负责人反馈标题旁那个 `＋` 太难找（它是 11px 标题行里的一个 14px 图标，看起来像计数的一部分）。**有服务器时**，左栏列表底部增加一行常驻入口；标题旁的 `＋` 作为快捷入口保留。

| 项 | 规格 |
|---|---|
| 何时出现 | **只在列表非空时**（`servers.length > 0`，且不在加载 / 失败态）。零台空态已经有中间的主按钮，不再加第三处 |
| 文案 | `新建节点`——与全站同一个动作名（标题行 `＋` 的无障碍名、中心空态 CTA、向导标题、到期屏都用这个名字）。**不要写成「新建服务器」**：那会变成第二个名字，点进去看到「新建节点」会以为走错了 |
| 形态 | 整行按钮：高 40、`padding: 0 10px`、左右与列表行同为 8px 缩进、圆角 8；左侧 14px `＋`（`--ink-3`），文字 13 / 500 / `--ink-2` |
| 分隔 | 顶部一条 `1px --hair`，把它和滚动内容分开；与列表间距 8 |
| 滚动 | **固定在列底部，不随列表滚动**。列表本体放进自己的滚动容器（`.rail__body`：`flex:1; min-height:0; overflow-y:auto`），10 台也不会把入口挤走、更不会被 `overflow:hidden` 裁掉 |
| hover / focus | hover 整行 `--bg-hover` + 文字转 `--ink`；焦点用内侧 2px `--focus` 描边 |
| 权重 | 次级：不加实心底、不用品牌粉。详情页主按钮是 `连接`，这行不能和它抢 |
| 向导期间 | 与其它左栏控件一起禁用（`.rail--locked`：45% 透明 + `pointer-events: none`） |
| 抽屉模式 | 抽屉里已有顶部的 `新建节点` 按钮，底部这行不在抽屉内重复 |

- **为什么不放页面标题区的动作栏**：中间区是「某一台服务器」的对象视图，一个全局的创建动作放进去会与 `连接` 并列成第二个主按钮；而左栏是列表所在，列表的「新增」本来就该在列表里。

## 2. 状态 B：列表与详情的分工

### 2.1 左栏行（280，两行）

```
● 东京 1 号
  运行中 · 东京 · $0.20/天
```

| 位置 | 内容 | 规格 |
|---|---|---|
| 第一行 | 名称 + 右侧状态点 | 15 / 500；状态点 6×6，`--green` 可用 / `--cobalt` 进行中 / `--amber` 欠费 / `--red` 失败 |
| 第二行 | 状态词 · 地区 · 每日价 | 12 / `--ink-3`；进行中写 `安装中 62%`，失败写 `创建失败`，欠费写 `已欠费` |
| 选中 | 同一套选中态 | `--card` 底 + 左侧 2px `--cobalt` + 名称 600 |
| 不显示 | 创建时间、IP、规格、流量 | 留在详情；列表只回答「哪台、什么状态、多少钱」 |

- 价格只用于区分不同档位；同价时不隐藏，保持一致的可扫描结构。
- 列表里**不显示「正在使用」**：当前节点只住在连接舞台的节点卡（`veyl-ui` §2.2）。
- 行高 64，与配置行 / 组行同构；不用紧凑行。

#### 2.1.1 选中态为什么与连接页的节点卡不同（2026-11-18 定，不要再统一）

| 场景 | 样式 | 它回答的问题 |
|---|---|---|
| **导航列**：56px 导航的当前 destination、左栏列表行的当前项 | `--card` 底（从 `--canvas` 抬起）+ 内侧 2px `--focus` 粉条 + 名称 600 | 「你现在看的是哪一项」 |
| **卡内选择**：连接舞台的节点行 | 12% 中性底 + 2px 墨色竖条 + 名称 500（`node-card-sources.md` §5.3） | 「这几个里你选了哪一个」 |

两个理由：

1. **粉条在本产品已经固定是「位置」信号**：56px 导航的当前 destination 就是一条 2px 粉条。左栏紧挨着导航列，两列必须说同一种语言；把它们拆成粉色与墨色两种，站在旁边的用户会以为其中一列坏了。
2. **节点卡改墨色的起因是同卡撞色**：卡里有粉色的 `测速` 链接，选中再粉一次就分不清哪个能点。左栏行里没有任何链接，那个冲突不存在。

所以这不是「新旧两套」，是**位置**与**选择**两种语义。**不要为了「全局一致」把左栏改成墨色**，也不要反过来把这套粉条扩散到卡片里。

```
东京 1 号                      ● 可用
────────────────────────────────────
地区      日本 · 东京
节点      已就绪
费用      每天 $0.20 · 本期有效至 12-03

────────────────────────────────────

```

| 区块 | 内容 | 说明 |
|---|---|---|
| 头部 | 名称 20/600 + 状态（点 + 词） | 状态只在这里出现一次 |
| 事实 | 地区 / 节点 / 费用 / 流量 | 每行 label 11 / `--ink-3`，value 14 / `--ink`；行距 12 |
| 操作 | 左下 `销毁`（danger ghost），右下主按钮 | 一屏一个主按钮 |
| 不显示 | IP、端口、协议、用户名、密码、创建时间、规格 | `my-servers.md` §17.3；规格也未在 §7.4 列出，本轮不加（见 §5） |

### 2.3 主按钮按状态（2026-11-19 改：不再连接/断开）

> 用户指出：这一页是「管理节点」的地方，连接逻辑属于控制台；PM 已同意。原来的 `连接` / `断开`（含「已连接但连的是别的」那条分支）整条撤掉。

| 状态 | 主按钮（实心） | 其他 |
|---|---|---|
| 就绪 · 未在用（`healthy` / `active`） | **`去连接`**：取凭据 → 绑进全局池 → 切到控制台（已连接时只切页面，见下）；**不设当前节点、不发起连接** | `销毁` danger ghost |
| 建机中（`creating` / `booting` / `installing` / `verifying`） | 不显示；显示四段进度 | `销毁` 是唯一出口 |
| 出错（`error`） | `重新建一台` | `AI 定位` 留在失败块；`销毁` danger ghost |
| 已失效（`gone`） | `重新购买` | — |
| 已销毁（`destroyed`） | 列表不出现，详情不可达 | — |

- **为什么不是 `连接`**：连接状态、计时器、失败出口、模式行全在控制台 hero。详情页也能发起连接，就等于有两个地方能改「现在连着谁」，而只有一处显示它连得怎么样。
- **为什么仍要有主按钮**：刚建好的机器，人就在这一页，下一步是去用它。没有入口就得背名字回控制台找。`去连接` 是「把人送到能连接的地方」，不是连接本身。
- **到控制台之后分两支**（2026-11-19，按架构组核查修正）：
  | 场景 | 取凭据 / `node_attach` | 预选 | 跳转 | 提示 |
  |---|---|---|---|---|
  | 未连接（`idle`） | 是 | 是 | 是 | 无 |
  | 已连接 / 连接中（`running` / `degraded` / `starting`）· 连的就是这台 | **否，一条命令都不发** | 否 | 是 | 无（到控制台看到的就是它） |
  | 已连接 / 连接中 · 连的是别的节点，或这台还没节点 | **否，一条命令都不发** | 否 | 是 | toast `当前正在使用另一台，要换成这台，先在控制台断开。` |
  **为什么已连接时不 attach**：`node_attach` 在连接中新增节点会走 `runtime_rebuild`（`commands.md` §4.0.1，stop→start，中间断流）。点一个「去连接」不该把用户的连接打断。已连接时也不预选——节点卡的选中行就是当前连着的节点，预选另一行等于显示假状态；已在池里的节点，用户到控制台自己点。
  **预选复用** `ConnectionStage` 既有的 `preselect`（一次性、带 nonce），**不新增第二个 prop**；但它现在会顺手标「最快」，从详情跳过去的节点没测过速，标了就是假话——给同一对象加 `markFastest?: boolean`（默认 `false`），只有试用步骤流传 `true`。
- 主按钮位置：详情底部操作行**右下**；`销毁` 在最左（`veyl-ui` 危险动作分离）。
- 不把主按钮放进左栏行：选中态与「要执行的动作」是两件事。
- **`veyl-ui` §2.1** 表里这一行还写着 `用来建配置`，落地时一并改成 `去连接`；`my-servers.md` 里同一位置的 `用来建配置`（约 8 处）也是上一版命名，随这次一起扫掉。

## 3. 状态 C：进入建机与返回

> 2026-11-18 改口：建机**不再切走**，在「我的服务器」原地打开。规则见 `stage-pages-review.md` §1.1。

### 3.1 进入

- `＋` 与零台空态的 `新建节点`：**destination 保持 servers**，在中间渲染建机向导；左栏服务器列表保留，导航高亮在「我的服务器」。
- 共用同一个 `MyServerWizard` 与同一份表单状态，与连接页那一份不是两套。
- 记住进入前选中的那台服务器，供 `返回` 时恢复。

### 3.2 返回

| 结果 | 去向 |
|---|---|
| `返回` / `Esc`（没有创建） | 回到服务器列表，恢复进入前的那台选中；**向导里已选的地区与档位保留**，再打开时还在 |
| 创建成功 | **留在 servers**，回列表并把新服务器排在第一行（选中它）；不跳去连接页 |
| 创建失败 | 留在向导的失败态，不换宿主 |
| 向导打开时点导航去连接页 | 先关闭向导、**连地区与档位一起丢弃**，再切过去（与 `返回` 不同，见 `stage-pages-review.md` §1.1） |
| 创建在途时点导航 | 不切——导航禁用，沿用 N5「创建中锁返回」；`Esc` 同时被吞，失败复位后恢复 |
| 从节点组带目标组进入 | 保持现有行为：创建成功回组详情 |

- 向导期间左栏**可见但禁用**（行不可点、`aria-disabled`、45% 透明，`＋` 同）：它是上下文，不是此刻的导航。
- 建机过程中左栏不出现「正在创建」占位行：状态由中间向导的步骤流承担。

## 5. 必须改 / 建议改 / 不改

### 必须改（P1）

1. **servers destination 恢复渲染向导**：`＋` 与零台 CTA **在原地打开**，不切 destination；与 client 那一份共用同一个 `MyServerWizard` 与同一份状态；两个宿主都有 `返回`（`stage-pages-review.md` §1.1）。
2. **中间补空态**：未登录 `先登录` + `登录`；零台 `还没有服务器` + `新建节点`；读取失败 `账户暂时读不到` + `重试`。不能靠向导填充。
3. **左栏去掉品牌块**（`Veyl / 网络控制台`），标题行只留 `我的服务器 0 ＋`。
4. **详情主按钮改为 `连接`**（按状态变 `断开` / `重新建一台` / `重新购买`），放在底部操作行右侧；`销毁` 在左侧。
5. **行第二行补状态词**：`运行中 / 安装中 62% / 创建失败 / 已欠费` · 地区 · 每日价。

### 建议改（P2）

6. 详情事实用两列（label/value），行距 12；不要做成大卡片或分组标题。
7. `＋` 的命中区 44×44（现在偏小），`aria-label="新建节点"`。
8. **列表底部加常驻的 `新建节点` 行**（§1.5），并把列表包进自己的滚动容器 `.rail__body`；`rail--locked` 的禁用清单加上 `.rail__new-row`。
8. 空态正文按 §1.2 / §1.3 的短句替换 `my-servers.md` §7.2 的长句（原文提到「云服务器」，界面不出现这个词）。
9. 列表失败与详情失败共用同一个 `重试`，只保留一个按钮。

### 不改

| 项 | 理由 |
|---|---|
| 详情显示 IP / 端口 / 规格 / 创建时间 | `my-servers.md` §17.3 明确不显示 IP、端口、协议、用户名、创建时间；规格也未在 §7.4 列出。要加需先改契约。 |
| 左栏宽度 280（窄屏 260/240） | 两行足够；与其他列表同宽、同一套拖拽范围。 |
| 左栏显示「正在使用」 | 当前节点的唯一住处是连接舞台的节点卡（`veyl-ui` §2.2）。 |
| 列表里显示流量额度 | 低价值；详情有一行。 |
| 选中行点击后立即连接 | 连接是显式动作，点行只换详情。 |
| 服务器页显示计时器 / 出口 | 连接状态只在 client hero。 |

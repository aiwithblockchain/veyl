## 1. 结构与层级

免费节点是「你已有什么」，建机是「你可以做什么」；最下面是动作。

```
我的服务器   2        ⟳  ＋
──────────────────────────────
▍新加坡 1                      ●
▍香港 2                        ●
（列表可滚）
免费节点还剩 2 个，不到 1 天后到期。 去控制台   ← 13/--ink-3，链接 13/500/--link
[  ＋ 新建节点  ]                              ← 实心主按钮：--ink 底 / --bg 文字 / 15/500 / 40 高 / 圆角 8 / 占满内容宽
[图标] 在手机上使用                            ← 本轮不动：保留现有图标与上边框
```

- **入口只在「已登录且至少一台服务器」时出现，并且始终是实心主按钮**（`.btn--primary`）。只有选中「结算失败 / 欠费停用 / 已失效」的机器时，中间详情会另有「去充值 / 重新建一台」主按钮——这是刻意接受的例外：入口不随选中机器改样式。
- **为什么不显示价格**：用户明确说不要价格——价格会让人犹豫，这一行要一眼看到、有点击欲望；起价本来只是参考值，真实价格在下单页。
- **为什么 0 台 / 未登录不出现**：0 台时中间空态已经有同款「新建节点」主按钮，未登录时中间已经有「登录」主按钮；左栏再放一份就是同屏两个主按钮或两个同名动作。这两种状态不是灰色、不是次级行，而是整块不渲染。
- 实心按钮自带边界，不再压细线；它下面的「在手机上使用」仍保留自己的上边框，两种动作各自分开。
- 列表加载中、列表读取失败、`disabled`（身份异常 / 向导已开）时入口不出现或整体禁用：列表还没确定有几台时不猜。
- 试用行保留现状的句子与 `去控制台` 链接，位置在入口上方，13/--ink-3。
- 未登录时左栏只有标题与一行提示，不渲染服务器行；`accountError` / `catalogError` 时左栏写「连不上服务器」。
- 手机行**本轮保持现状**（图标 + 上边框 + 现有字号与命中高）；§4 只是将来目标形态，不在本次实现范围。

## 3. 状态

| 状态 | 试用行 | 建机入口 | 手机行 |
|---|---|---|---|
| 已登录 · 有服务器 | 有免费节点时显示（现状条件不变） | **出现**（实心主按钮） | 按现有 `showMobile` |
| 已登录 · 零台 | 不显示（中间空态已有同一句） | **不出现** | 不显示（`showMobile` 为假） |
| 未登录 | 不显示 | **不出现**（登录主按钮在中间） | 不显示 |
| 未登录 · 控制面不可达（`accountError` / `catalogError`） | 不显示 | 不出现 | 不显示 |
| 已登录 · 列表加载中 / 读取失败 / 锁定 | 按现状 | 不出现（锁定为禁用） | 按现状 |

- 0 台与未登录两态整块不出现，不占用底部空间；中间区承担那两态的主动作。

- 不做营销卡片、不加插图、不加动画。

## 6. 验收点

1. **出现条件**：已登录且 ≥1 台时出现；0 台、未登录、列表加载中、读取失败都不出现，左栏不为它留空位。
2. **层级**：入口是实心主按钮（`--ink` 底、`--bg` 文字、15/500、40 高、圆角 8、占满左栏内容宽、左侧 ＋ 16px）；入口不随选中机器改动；选中「结算失败 / 欠费停用 / 已失效」的机器时中间详情另有主按钮，这是刻意接受的同屏两个实心按钮例外；没有价格文案。
3. **关系**：试用行在入口上方；入口是一个 `<button>`，内部没有嵌套链接；手机行保持现有图标、上边框与字号。
4. **宽度**：220 / 240 / 280 宽下中英文标签都单行完整、不省略，图标与文字不挤。
5. **键盘与禁用**：Tab 可达、focus 环可见；`disabled` 时沿用 `.btn--primary` 的禁用样式且不可点。

# 左栏「新建节点」入口

> 日期：2026-11-23
> 状态：**已定稿（2026-11-23）**。只出文档，不改代码。
> 范围：`MyServersRail.tsx` 桌面左栏底部（服务器行与顶部工具不动；手机项本轮不改形态）。
> 依据：`veyl-ui` §2.1（一屏一个主动作）/ §2.2（一个事实一个住处）/ §3.1–§3.3（色、字号、间距）/ §6（文案）；`ui-ux-pro-max` 命中 `Typography · Font Size Scale`（用固定字号阶梯，不临时造字号）与 `Feedback · Empty States`（空态要给说明与动作）；「次级动作降权」检索无数据库命中，按 `veyl-ui` 自身的层级规则处理。价格事实源：契约 `commands.md` 2.29.0 起 `MyServerPlan.daily_price_cents`（唯一真源）。

## 1. 结构与层级

免费节点是「你已有什么」，建机是「你可以做什么」。一条细线把两者分开，线上是事实，线下是动作。

```
我的服务器   2        ⟳  ＋
──────────────────────────────
▍新加坡 1                      ●
▍香港 2                        ●
（列表可滚）
免费节点还剩 2 个，不到 1 天后到期。 去控制台   ← 13/--ink-3，链接 13/500/--link
──────────────────────────────   ← 唯一一条 hairline
＋ 新建节点          $0.30/天起    ← 15/500/--ink；价格 mono 12/--ink-2
独享 IP，按天付费                  ← 12/--ink-3
（沿用现状：8 间距 + 上边框）
[图标] 在手机上使用                ← 本轮不动：保留现有图标与上边框
```

- **整个 CTA 是一个 `<button>`**（两行都在命中区内），透明底、不加填充色：一屏唯一的实心按钮仍是中间区那个（`veyl-ui` §2.1）。hover 用 `--bg-hover`，focus 2px `--focus` 内描边。
- 手机行**本轮保持现状**（图标 + 上边框 + 现有字号与命中高）；§5 只是将来目标形态，不在本次实现范围。
- 未登录时左栏只有标题、一行提示与 CTA，不渲染服务器行；`accountError` / `catalogError` 时左栏整块不出现，只写「连不上服务器」。
- 试用行保留现状的句子与 `去控制台` 链接，只随 CTA 一起下移、缩到 13/--ink-3，不再与 CTA 同权重。
- **不合并成一张卡**：试用行里有导航链接，CTA 是动作。合并后要么整块看着可点却只有下半截能点，要么链接嵌在按钮里。细线分开，两种可点物各自诚实。
- 价格右对齐，只出现一次；不显示「≈月付」，不加第二列数字。

## 2. 文案（中 / 英）

| 用途 | 中文 | 英文 |
|---|---|---|
| 标题（复用 `rail.newNode`） | 新建节点 | New node |
| 价值句（新增 `rail.build.value`） | 独享 IP，按天付费 | Dedicated IP, paid by the day |
| 价格（新增 `rail.build.price`） | `{price}/天起` | `{price}+/day` |

- `{price}` 取 `formatDailyPrice(最小值)`，数字部分套 `.num`（tabular-nums）；中文 `/天起`、英文 `+/day` 用正文，不进 mono。
- 英文用 `+` 表示起价（`$0.30+/day`）：`from $0.30/day` 在 240 宽下会把标题挤成省略号；`+` 不能省，否则读成确切价格。
- 不写「低至」「仅需」「限时」，不用感叹号（`veyl-ui` §6）。

## 3. 价格的取数与缺省

- `X = min(plans[].daily_price_cents)`；排除 `regions` 明确为空数组的档位（目录说这个档位没有可用地区），`regions` 缺省按「不限制」保留。
- 只在**已登录 且 目录非空 且 存在 > 0 的日价**时渲染价格。
- 其余情况**整段不渲染**：不写 `--`、不写「价格加载中」、不留空位。文案与布局不因此跳动。

## 4. 状态

| 状态 | 试用行 | 价格 | 手机行 | 点击 CTA |
|---|---|---|---|---|
| 已登录 · 有服务器 | 有免费节点时显示（现状条件不变） | 显示 | 按现有 `showMobile` | 打开新建向导 |
| 已登录 · 零台 | 不显示（中间空态已有同一句，避免同屏两处） | 显示（目录可用时） | 不显示（`showMobile` 为假） | 打开新建向导 |
| 未登录 | 不显示 | 不显示 | 不显示 | 弹登录框；左栏仍不渲染服务器行 |
| 未登录 · 控制面不可达（`accountError` / `catalogError`） | 不显示 | 不显示 | 不显示 | **不出现 CTA**；左栏只写「连不上服务器」 |
| 目录失败 / 未加载（已登录） | 有免费节点时显示 | 不显示 | 按现有 `showMobile` | 打开新建向导 |

- 列表加载中、列表读取失败、`disabled`（身份异常 / 向导已开）时整个底部区不出现或整体禁用，沿用现状。
- 未登录时 CTA 照常占位，是「建机要登录」的唯一入口；这与 `login-and-payment.md` §3.1「点创建服务器 → 弹登录弹窗」一致，并按 2026-11-23 PM 决定同步改写了 §11.2。

## 5. 手机项（仅记录将来目标形态，本轮不改）

本轮代码保持现状：图标、上边框、现有字号与命中高都不动。以下是下一轮再收的形态，**不属于本次交付**。

去掉图标与边框，13/--ink-3，行高 32，右侧一个 `›`；hover 变 `--ink`。它与 CTA 之间留 12，不再有第二条细线——排在 CTA 之后，位置与字重都说明它是次级。

## 6. 不做

- 不动顶部 `＋`（PM 约束：顶部工具不动），它与 CTA 是同一动作的两个入口，沿用现状。
- 不做营销卡片、不加底色、不加插图、不加动画。
- 不改窄屏抽屉（< 1024px）：其顶部 ghost 按钮与底部旁注本轮保持原样。
- 不可达错误态（`accountError` / `catalogError`）不放建机入口：点了也建不成。
- 不改中间区空态与服务详情的主按钮。
- 不新增契约与命令：只读已有的 `my_server_catalog` 结果。

## 7. 验收点

1. **价格来源**：`$X/天起` 的 X 等于目录可用档位 `daily_price_cents` 的最小值；未登录 / 目录为空 / 最小值 ≤ 0 时整段价格不渲染，代码里没有硬编码金额。
2. **层级**：CTA 标题 15/500 `--ink`、价格 12 mono、价值句 12 `--ink-3`；全屏唯一实心按钮仍是中间区那个，CTA 不带填充色；手机行本轮保持现有图标、上边框与字号。
3. **五态**：未登录点击弹登录框且左栏不出现服务器行；未登录且 `accountError` / `catalogError` 时 CTA 不出现，只留「连不上服务器」；零台时左栏 CTA 与中间空态按钮并存但不产生第二个主按钮；目录失败时无价格、无占位、无跳动；有服务器时试用行位于细线上方。
4. **关系**：试用行不被合并进 CTA，`去控制台` 仍只切 destination；CTA 整块可点且内部没有嵌套链接。
5. **宽度与键盘**：240 / 260 / 280 宽下中英文均完整单行；CTA 是单个按钮，Tab 可达、focus 环可见。**已知限制**：栏宽 220–237 时英文标题与价值句会截断——换行栅格要 244 宽才能完整，没有两全阈值，故维持现有 196px 换行阈值；这一档不做额外处理。

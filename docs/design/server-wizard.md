# 新建节点向导：版式与信息层级重做

> 日期：2026-11-24
> 状态：**已定稿（2026-11-24）**。只出文档，不改代码。
> 范围：`MyServerWizard`（我的服务器 › 新建节点）整页版式、层级与文案；左栏、详情页、订单链路不动。
> 依据：`veyl-ui` §2.1（一屏一个主按钮）/ §2.2（一个事实一个住处）/ §3.1（色 token 与用色规则）/ §3.2（字号阶梯：22 / 17 / 15 / 13 / 12，页面标题用 22 档）/ §3.3（4px 网格 4/8/12/16/24/32/48、圆角三档）/ §6（文案：动词短语、错误三段式、不堆客套）；`ui-ux-pro-max` 命中 `Accessibility · Text Reflow and Spacing`（内容驱动高度、不裁字）、`Accessibility · Chip Collection Reflow`（chip 必须换行，不能压进一行裁掉）、`Navigation · Sticky Navigation`（吸底/吸顶不能盖住内容）、`Forms · Error Placement`（错误贴着动作，不只放页顶）、`Feedback · Loading Indicators`（异步按钮要 `aria-busy`，不闪）；「checkout summary sidebar」与「price display pricing」检索无数据库命中，两栏摘要与价格层级按 `veyl-ui` §2.2 / §3.2 / §3.3 处理，**标注为 fallback**。

## 0. 结论摘要

1. **默认单列 + 吸底操作栏；内容宽 ≥ 900 时升级为「左选择 + 右 280 摘要栏」**。常见窗口的中栏只有约 632 宽（1440 窗口：56 + 280 + 420 三栏 + 24/28 边距），两栏会把三张档位卡挤成两行；宽窗口才值得两栏。版心从 640 放宽到 960，**只对 `--new-node` 生效**。
2. **层级重排**：标题 22、分区标题 15、卡片名 15、正文 13、元信息 12；分区标题从 12 灰色升为 15 `--ink`，不再像文档小标题。区块间距 32，块内 8/12。
3. **「让 AI 帮我选」升为标题区右上角的 ghost 按钮**，32 高、与「返回」同一行；未配置 AI 时不出现（App 现有 `aiReady` 状态决定是否传 `onAskAi`）。
4. **系统信息整块删除**（`wizard.system`、`.wizard-system`、Ubuntu 文案）。
5. **连通性提示换成「风险说明」块**：2px 左线 + 加粗引导句 + 13/`--ink-2` 正文，中性色不用红；两栏时在摘要栏按钮上方，单列时紧贴吸底栏上方。
6. **摘要区**：日价是唯一计费单位（17/600），「约 $12/月」是 30 天估算（12/`--ink-3`，永远带「约」）；不显示任何系统信息。

## 2. 版式：单列为主，宽窗格两栏

### 2.1 断点与版心

- `.connection-stage--new-node .connection-stage__col` 的宽度从 `min(640px, 100%)` 改为 `min(960px, 100%)`，并在该元素上设 `container-type: inline-size`；其余舞台不受影响。
- 以**内容宽**（即这个容器宽）断点：
  - **< 900**：单列，摘要变吸底栏。
  - **≥ 900**：两栏 `grid-template-columns: minmax(0, 1fr) 280px`，列间距 48，右栏 `position: sticky; top: 24px`。
- 为什么常见窗口不两栏：1440 窗口下中栏内容约 632，两栏只剩约 300 给选择区，三张档位卡（最小 176）必然换行，反而更乱。宽窗口（AI 栏收起或大屏）才升级。
- 900 这一档不是拍脑袋：两栏左列 = 900 − 280 − 48 = **572**，正好容下三张 176 的卡（176×3 + 8×2 = 544）。低于 900 左列会不足 544，卡片就要折行。

## 5. 风险说明

### 5.1 版本与文案

中性色的说明块，不是红色警告条。2px 左线（`--hair-strong`）+ 左内边距 12，无底纹；引导句 13/500 `--ink`，正文 13/1.6 `--ink-2`。不用 `--red` / `--amber` 填充，不用感叹号。

- 中文：
  **IP 不一定能连上**：目标地区可能屏蔽它，或你到该地区的线路不通。开通后到「连接」里测速确认；连不上可以销毁重建。计费从开通当天开始，销毁本身不收费，但已扣的当天费用不退。
- English：
  **The IP may not be reachable**: the target region can block it, or the route may not work. After setup, check it in Connect; if it doesn't connect, destroy it and create another. Billing starts the day it's activated — destroying is free, but that day's charge isn't refunded.

四个事实一一落位：IP 可能被屏蔽 / 线路不通 → 开通后测速 → 可销毁重建 → 计费起点、销毁不收费、当天费用不退。比旧句多了「IP 被屏蔽」与「计费起点」，去掉了「能不能连上取决于你当前的网络到那个地区的线路」这种半对半错的概括。

### 5.2 位置与状态

- **两栏**：摘要卡内、创建按钮上方，与价格之间用 16 + 1px `--hair` 分开；始终同屏。
- **单列**：主列最后一个区块，紧贴吸底栏上方（32 距上一块），滚到底就是按钮上方的最后一行。
- 旧的「地区下方连通性提示」`wizard.regionConnectNote` **删除**：同一件事不再两处说（§2.2）。
- 状态变化：
  - 创建中：风险块不变，创建按钮「正在创建…」+ `aria-busy`；
  - 余额不足：摘要里按钮上方出 `role="alert"` 错误与「去充值」，风险块保留（计费口径仍成立）；
  - 组合不可用：提示留在档位卡旁，创建禁用，风险块保留；
  - 目录读不到 / 无可用地区：整块不显示（建不了，风险话术无意义）。

## 6. 摘要区

- **选中项**：地区名 17/600；下一行「档位 · 规格」13/`--ink-2`（如 `标准 · 1 核 · 1GB`）。两栏才显示，单列由上方选中态承担。
- **价格**：
  - `每天` 12/`--ink-3` + `$0.30` 17/600（`.num`）——这是真正扣费的单位，唯一主数字；
  - `约 $12/月` 12/`--ink-3`，紧邻其下。月度 = 日价 × 30（现有 `formatMonthlyFromDaily`），只是量级参考，**永远带「约」、永远不放大**；
  - 不再出现第二个价格数字或「低至」类措辞。
- **计费行**：`每天续扣；余额不足会提示充值。` 12/`--ink-3`（改写现有 `wizard.demo` 并改名为 `wizard.billing`，去掉与风险块重复的「开通后开始计费」）。
- **系统信息**：不显示任何一项（OS、镜像、内核）。用户不能选也不能改，控制面固定同一套镜像，显示它只会制造「报告感」。
- **创建按钮**：两栏时全宽、44 高；单列时吸底栏右侧、`min-width 96`、44 高。禁用条件不变（创建中、组合不可用、无地区、目录失败）。加载态文案沿用 `wizard.signingIn` / `wizard.creating`。
- 单列吸底栏：左「每天 $0.30 · 约 $12/月」（价格 15、月价 12），右创建按钮；栏高约 64。

## 9. 验收点

1. **640 内容宽**：单列；三张档位卡并排（≥176）；地区 chip 自动换行、不裁字；吸底栏始终可见价格与创建；风险块在栏上方；无横向滚动。
2. **760 内容宽**：同上；标题 22、分区标题 15、正文 13、元信息 12 四档清晰；「返回」与「让 AI 帮我选」同一行。
3. **900 内容宽**：两栏 280 + 48；右栏 sticky；选中项、日价、月价、计费行、风险块、全宽创建都在右栏；吸底栏消失；左列三卡不折行。
4. **中英文**：两种语言在 640 下风险正文与计费行完整换行不溢出；`约 $12/月` / `About $12/month` 不被截断。
5. **层级**：全页只有 22 / 17 / 15 / 13 / 12 出现在对应位置；分区标题不再是 12 灰字；选中态只用描边 + 浅底；全屏唯一实心按钮是创建。
6. **AI 入口**：`aiReady` 为真时出现在标题区右上、32 高 ghost；为假时不渲染；点击发既有 prompt；不抢焦点、不建机。
7. **系统信息**：页面上没有任何 OS / 镜像 / 内核文案，字典与 CSS 中无 `wizard.system`、`.wizard-system`。
8. **风险说明**：覆盖 IP 被屏蔽 / 线路不通、开通后测速、可销毁重建、计费起点、销毁不收费、当天费用不退六点；只用中性色，`role` 无告警语义（它是说明，不是错误）。
9. **状态**：创建中 `aria-busy`、组合不可用与余额不足按 §7；余额不足错误是 `role="alert"` 且紧贴创建按钮。
10. **键盘**：两个 `radiogroup` 方向键可用；chip 与卡片的 focus 环 2px `--focus`；吸底栏不被内容遮挡。
11. **吸底栏可见性**：900×600 打开向导，初始视口内就能看到价格与创建，不需要滚动；滚到表单任意位置，动作栏都贴着视口底部。

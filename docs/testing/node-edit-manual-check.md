# 真机验收清单：编辑自定义节点

> 日期：2026-11-25
> 对应设计：`docs/design/node-edit.md` §5。
> 用法：装好包启动应用，按顺序做完，勾选「通过」。任何一条失败，记下卡在哪一步、界面原文，交回给我。

---

## 准备

- 节点卡里有一个**手动添加**的节点（自己的服务器，知道地址、端口、加密方式、密码）。
- 另有一个**订阅导入**的节点。
- 另有一个**托管**节点（在我的服务器里创建的那台）或一个**免费**节点，用来做「不该出现入口」的反例。
- 应用当前未连接。

---

## 1. 只改名字

- 操作：手动节点行 › `⋯` › 编辑节点，只改名称，保存。
- 期望：行内名字立即变化；地址、端口、加密方式看起来没变；关掉应用重开，还是新名字。
- [ ] 通过

## 2. 改连接参数

- 操作：把地址、端口、加密方式改成另一组可用的参数，密码留空，保存。
- 期望：保存成功；这个节点在列表里的延迟变回「未测」；用新参数连接能连上。
- [ ] 通过

## 3. 改正在用的节点

- 操作：选中这个节点并连接，再次编辑它，改任意一个连接参数，保存。
- 期望：顶部从「已连接」变回「未连接」；提示说明「已保存；已断开，重新连接后使用新设置」；**不会自动重连**。
- [ ] 通过

## 4. 改连接中配置里的其它节点

- 操作：连接在 A 节点上，编辑同一套配置里的 B 节点（不是当前用的那个），改参数，保存。
- 期望：连接自动按新设置重建并继续可用；当前选中的仍然是 A；没有断过又连上的中途提示。
- [ ] 通过

## 5. 测速进行中编辑

- 操作：点「测速」，在进度还没跑完时编辑其中任意一个节点并保存。
- 期望：旧的那次测速结果不会落到被编辑的节点上；那一行最后显示「未测」。
- [ ] 通过

## 6. 订阅节点只读

- 操作：对订阅节点点 `⋯` › 编辑节点。
- 期望：地址、端口、加密方式、密码四项灰显不可改；说明写的是「本地改了不会同步、也不会被订阅纠正」；**只改名字能保存**。
- [ ] 通过

## 7. 托管与免费节点没有入口

- 操作：对托管节点和免费节点分别点 `⋯`。
- 期望：菜单里**没有「编辑节点」**（只剩其它允许的项，或没有这个菜单）。
- [ ] 通过

## 8. 输入校验

- 操作：名称留空保存；地址填 `https://example.com`；端口填 `70000`；密码填 257 个字。
- 期望：每一项都在对应栏下方给出错误，焦点回到第一个错的栏；不会发起保存。
- [ ] 通过

## 9. 密码留空不覆盖

- 操作：不改密码、只改名称并保存，然后连接这个节点。
- 期望：还能用原密码连上（说明密码没被清空）。
- [ ] 通过

## 10. 改过之后重新导入

- 操作：把改过名称的手动节点，用**原来的那条链接/参数**再导入一次。
- 期望：不会多出第二个节点（按「已有相同节点」跳过）；用**改名后的新名字**手动新建，则会出现第二个——这是预期。
- [ ] 通过

---

## 1. 建配置

左侧「＋ 新建配置」→ 名字「全部流量」→ 选 **接管全部流量** → 保存。
保存后自动成为当前配置。

## 2. 连接

点顶部「连接」。

- 遮罩依次：正在准备后台组件 → 正在建立连接 → 正在确认出口
- **首次弹一次管理员授权**，输密码。文案应说明：后台组件、只用于全部流量、代理模式不需要授权
- 若提示去「系统设置 › 登录项与扩展」打开助手：照做，回来再点一次连接（首次注册的正常流程）

## 3. 连上后

```bash
curl -s https://ipinfo.io/ip; echo
```

**必须不是** `<直连 IP>`。

```bash
netstat -rn | grep "^default"
```

IPv4 默认路由应指向 `utun`，不再是 `en0`。

浏览器打开任意网站，能上。

## 4. 断开（最重要）

点「断开 VPN」，遮罩：正在断开连接 → 正在收尾。

**断开后立刻**：

```bash
scutil --proxy | grep -E "HTTPEnable|HTTPProxy"
```

应无输出。

```bash
curl -s https://ipinfo.io/ip; echo
```

应为 `<直连 IP>`。浏览器刷新一个页面，能开才算过。

## 5. 再连一次

第二次连接**不应再弹授权**。连上 → 验证 IP → 断开 → 再验证 IP。

## 出问题

| 现象 | 怎么做 |
|---|---|
| 连不上 | 把遮罩最后那句话发我 |
| 断开后上不了网 | 设置 → 遇到问题 → 修复网络 → 清除残留代理 |
| 还不行 | 再用「强制重置网络」，不要连续重试 |
| 其它异常 | 告诉我大概时间，我去翻 `logs/` |

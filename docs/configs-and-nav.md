# 配置与左侧导航

> 日期：2026-11-03
> 一句话：**一套配置 = 一套完整的网络方案。左栏列出所有配置，点一下切换。**

---

## 1. 最左侧：activity bar

和 VS Code、Claude Code 桌面版一样，最左边一列是窄条图标，切换「当前在看什么」。

**本期只有一个：客户端。**

| 位置 | 内容 | 本期 |
|---|---|---|
| **客户端** | 我自己的配置列表 | 做 |
| ~~服务商~~ | 面向用户的服务商市场（后期做成 dapp 入驻） | **不做，也不显示图标** |
| ~~自建站~~ | 四级用户管理自己的站点与统计 | **不做，也不显示图标** |

**不做的就不显示。** 留一个点了没反应的空图标，用户只会以为坏了。等做的时候再加回来，成本是同一处代码。

服务商与自建站是两件完全不同的事：**服务商是买家视角**（去哪买服务），**自建站是卖家视角**（我怎么提供节点、赚了多少）。将来加进来时也必须用不同的词。

## 2. 左栏：配置列表（客户端）

```
┌──────────────┐
│ ▪ 配置 1          │  ● 已连接
│   2 个节点 · TUN 模式 │
├──────────────┤
│ ◇ 配置 2          │
│   5 个节点 · Proxy 模式 │
├──────────────┤
│ ＋ 新建配置       │
└──────────────┘
```

每一行显示：**名称 · 节点数 · 接管方式**。

- **名称**创建时自动生成（`配置 N`），建立后可双击改名（§2.2）
- **节点个数**：一套配置可以挂多个节点，随时在中间底部的节点下拉里换
- **接管方式**：小字固定为 `TUN 模式` / `Proxy 模式`，与新建配置的选项措辞一致；**每行名称前另有 6×6 标记**——`TUN` 实心方块、`Proxy` 空心圆环，只用 `--ink-3`（`docs/design/rail-mode-distinction.md`）。标记只做扫视分组，文字负责确认；选中仍靠左竖条 + 卡底 + 名称加粗，标记不变色不变形
- 本机代理端口**不在行内显示**：地址与端口的唯一住处是设置 → 连接（`veyl-ui` §2.2）

**配置的切换入口就在这里，不在中间区域顶部。** 配置是导航级的东西，和「我在看哪个列表」同级，放在中间会让它看起来像个临时控件。

### 2.1 列表一开始是空的

**配置不预生成，等用户在对话里做出选择之后才出现。**

| 用户的选择 | 生成什么 |
|---|---|
| 在 `source_choice` 里选「Veyl 免费节点（仅供试用）」 | 一条配置，名字「默认配置」，节点来自种子包 |
| 选「用我自己的节点」并填好 | 一条配置，名字由用户起，节点来自 URL 解析或手动填写 |

空列表的状态：

```
还没有配置

在右侧告诉助手你的情况，它会帮你配好第一套。
或者自己新建一套。

[ 新建配置 ]
```

**空态必须能自己走出去**——用户删光了所有配置之后，回到这里仍然有路。

配置**可以删除**，包括那条「默认配置」。删光之后回到空态，从空态能重新生成。不设「不可删除」的特例：特例会让人不敢动，而且删除后再生成本来就很简单。

### 2.2 行交互：单击选中、双击改名

| 操作 | 结果 |
|---|---|
| 单击行 | 选中这条配置（切换当前查看的配置，不改变连接） |
| **双击名称** | 名称变成行内输入框，进入改名 |
| 悬停行 | 右侧出现「重命名」与「删除」两个操作；不做常驻按钮 |

**改名规则**（与实现 `ConfigRail.tsx` 一致）

- Enter 保存，Esc 取消，**点行外（包括点另一条配置行）等同于保存当前行**；输入框限 40 字。
  从一行切到另一行编辑时，旧行只保存一次，不会重复提交。
- **空值或没改过就退出，不发请求**：trim 后为空、或 trim 后与原名相同，直接还原显示，不调 `config_update`。
- 保存走 `config_update { configId, name }`：trim 后非空、≤ 40 字符、不重名。
- **失败时关闭编辑、恢复原名，并在该行下方行内提示**（重名：「已经有一套叫这个名字」；其它：「改名失败，请重试」）。
  不保留输入内容；要再试就重新双击。
- **改名不影响连接**：只改显示名，不重启运行时、不重新生成配置；**正在连接的配置也能改**。
- **输入法组合态回车不提交**：中文输入法选词时的 Enter 属于输入法，不是保存；等组合结束再按 Enter 才保存。
- 悬停「重命名」入口与双击等价：同样进入行内编辑。

## 3. 一套配置包含什么

| 项 | 例子 |
|---|---|
| 连接方式 | 接管全部流量 / 只给代理地址 |
| 分流策略 | 本地直连 / 全部走 VPN（两档；不支持按服务挑选） |
| 节点集 | 一个或多个服务器 |
| 当前使用哪个节点 | 节点集里的某一个 |
| DNS | 本地与境外各用哪几个候选 |
| 监听端口 | 本机代理端口（接管全部模式不用） |
| 内网排除 | 额外要绕开的网段（仅接管全部模式） |

这些是一整套，**不拆开单独切换**。用户换配置就是换一整套方案。

---

## 4. 什么时候新建一套

| 触发 | 举例 |
|---|---|
| **改连接方式** | 从「只给代理地址」升级成「接管全部流量」——必须新建，不能就地改 |
| 换场景 | 公司一套、家里一套、出差一套 |
| 换用途 | 一套「日常」，一套「只给某个软件用」 |

**改连接方式必须新建而不是就地修改**：这两种方式是完全不同的网络接管方式，就地改会让「我刚才明明配好了」变成「它自己变了」。新建一套、起个名，用户知道自己做了什么。

其它改动（换节点、加一条分流规则）**就地改当前配置**，不新建——否则列表会爆炸。

## 5. 名字

**创建时自动给名，建好之后随时可改。**

```
新建一套配置（审视页）

名称        配置 1
接管方式    TUN 模式（接管全部流量）
节点来源    Veyl 免费节点
...
```

创建流程里名称是**只读事实**（`配置 N`，取当前未被占用的最小整数），不给输入框——两问之后用户此刻的意图是确认，不是编辑。**建立后**在左栏双击名称就地改名（§2.2），改名不影响连接。

旧版「场景或时间 · 关键特征」的建议名（「家里 · 本机代理」）不再使用：接管方式与节点数已经在行内显示，名字里再写一遍就有两个住处。

**不允许重名**——列表里两个一模一样的名字等于没有名字；改成已存在的名字会被拒绝，输入框保持打开。

## 6. 切换的代价

| 情况 | 行为 |
|---|---|
| 当前未连接 | 直接切，无感 |
| 当前已连接 | **先提示会断开一次**，确认后切换并自动重连 |
| 当前有未保存的改动 | 先问是否保存 |

不静默切换。用户点一下，网络断两秒，不说清他会当成故障。

---

## 7. 「节点」和「配置」是两个层级

| | 节点 | 配置 |
|---|---|---|
| 是什么 | 一台具体服务器 | 一套用法 |
| 数量 | 可以很多 | 可以多个，每个引用若干节点 |
| 在哪看 | 配置详情、中间底部 | 左栏 |

一个节点可以被多套配置引用。**「换节点」和「换配置」长得像，但结果差很远**，界面上必须分得开。

- 换节点 → 中间底部「切换到此节点」，只换服务器，分流不动
- 换配置 → 左栏点另一行，连接方式、分流、节点全变

## 8. 存储

| 内容 | 存哪 | 为什么 |
|---|---|---|
| 配置索引（id、名字、创建时间、最后使用、是否激活） | SQLite | 排序、查重名、记住上次用的哪套 |
| 配置详情与节点集 | SQLite | 整体读写、整体校验 |
| 节点密码 | `secrets.enc`，配置里只留引用 | 明文密码永不落盘 |
| **预置资源**（提示词、默认配置模板、规则集） | **文件**，随包预置 | 见 `docs/upgrade.md`：产品资产，跟 APP 版本走，不进数据库 |

---

## 9. 与「千人千面」的关系

配置定的是**方案**，不是**界面长相**。中间区域的分上中下骨架固定，只有中间那段由 AI 编排（`docs/center-panel.md` §2.1）。

但两者有关系：**换了配置，AI 应该重新编排一次中间区域**——连接方式和分流都变了，原来那块「本机代理地址」的卡在新配置里没有意义。

切换之后 AI 收到一条系统消息说明换了什么，然后自己决定中间显示什么，不再问用户一遍。
